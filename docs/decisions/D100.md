# D100 · Every value explains itself

Domain. Language.
Decision. `explain` resides on `::any` and answers the explanation of
any value [D98]: the page `docs` reads for it under `:doc`, then the
value itself under `:value`. A name reads its own page,
`::number/add | explain`, a value the page of the kind it shows,
`42 | explain`, and an error `!|` opened the page of its site, the tag
it shows [D97], so an error explains as it did. The explanation answers
the value by `value`, which for an error is the error on the success
track that `raise` raises again, and its page by `doc`. `trail` stays
on `::error`, a word of errors alone.
Source. «а обычное значение так же можно заэксплайнить? или как?»
(maintainer, 2026-09-27 10:56, session d427ce7e) and «окей, проверяй..»
(10:59), answering the model's proposal to move `explain` onto any
value over `docs` once the name `value` proved free. The reading is the
model's, the same day, from the probes in which `42 | explain` reached
the verb of errors and wrote the number under `:error`.
Set aside. `explain` on `::error` alone, which a value of another kind
reaches by its name and answers with a field that names it an error.
`error` as the name of the field and its verb, which holds a value of
any kind.
