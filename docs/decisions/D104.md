# D104 · A sentence of the first screen answers frictions a run records

Domain. Process.
Decision. The first screen, the page of `::qlang`, is written against
the runs of the benchmark [D26]. A run hands a fresh model the first
screen as its only prior, the tasks of `scripts/benchmark/tasks.mjs`
and the command line, and its record under `scripts/benchmark/runs/`
holds the hash of the screen it read, the calls each task cost and
every friction met, each with its query, what was expected and what
came. A sentence enters the first screen, or a page, to answer
frictions a run records, and the decision that writes it names them;
its examples are laws the suite runs; the next run, on the screen that
holds it, tells whether they are gone, and a sentence whose frictions
no run meets again is one a later decision may take out. The
references of the tasks, the shortest query the tree answers each with,
run in the gate, so a task stays solvable and its price is on record.
The first screen of run R1 gains, each for its frictions:
- the forms, `a | b`, `a * (body)` with its first failure, `/k` and
  `/0`, `a !| b`, the quote as code held as a value, the literals and
  a name for a value: R1.F2, R1.F3, R1.F4;
- the channel of the command line, JSON in and JSON out, a JSON object
  a map whose keys are keywords, `--raw` and `| json`, and a string
  turned into a keyword to group or index by: R1.F7, R1.F10;
- the doc a page is, which answers its text by `content` and its
  examples by `quotes`, the list of verbs of a kind as the whole of
  them, so a verb missing there does not exist, and `explain` on an
  error: R1.F5, R1.F9.
The page of `groupBy` says a string key is made a keyword, R1.F7, and
the page of `sort` that `reverse` answers the order descending, R1.F8.
R1.F1 is the shell of the machine, which the prompt of a run states.
