# D108 · The code of a doc takes its role from the tags over it

Domain. Language.
Decision. A doc holds prose, quotes and quotes under tags, a stack of
any depth, `::link~(…)`, the form a quote under a tag has in code [D20];
the grammar of a doc reads the stack before a quote. A quote with no tag
is code the prose holds; a tag gives the quote a role, each tag of the
stack its own, read from the outside in as the tags of any value
[D34]. The first is `::link`: a query a reader follows, which answers
without an error; `links` answers the segments of a doc whose stack
holds `::link`, a host's tag over it among them; and every link of
every page of the catalog runs in the suite, so a link that dies fails
the gate. A role that asks for its own check comes as a kind of its own,
with no change to the grammar or to the doc. `content` and the print of
a doc write each stack before its quote, so a doc reads back as itself
[D96]. A mention in backticks stays prose, for a fragment that is no
query; a query a page names to be followed is a link.
Source. «как разобраться с `::qlang | manifest` и ~(…) .. ?  ..
заворачивать примеры в а ля ::expample?  или нагавигацию в тэги или
как.. ::link~(::qlang | manifest)?  или как? подумай хорошенько здесь..
с точки зрения эмержентности и т.п. главных целей qlang» (maintainer,
2026-09-28 08:26, session d427ce7e), «почему только link ?» (08:57) and
«а если 2 тэга будет или 5?» (08:57), answering the model's proposal of
`::link` over a quote; the general stack and the role of each tag are
the model's reading of those questions, the same day.
