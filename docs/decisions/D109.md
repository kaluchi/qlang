# D109 · An answer within a budget, and the marker that reads what it left out

Domain. Language.
Decided by. The maintainer: a kind of the core, a verb the model
controls and a budget the host applies. The model's: the form of the
marker, the order in which a value gives way, and that a part gives way
only to a marker that prints shorter than it.
Decision. `elide` answers a value whose print fits a budget of
characters, replacing what does not fit by values of the kind
`::elision`, a kind of the core, since every host and every print meets
them [D21]. Among the parts beneath the top, a part gives way only where
its marker of it whole prints shorter than it: `[]`, `{:n 1}` and a
short string stay as they are, so a budget never lengthens a print, and
a value whose parts all print no longer than their markers is answered
as it is, over the budget. The largest such part gives way first: a
string or a map to its marker, a vector to its first half and a marker
of the rest, halving on to its marker whole at the most, which prints
shorter than it. An alert's excerpt and a budget the command line asks
for follow the same rule, as a subject a failure passed gives way only
to a shorter marker [D7]. A marker holds `:size`, the elements, the
entries or the characters it stands for, `:read`, the quote that applied
to the value `elide` took answers the part left out, and for a string
`:head`, its first characters; it prints and reads back as the value it
is [D96], so a reader continues the query by `:read` to see what the
budget left out. A value whose print fits is answered as it is. `elide`
is a word of `::any`, and a host applies it to an answer within a budget
asked for [D120].

Set aside. `::cli/elision`, which a second host would spell again. A
budget the host applies unseen, which a marker that says how to read
back makes seen. Each step of the halving allowed only where it prints
shorter, which stops a vector at once, since a marker among its elements
spreads the vector over lines, and gives forty numbers way whole where
five of them and a marker fit; a floor of size below which nothing gives
way, a number with no reason.
Requirements. `:any/elide/keepsAPartShorterThanItsMarker`, `[[] {:n 1}
"short"] | elide 3` answering itself; the laws of a string giving way on
a string longer than its marker; the unit test that a failure within a
budget prints no longer than its alert whole.
