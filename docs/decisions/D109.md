# D109 · An answer within a budget, and the marker that reads what it left out

Domain. Language.
Decision. `elide` answers a value whose print fits a budget of
characters, replacing what does not fit by values of the kind
`::elision`, a kind of the core, since every host and every print meets
them [D21]. While the print exceeds the budget, the largest part of the
value beneath its top gives way: a vector keeps the first half of its
elements and ends with a marker of the rest, a string or a map gives way
whole, and the top itself, a vector, keeps the first half of its
elements. A marker holds `:size`, the elements, the entries or the
characters it stands for, `:read`, the quote that applied to the value
`elide` took answers the part left out, and for a string `:head`, its
first characters; it prints and reads back as the value it is [D96], so
a reader continues its query by `:read` to see what the budget left
out. A value whose print fits is answered as it is. `elide` lives on
`::qlang/any`, and a host applies it to the answer it prints with a
budget of its own: the command line prints within four thousand
characters, an error, an alert, within one thousand, `--full` lifts the
budget, and the JSON channel, whose
answer other tools read as data, answers data whole and elides an error
alone, whose facts reach within the budget and whose `:read` reads
beneath `!|`.
Source. «это будет ::elision или ::cli/elision или как? кто будет
заниматься?  как управляться? скрыто автоматически или это управляемый
концепт .. как твои head tail в баше ? | elide  ?» (maintainer,
2026-09-28 08:43, session d427ce7e) and «ну пусть.. не проверим не
узнаем» (08:44), answering the model's proposal of a kind of the core,
a verb the model controls and a budget the host applies; «потому что все
что старое там изначально записанное это скорее были идеи и понимание
что надо делать.. а не конкретная форма..» (08:35), on D21. The form
of the marker and the order in which a value gives way are the model's,
the same day.
Set aside. `::cli/elision`, which a second host would spell again. A
budget the host applies unseen, which a marker that says how to read
back makes seen. The JSON channel cutting data, which a tool downstream
reads whole.
Replaced in part by [D120], under which the command line prints an
answer whole and applies a budget only when asked, by `--budget=N`.
