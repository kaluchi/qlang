# D115 · The step of a constructor is no tagged value

Domain. Language.
Decision. The step a constructor invocation `::T<payload>` leaves in a
quote is a record of the kind `::construct`. It was a record under
`::tagged`, the tag of the kind of every value under a tag,
`::qlang/tagged`: one tag named two kinds, and its one page spoke of the
step while its noun held the verbs of every tagged value, `payload` and
`within`, so `type` of a step and of any tagged value read alike and a
reader asking for either reached the page of the other.
Source. «заоно посмотри остальное как оно все проецируется на
существительные и т.п.» (maintainer, 2026-09-28 10:52, session
d427ce7e); the reading, the model's the same day, from the probe in
which `::tagged | eq ::qlang/tagged` answered `true`.
Set aside. The name kept, one tag for the step of a quote and for the
kind of the values it builds.
