# D116 · `map` over a set answers the vector of its images

Domain. Language.
Decision. `map` over a set runs its code on each element in the one
order and answers the vector of the images, one per element [D181].
`filter`, `take`, `drop` and `flat` keep a set, since what they answer
is a part of it; the image of a set under code is no part of it, and
`distinct` after `map` makes it a set again when a set is meant. The
listings of the catalog, `manifest` and `kinds`, are sets, and a count
or a sum of what code answers for each of them counts every element.
Source. The maintainer's agreement at 2026-09-28 11:49 (session
d427ce7e) to the model's proposal, after run R6 met
`::vec | spec | /verbs * (docs | first | quotes | count) | sum` answering
`6`, the sum of the distinct counts, where the verbs of vectors hold
thirty-six laws; the reading, the model's the same day, is D103's: a
failure is loud, and an answer a reader cannot tell from a right one is
the worst failure there is.
Set aside. The listings of the catalog as vectors, which leaves the trap
