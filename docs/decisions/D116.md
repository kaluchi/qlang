# D116 · `*` over a set answers the vector of its images

Domain. Language.
Decision. `*` over a set runs its body on each element in the one order
and answers the vector of the images, one per element, where it
answered the set of them and merged the images that were equal.
`filter`, `take`, `drop` and `flat` still keep a set, since what they
answer is a part of it; the image of a set under a body is no part of
it, and `distinct` after `*` makes it a set again when a set is meant.
The listings of the catalog, `manifest` and `spec | /verbs`, are sets,
and a count or a sum of what a body answers for each of them now
counts every element.
Source. The maintainer's agreement at 2026-09-28 11:49 (session
d427ce7e) to the model's proposal, after run R6 met
`::vec | spec | /verbs * (docs | first | quotes | count) | sum` answering
`6`, the sum of the distinct counts, where the verbs of vectors hold
thirty-six laws; the reading, the model's the same day, is D103's: a
failure is loud, and an answer a reader cannot tell from a right one is
the worst failure there is.
Set aside. The listings of the catalog as vectors, which leaves the trap
in every set a reader builds. A warning on the page of the set, which
the run did not read.
