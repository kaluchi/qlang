# D118 · A name a reader guessed leads to the names it was near

Domain. Language.
Decision. The names an unknown name was likely meant to be are, beside
those within a slip of the hand, the names one of which begins the
other, three letters at least: a reader who guesses `multiply` meets
`mul`, and one who guesses `::str` meets `::string`. The refusals of the
axes that read a name, `docs`, `spec`, `examples` and `source`, carry
the same `:nearest`, over the names of tags for a tag and over the
names of the scope for a keyword, as the refusal of a name a query
calls does [D7].
Source. Run R6 of the benchmark (2026-09-28, session d427ce7e), frictions
R6.F2 and R6.F3: `::str | spec` answered `SpecBindingNotFoundError`
with no name near it, and `:triple ::verb~(multiply 3)` answered
`UnresolvedIdentifierError` with `:nearest []`; the maintainer's
agreement at 11:49 to the order of work that named them. The rule of the
prefix is the model's, the same day.
Set aside. A table of synonyms, `lower` for `downcase`, which a catalog
would keep in a second spelling beside its names.
