# D119 · A name has one page, and a keyword is an anchor within it

Domain. Language.
Decision. `doc` answers the page of a name, one doc, where `docs`
answered the vector of the docs of its slot, one in every declaration
of the catalog; the docs a declaration writes are the parts of that one
page. An absolute name, `::vec`, `::qlang`, `::vec/sort`, is the
subject, and a keyword is an anchor within it, as a key within a map
and a name within a scope: `::qlang | doc :pipeline` answers the page of
the member `pipeline` of `::qlang`, `::vec | doc :take` the page of a
verb, a vector of keywords is a path of anchors, `::vec | doc [:take
:count]` the page of a slot of a verb, and a set of keywords answers the
pages of several, `::qlang | doc #[:pipeline :errors]`. A member of the
root noun has no address of its own, where D117 wrote it short as a
tag, `::pipeline`, which read as a kind. A link names a page by the same
address, `::link~(::qlang | doc :pipeline)`. A name without a page
answers null.
