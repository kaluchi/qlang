# D121 · A link opens a page

Domain. Language.
Decision. A link names a page: the query a `::link` holds answers a
doc, so `links * open` over a page answers pages alone and `* content`
reads them. A query that lists or shows something, `::qlang |
manifest`, `::vec | spec | /verbs`, `::vec/sort | spec`, stands in the
prose as code with a sentence saying what it answers. The suite follows
every link of the catalog, the pages of the concepts among them, and
fails on one that answers no doc.
Source. «то как будто бы какой-то мусор в начале .. или то так задумано
было тобой?» (maintainer, 2026-09-28 14:02, session d427ce7e), on the
kinds and the verbs that `::qlang | doc | links * open` answered before
the pages. The rule and its check are the model's reading, the same day.
Set aside. A link to a listing, which `links * open` mixed with the
pages it opened. A filter by `type` after every fan-out, which each
reader would write again.
