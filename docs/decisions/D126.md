# D126 · The JSON channel writes a set as an array

Domain. Host.
Decision. Under the JSON channel of the command line a set is written as
the array of its elements in the one order: `echo '[1,2,2]' | qlang
'distinct'` answers `[1,2]`, as `distinct | json` already wrote it. A
set is the vector in the one order without duplicates [D16], so the
array carries all of it but the mark that it is a set, which the lossy
codec of the boundary gives up as it gives up a map's order of keys. A
quote, a keyword, a tag and a tagged value stay refused with the path to
them, since JSON has no form for them that is no guess [D103].
Source. «множество прекрасно встает в json это обычный вектор же... в
чем там проблемы?» (maintainer, 2026-09-28 19:58, session d427ce7e),
after runs R7 and R8 of the benchmark had to end the distinct messages
of a log in `| json`; «и остальне делай» (20:01).
Set aside. The set refused with the quote, which made the channel refuse
what the verb `json` writes.
Replaces in part [D103].
