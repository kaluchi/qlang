# D130 · The language takes the forms a newcomer writes by habit

Domain. Language.
Decision. Where a fresh reader writes a form by the habit of every other
language, and the form has one reading, the language takes it rather
than the first screen explaining an exception. A pipe written before
`!|`, `a | !| b`, stands for the combinator after it; a pipe after it,
or two pipes, are refused with the sentence of [D46]. The key of
`groupBy` and `indexBy` that answers a string or a number files the
element under the keyword of its text, so a field of JSON groups as it
is, `groupBy ~(/status)`, and a number keys `:"1"`; a boolean, null and
a tag name key by the keywords of their literal and name [D201], and a
key of any other kind is refused. `contains` asks a vector and a set
for an element, as `has` does, and a string for a substring, so
membership in a JSON array reads under the word every other language
gives it; a value of no kind it serves is refused with its addresses.
Source. «т.е. если можно не тянуть исключения в стартовое описание и не
воевать с прайором -  а просто дешево полечить в самом языке - то так и
надо делать» (maintainer, 2026-10-02 23:10, session 87118b06), after a
measurement the same night: clean children given the first screen and
the command line wrote `filter ~(…) | * (…)` and `groupBy ~/customer`
in most of the tasks they failed, each refused, and the benchmark had
met `| *` in runs R6 to R10, a string key of `groupBy` in R1 and
`contains` on a vector in R10.
Set aside. A refusal of `a | !| b` that names the right form, which the
children met without reading it; refusing a number key, which JSON data
carries as often as a string.
Replaces in part [D127], whose refusal of `| *` and `| !|` this takes
back.
