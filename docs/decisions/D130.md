# D130 · The language takes the forms a newcomer writes by habit

Domain. Language.
Decision. Where a fresh reader writes a form by the habit of every other
language, and the form has one reading, the language takes it rather
than the first screen explaining an exception. A pipe written before
`*` or `!|`, `a | * b` and `a | !| b`, stands for the combinator after
it, so `a | * b` is `a * b`; a pipe after either of them, or two pipes,
are still refused with the sentence of [D127]. The key of `groupBy` and
`indexBy` that answers a string or a number files the element under the
keyword of its text, so a field of JSON groups as it is, `groupBy
~(/status)`, and a number keys `:"1"`; a key of any other kind is
refused as before. `contains` asks a vector and a set for an element, as
`has` does, and a string for a substring as before, so membership in a
JSON array reads under the word every other language gives it; a value
of no kind it serves is refused with its addresses.
Source. «т.е. если можно не тянуть исключения в стартовое описание и не
воевать с прайором -  а просто дешево полечить в самом языке - то так и
надо делать» (maintainer, 2026-10-02 23:10, session 87118b06), after a
measurement the same night: clean children given the first screen and
the command line wrote `filter ~(…) | * (…)` and `groupBy ~/customer`
in most of the tasks they failed, each refused, and the benchmark had
met `| *` in runs R6 to R10, a string key of `groupBy` in R1 and
`contains` on a vector in R10.
Set aside. A refusal that names the right form, kept by [D127] for `| *`
and met by the children without reading it; a verb `each` beside `*`,
set aside by [D127]; refusing a number key, which JSON data carries as
often as a string.
Replaces in part [D127], whose refusal of `| *` and `| !|` this takes
back.
