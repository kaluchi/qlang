# D131 · The first screen teaches the foundation, measured on probes its author never saw

Domain. Process.
Decision. The first screen, the page of `::qlang`, is written from the
invariants of the language: what a reader can rely on, then the
combinators, the literals, the reading of parts, the commands, the
kinds and their verbs, what differs from the languages a reader knows,
failures, code and prose as values, the way to work a task, the way to
ask, and the chapters, each claim with a law that runs. A sentence stays
by what it carries to a clean reader, measured on probes the author did
not write the screen from: conformance cases drawn by a hash and kept
unread, tasks a clean author wrote with answers computed outside the
language, and the first attempt written blind. A clean reader is a
process of its own, started from an empty directory, whose context the
page and the probes are alone. The screen is complete first; the bound
of four kilobytes waits for a pass on compactness that the same probes
measure.
