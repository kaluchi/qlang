# D135 · `groupBy` and `indexBy` without a key file an element under itself

Domain. Language.
Decision. The key of `groupBy` and `indexBy` is optional, as the key
of `sort` is: `:key #[::quote ::null]`. Without a key, an element is its
own key, a keyword as it is, a string or a number under the keyword of
its text [D130], so `["b" "a" "b"] | groupBy * count` is `{:b 2 :a 1}`.
Source. «т.е. если можно не тянуть исключения в стартовое описание и не
воевать с прайором - а просто дешево полечить в самом языке - то так и
надо делать» (maintainer, 2026-10-02 23:10, session 87118b06). Clean
readers counting the occurrences of each value wrote `groupBy ~(.)`
and `groupBy ~` on fresh sets of tasks, the
identity key spelled the way their prior spells it.
Set aside. A verb of its own for the occurrences, `frequencies`, a
second spelling of `groupBy * count`.
