# D140 · A key ranks by the one order, and `::desc` turns a place to descend

Domain. Language.
Decision. The key of `sort` answers the value an element ranks by, and
the one order compares it; a vector it answers ranks element by
element, the first place first and each later one among the elements
the places before it leave alike [D16]. `::desc` is a kind whose order is
the reverse of its payload's, written by `desc` or `::desc(…)`: the one
order ranks the values of the kind so, between elision and the other
tags, and the kind owns its comparisons, `gt`, `gte`, `lt` and `lte`, so
`1 | desc | gt (2 | desc)` is true as `max` and `sort` read it. A key, or
one place of a vector key, descends whatever the kind it ranks, a string
among them, `sort ~([(/count | desc) /name])` as `ORDER BY count DESC,
name` reads. `min` and `max` take the key `sort` takes and answer the
element, the first of equal ones. A key that answers an error answers
the call, and so does a key whose vector holds one, where the vector
carried the error into the order without a word [D87]; without a key an
error among the elements ranks as the one order ranks it.

session 87118b06). A first reading took several key quotes on `sort` and
