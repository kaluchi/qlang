# D142 · The benchmark measures on tasks its reader never saw

Domain. Tooling.
Decision. A measurement of what a reader of the first screen can do runs
on a set of tasks a clean author wrote: `claude -p` from a directory of
its own, with no settings, memory or server, writes the inputs, the
tasks and a script that computes the answers, and never sees the
language. A set measures once. Reading what its children missed, `misses`
or `frictions`, marks it seen, and a seen set serves the work; the next
measurement orders a new set. Clean children solve a set blind, the
screen and the inputs alone, or with the command line, which they may
run and ask, and the tree of the checkout grades the queries they wrote,
each line naming the commit that graded. A screen is the first page as
a tree printed it, saved under a name, so a run names the page it read
and two runs compare two pages; a run of the command line keeps every
call and what the language answered. The prediction of conformance
cases, drawn by a hash of their query and never printed, measures the
reading of single answers. The tooling is `scripts/benchmark.mjs`, with
`author`, `run`, `grade`, `misses`, `frictions`, `predict` and
`predictions`, and the sets of session 87118b06, H to N, live under
`scripts/benchmark/sets/` with their runs, seen.
Source. «понимаешь, я хочу что бы агент цельную актину получал о языке,
а не набор шпаргалок имитирующих то ли баш, то ли ещё что-то .. в общем
адхуки заточенные на прохождение бенчмарка это не то что я хочу»
(maintainer, 2026-09-28 09:51, session d427ce7e); «скрипты да.. надо
выводить из тени скрачпада ...» (2026-10-03 17:43, session 87118b06),
and «ок» on the layout (17:57). The tasks of D104 stayed the same from
run to run while sentences of the first screen were written to answer
their frictions, so the runs measured a page fitted to its test; the
measurements behind D131 to D141 ran on fresh sets, from a scratchpad
that would not outlive its session.
Set aside. A page condition written as a copy beside the catalog, which
drifts from the page the tree prints; a run graded by the tree of its
own time alone, which a later checkout cannot reproduce without that
tree; and the transcripts of the children kept whole, where the calls
and their answers carry what a reading needs.
Replaces in part [D104], whose fixed tasks remain the reading test of
the first screen and no longer its measure.
