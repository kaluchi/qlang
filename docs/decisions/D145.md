# D145 · A soft read of null is null

Domain. Language.
Decision. `at` resides on `::null` and answers null whatever the place,
so soft reads chain: `{:a null} | at :a | at :b` is null, and a
`coalesce` after the chain gives its fallback once,
`at :assignee | at :login | coalesce "unassigned"`. The strict
projection keeps refusing null as it refuses every value without parts,
`null | /k` answering `::ProjectionSubjectNotProjectableError`, so a
reader picks the strict or the soft reading of a path by its spelling,
as before.
Source. «да делай» (maintainer, 2026-10-03 19:59, session 87118b06), on
the proposal that a soft read of the absent value be absent, as
`(get nil :k)` in Clojure and `null | .a` in jq answer. Clean children
wrote such chains, `at :assignee | at :login | coalesce "unassigned"`
among them, and a soft read whose subject was null answered
`::VerbWithoutBodyError`, since no residence of `at` served null.
Set aside. Null read softly by every verb of containers, which would
let `null | count` answer where a reader asked of a missing container;
and the strict projection answering null on null, which would erase the
one spelling that says a part must be there.
