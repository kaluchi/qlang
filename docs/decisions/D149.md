# D149 · A page shows its laws as their author wrote them

Domain. Language.
Decision. `content` writes each quote of a doc in the text its literal
spelled, which reads back as the same steps, and prints only a quote
assembled from data, which has no text of its own. The first page read
by `::qlang | doc | content` shows `~({"a": 1, "b": [true, null]} | eq
{:a 1 :b [true null]})` as written, where the printer had made both
sides one map and the law that shows JSON pasting in said nothing. The
first page also names `avg` among the soft reads, says that a pipeline
inside a literal stands in parentheses as a command with modifiers
does, and that `parseJson` reads a number or any JSON out of text.
Source. «ок, предыдущая итерация выдала весьма полезные дополнения и
замечания .. может снова повторить?» (maintainer, 2026-10-03 21:11,
session 87118b06). Two clean Sonnets, each after solving a fresh set and
reading the core, reported that the page they were given differed from
its source in its laws, the JSON literals, `* (mul 10)` and `sort ~/n`
among them; the second also missed `avg` among the soft reads and
stumbled on `[[] | first]`.
Set aside. The print of a quote value made to keep its text as well,
which `print` answers as the one spelling a value reads back as.
