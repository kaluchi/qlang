# D15 · A map's elements are its values

Domain. Language.
Decision. A map is a record and a dictionary at once. Its elements are
its values, and its keys are the shape that travels with them: `map`,
`filter`, `sort`, `take`, `drop` and `reverse` act on the values
and keep the keys, the reducers read the values, `keys` answers the
set of keys, and a predicate sees the value alone.
