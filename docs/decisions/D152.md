# D152 · One tree of names: a name is declared by a keyword, and a tag is its address

Domain. Language.
Decision. The names of the language form one tree whose root is `::`,
and every node of it is a binding: a name, its page and its value.
What the node is, its value says: a kind's value is a `::spec~(…)`, a
verb's a `::verb~(…)`, a page alone is a page, and any other value is
data. A declaration names its node by a keyword alone, `:number |~~ … ~~|
::spec~(…)`; a tag name in the place of a declaration's name is refused,
so `::Box []` declares nothing.

A module is a file and a pipeline, and the bindings it declares are
the nodes under one path: a name `:x` declared in the module of the
path `P` is the node `::P/x`. The node `::P` itself is the binding
`P`'s parent module declares, and the module of the path `P` serves
what lies under it, so a name never declares itself. The root binds
the providers, `:qlang` whose page is the first screen, a host its
own, `:jdt`, and the command line its own, `:cli`. The module `qlang`
binds the nouns of the language and the pages of its concepts, each a
binding of the root's module, `::qlang/number` and `::qlang/pipeline`
side by side; the module `qlang/number` declares the verbs of numbers,
`::number/add`, and its refusals, `::number/AddLeftNotNumberError`,
whose names keep their words and gain the path of the module that
declares them. A kind holds its page and its declaration in its
parent's module and its verbs, refusals and members in its own: the
cut that D114 refused falls where every binding falls, the name and
its page with whoever binds it and what lies under it in its own
module, and it is the price of a name that no value declares.

A kind's value is a `::spec~(…)`: its leading declarations are its
fields, or `:payload` with the kind of a payload that is no record, a
`* :name kind` last admitting the keys it does not name, as `::error`
declares; its body, when it has one, is the constructor that computes,
a `::builtin{:impl}` step for a constructor of the host. A kind
without fields and without a body is identity. `spec` answers the
value of a node's binding as it was declared, the head of a verb for
a verb, and computes nothing beside it; `manifest` answers the nodes
under a noun, its kinds, verbs, refusals and pages, so `::vec |
manifest` is what `::vec | spec | /verbs` and `/throws` answered
together. Which place of a verb a refusal guards, and so the refusals
a verb lists, its refusal declares [D46].

A tag name is the address of a node, and reads as a name does,
nearest first: a path whose first segment names a provider is that
provider's, and any other is first the scope's own, a kind the query
declared, then the language's, `::vec` being `::qlang/vec`, and the
address of the language is always one step away, `::qlang/vec`. The
printer writes the language's names and the scope's own short and a
provider's in full, `::jdt/Method`. A keyword names a binding of the
scope where it stands and a key of data, and no module: a module is
reached by its tag, `use ::lib`.

One loader resolves a tag: it walks the path from the root, asks each
provider for the module of each path it meets, runs that module once
in a scope of its own, where its helpers and the implementations its
host hands stay, and answers the node. A literal under a tag, a tag in
the subject's place, an address a step calls, an axis and `use` ask
it alike, so the catalog loads by what a query names and the list of
modules with its order leaves. A tag that no provider knows is a kind
the scope declares implicitly, with no page and no check, and every
axis answers one node, declared or implicit, the same way whatever
asked it first.

nodes of a module out of the tree its noun heads and makes `manifest`
answer the exports of a module apart from the tree of names. A short

module loaded later changes. A keyword with a path as the name of a
module, a second name of what its tag already addresses.
