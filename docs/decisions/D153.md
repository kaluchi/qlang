# D153 · A source of the root is a cell, and a name with a path is an address

Domain. Language.
Decision. What a host loads and what a source declares are two things,
and the language knows only the second. The root is a scope: the one
the host's sources declare, each source a cell of a session run over
the root the sources before it left, the language's first, before the
first step of a reader. A source of the root, a cell of a session and
a query are written alike, and whatever one of them declares the
others declare the same way; a host hands its sources and the
implementations of their verbs [D80], and nothing else of it takes
part in a query.

A name is declared by its keyword, its page in the slot after it and
its value last [D152]. A name with a path declares a node under the
noun its path names before its last name, a noun declared before it,
`:vec/count` under `::vec` and `:jdt/Method/callers` under
`::jdt/Method`, and the tag of a name is its address, `::vec/count`:
the address is the name as it was declared, so the path of a file, a
module and a provider are no part of it, no prefix stands for the
language, and `::number` is the kind the root declares under that
name. A name with a path, written as a step, reads what its address
declared, a verb run and any other value itself. The root holds nouns
and the language's topic, `::qlang`, whose page is the first screen and
whose members are its chapters, `::qlang/values`.

A verb takes the address of its first declaration and resides on the
noun of that address when the noun is a kind, so a value of the kind
finds it by name through the walk of its tags [D72], whoever declared
it; its head names no subject of its own, a head that does being
refused, and it takes its subject as a head that names the kind does,
by the walk of its tags [D156]. A declaration writes into no verb it was handed: a verb no
declaration named yet is succeeded by one of its own over the same code
and scope, and a verb declared before keeps its address, its residence
and its host under any name, so under another kind it is reached by its
address alone. A verb under a noun that is no kind, a host's topic,
serves any value. `::any` and `::tagged`
are kinds whose specs build nothing. The command line declares
`:vec/table` and `:any/@out`, and a reader declares `:Box ::spec~(…)`
and then `:Box/area ::verb~(…)` in the cells after it. A host's verb
ends with `::builtin{}` and calls the implementation the host handed
beside its source under the name it declared, and a `::builtin{:impl …}`
step names a primitive of the core: the root refuses, as it is
declared, a verb ending in `::builtin{}` the host handed nothing for
and an implementation handed for any other name. A `::builtin` step in
a verb or a kind a reader declared is a step [D73].

A bare name reaches, nearest first [D62]: the reader's declaration,
then the verb residing on a kind the walk of the subject reaches, then
the root's name, and last the one verb of the name residing on a kind,
whose head refuses a subject the walk does not bring to its kind
[D156]; a name several kinds
answer has its contract on `::any`, which the walk reaches, and one
that reaches nothing is refused with the addresses where verbs of it
live. The language server answers goto-definition by the same reach.
A step reads the nearest declaration of its name and a tag the root's
node of it first, so a reader's `:vec 5` stands over the bare name
`vec` and `::vec` stays the root's kind; a source declares no name the
root holds, bare or with a path, a refusal naming the name, and a
reader no node under a path the root holds, so it extends a noun of the
root and replaces none of its nodes, the way a tag over a value, and no
declaration, changes what a name finds for it. A name is declared once
in its scope [D71]. A reader's own nouns follow the scope: a cell after
it declares `:Box/area` again. `env` answers the names of the scope,
those of one segment, the nouns of the root among them, and `manifest`
the nodes declared one name under a noun. A binding records its
`:origin`, the source or the cell it was read from, which is the one
place where what loaded a name shows. The root sits beneath the frame
of a reader's names under a key no name spells, so a declaration
copies the frame alone.

One address is no name as it was declared. The tag a refusal of the
host answers by is found by the last name of its class, process wide,
until its site names its address [D46], so a source of the root that
declares a refusal under a second address is refused, and the next
branch on the errors deletes that registry with the exception.

The verb `use` leaves the language: a reader names nothing to load, the
host's sources are the root, and a map's entries brought in as names
are a declaration spelled a second way, whose names a reader learns
only by running it. A helper of one verb lives in the group of its
declaration, `:f (:h 2 | ::verb~(mul h))`, which closes over it; a
helper several verbs share is a node under their noun. The language
lists its sources once, `LANGUAGE_SOURCES` in
`core/src/runtime/bootstrap.mjs`, which the bundle of the site and the
language server read, and every source is read whole when the runtime
starts, since the contracts, the refusals that name where a verb lives
and the names a guess is held against read every kind.

Set aside. A file that declares the node of its own path, by its
leading doc and its last value, by a reserved name such as `:doc`, or
by a doc of its own form: each needs a slot for the file itself, the
artifact of `__init__.py`, `package-info.java` and `mod.rs`, and a doc
before a declaration is refused [D83]. A later source overriding an
earlier one, which makes the meaning of a name depend on the order the
host loads in, the trap of a library that took `flatten` from a
standard. A search path of providers for bare names, a second order
beside the walk of the subject. Loading a source when a query first
names what it declares, which saves at most the half of the
bootstrap the language's own sources do not need and makes the
contracts and the refusals answer by what was loaded before. A map
read into names at run time, JavaScript's `with`.
