# D153 · A source of the root is a cell, and a name with a path is an address

Domain. Language.
Decision. What a host loads and what a source declares are two things,
and the language knows only the second. The root is a scope: the one
the host's sources declare, each source a cell of a session run over
the root the sources before it left, the language's first, before the
first step of a reader. A source of the root, a cell of a session and
a query are written alike, and whatever one of them declares the
others declare the same way; a host hands its sources and the
implementations of their words [D80], and nothing else of it takes
part in a query.

A name is declared by its keyword, its page in the slot after it and
its value last [D152]. A name with a path declares a node under the
noun its path names before its last name, a noun declared before it,
`:vec/count` under `::vec`, and the tag of a name is its address,
`::vec/count`: the address is the name as it was declared, so the path
of a file is no part of it, no prefix stands for the language, and
`::number` is the kind the root declares under that name. A name with
a path, written as a step, reads what its address declared, a word run
and any other value itself. The root holds nouns and the language's
topic, `::qlang`, whose page is the first page and whose members are
its chapters, `::qlang/values`.

A word takes the address of its first declaration and resides on the
noun of that address when the noun is a label, so a value of the label
finds it by name through the walk of its tags [D72], whoever declared
it, and it takes its subject by the walk of its tags [D156]. The
command line declares `:vec/table` and `:any/out`, and a reader
declares `:Box |~~ A box. ~~|` and then `:Box/area ~(…)` in the cells
after it. A host's word is `::builtin{}`, which calls the
implementation the host handed beside its source under the name it
declared: the root refuses, as it is declared, a `::builtin{}` the host
handed nothing for and an implementation handed for any other name. A
`::builtin` in a word a reader declared is a step [D73].

A bare name reaches, nearest first [D62]: the reader's declaration,
then the word residing on a label the walk of the subject reaches, then
the one word of the name, which refuses a subject the walk does not
bring to its label [D156], and the root's bare name where no word has
the name; a name that reaches nothing is refused with the addresses
where words of it live. The language server answers goto-definition by
the same reach. A step reads the nearest declaration of its name, and a
tag a label of the root from the root, so a reader's `:vec 5` stands
over the bare name `vec` and `::vec` stays the root's kind; a source
declares no name the root holds, bare or with a path, a refusal naming
the name, and a reader no node under a path the root holds, so it
extends a noun of the root and replaces none of its nodes, the way a
tag over a value, and no declaration, changes what a name finds for it.
A name is declared once in its scope [D71]. A reader's own nouns follow
the scope: a cell after it declares `:Box/area` again. `manifest`
answers the nodes declared one name under a noun. A binding records its
`:origin`, the source or the cell it was read from, which is the one
place where what loaded a name shows. The root sits beneath the frame
of a reader's names under a key no name spells, so a declaration
copies the frame alone.

The verb `use` leaves the language: a reader names nothing to load, the
host's sources are the root, and a map's entries brought in as names
are a declaration spelled a second way, whose names a reader learns
only by running it. A helper several words share is a node under their
noun. The language lists its sources once, `LANGUAGE_SOURCES` in
`core/src/runtime/bootstrap.mjs`, which the bundle of the site and the
language server read, and every source is read whole when the runtime
starts, since the refusals that name where a word lives and the names a
guess is held against read every kind.

Set aside. A file that declares the node of its own path, by its
leading doc and its last value, by a reserved name such as `:doc`, or
by a doc of its own form: each needs a slot for the file itself, the
artifact of `__init__.py`, `package-info.java` and `mod.rs`, and a doc
before a declaration is refused [D83]. A later source overriding an
earlier one, which makes the meaning of a name depend on the order the
host loads in, the trap of a library that took `flatten` from a
standard. A search path of providers for bare names, a second order
beside the walk of the subject. Loading a source when a query first
names what it declares, which saves at most the half of the
bootstrap the language's own sources do not need and makes the
contracts and the refusals answer by what was loaded before. A map
read into names at run time, JavaScript's `with`.
