# D153 · A source of the root is a cell, and a name with a path is an address

Domain. Language.
Decision. What a host loads and what a source declares are two things,
and the language knows only the second. The root is a scope: the one
the host's sources declare, each source a cell of a session run over
the root the sources before it left, the language's first, before the
first step of a reader. A source of the root, a cell of a session and
a query are written alike, and whatever one of them declares the
others declare the same way; a host hands its sources and the
implementations of their verbs [D80], and nothing else of it takes
part in a query.

A name is declared by its keyword, its page in the slot after it and
its value last [D152]. A name with a path declares a node under the
noun the path begins with, `:vec/count` under `::vec`, and the tag of
a name is its address, `::vec/count`: the address is the name as it was
declared, so the path of a file, a module and a provider are no part of
it, no prefix stands for the language, and `::number` is the kind the
root declares under that name. A verb declared under a noun resides on
it, so a value of the kind finds it by name through the walk of its
tags [D72], whoever declared it: the command line declares `:vec/table`
and `:any/@out`, and a reader declares `:Box ::spec~(…)` and then
`:Box/area ::verb~(…)` in the cells after it. The root holds nouns and
the language's topic, `::qlang`, whose page is the first screen and
whose members are its chapters, `::qlang/values`.

A bare name resolves nearest first [D62]: the reader's declaration,
then the verb declared under a kind the walk of the subject reaches,
then the root's name, and last the one verb of the name declared under
a kind, whose head refuses the subject at its place; a name several
kinds answer has its contract on `::any`, which the walk reaches. A
name is declared once in its scope [D71] and an address the root holds
once at all: a second source that declares one is refused as it is
run, and a reader extends a noun of the root and replaces none of its
nodes, the way a tag over a value, and no declaration, changes what a
name finds for it. A reader's own nouns follow the scope: a cell after
it declares `:Box/area` again. `env` answers the names of the scope,
those of one segment, the nouns of the root among them, and `manifest`
the nodes declared one name under a noun. A binding records its
`:origin`, the source or the cell it was read from, which is the one
place where what loaded a name shows.

The verb `use` leaves the language: a reader names nothing to load, the
host's sources are the root, and a map's entries brought in as names
are a declaration spelled a second way, whose names a reader learns
only by running it. A helper of one verb lives in the group of its
declaration, `:f (:h 2 | ::verb~(mul h))`, which closes over it; a
helper several verbs share is a node under their noun. The language
lists its sources once, `LANGUAGE_SOURCES` in
`core/src/runtime/bootstrap.mjs`, and every source is read whole when
the runtime starts, since the contracts, the refusals that name where
a verb lives and the names a guess is held against read every kind.

Set aside. A file that declares the node of its own path, by its
leading doc and its last value, by a reserved name such as `:doc`, or
by a doc of its own form: each needs a slot for the file itself, the
artifact of `__init__.py`, `package-info.java` and `mod.rs`, and a doc
before a declaration is refused [D83]. A later source overriding an
earlier one, which makes the meaning of a name depend on the order the
host loads in, the trap of a library that took `flatten` from a
standard. A search path of providers for bare names, a second order
beside the walk of the subject. Loading a source when a query first
names what it declares, which saves at most the half of the
bootstrap the language's own sources do not need and makes the
contracts and the refusals answer by what was loaded before. A map
read into names at run time, JavaScript's `with`.
