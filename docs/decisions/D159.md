# D159 · A refusal's constant is its address without the slash

Domain. Language.
Decided by. The model, at the maintainer's word to hold the drift
between the implementation and the catalog in code.
Decision. The constant that holds a refusal's class is named by the
refusal's address without its slash, each name capitalised: `number/AddLeftNotNumberError` is held by
`NumberAddLeftNotNumberError`, `call/UnknownNameError` by
`CallUnknownNameError`. A grep for the address finds the declaration,
the page and every case; a grep for the constant finds the declaration
and every throw; and neither name is a part of the other, so a
replacement of one never reaches the other. Every factory of a refusal
and every recording of a site outside one takes the address as a
literal, `'noun/LastNameError'` [D158]. Check (3) of `check:conventions`
refuses an argument that is no such literal and a constant whose name
the address does not give, where it refused a class name without the
suffix `Error`, a check the addresses had left without a match. The six
refusals of a name that `binding`, `source`, `doc`, `spec`, `explain`
and `runLaws` read and find no declaration of keep a tag each, one
throw serving them all: the tag says which verb read the name, at the
price of one more name per verb, and the five pages after the first
point to it.
Source. The maintainer: «я просто мыслю так.. что чем больше
уникальности - тем выше ценность сигнала, банально грепом потом проще
найти одну точку .. чем если бы у нас было по всему коду что-то типа
безликих new Error(msg) .. речь про высокоэнтропийность здесь, она
очень хорошо тебе помогает впоследствии» (2026-10-08 18:18, session
22b934f8), «и здесь только тесты и автоматизированая проверка
конвенций может помочь .. кодом такой дрифт надо удерживать.. в общем
поработай по этой теме» (18:23), and, after the model's pass replaced
the last name of a constant inside the addresses that held it, «вот
видишь, а если бы использовались более уникальные имена .. .то замена
грепом бы работала.. и не цепляла лишнего» (18:30). The rule is the
model's.
Set aside. Constants named by the last name, which collide where one
module declares refusals of several nouns, `ReadBackDiffersError`
seven times, and which a word of an address contains. One refusal for
the six readers of a name, which the model proposed and the
maintainer's measure of a signal weighs against.
