# D163 · The seed is a table of contents, never a summary of the tree

Domain. Work.
Decided by. The maintainer.
Decision. The instruction file of a repository holds what the
repository itself does not: how the project is built, how the work
moves, which resources outside the tree belong to it, and pointers to
further context, as a table of contents. It holds no summary of the
source; what the tree holds and how its parts relate the model
computes from the tree, which keeps it current where a summary goes
stale. The language is held to the same test: a model without trained
knowledge of qlang reads it from what qlang says about itself, which
shows whether the language is plain or a crutch on a crutch.
Source. The maintainer, on the seed every scenario starts from, the web
page a server dictates to a browser, a coffee machine an agent speaks
for, a bottle's code that opens a consultant: «claude.md в репозитории
это постоянно протухающая свалка самаризаций о репозитории, туда если и
вставлять то какое-то оглавление», «а то что в репе есть и как связано
- модель сама в состоянии вычислить - и это будет актуально, в отличии
от мусора в claude» and «пока без вшитых знаний у нас хороший шанс
проверить - понятен ли язык на самом деле или же там костыль на
костыле» (2026-10-08 23:30, session 22b934f8).
Set aside. Retelling the code, its files and their roles, in the
instruction file.
Requirements. `CLAUDE.md` holds how the project is built, how the work
moves, the resources outside the tree and pointers into it, and no
summary of the source: its reading tiers name files by what a session
reads them for, without retelling what they hold.
