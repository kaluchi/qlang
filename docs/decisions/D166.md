# D166 · The mechanics of names under a label, parts of an object, laws, defaults and the vocabulary

Domain. Language.
Decided by. The model, working out the mechanics of [D164] and [D165]
from the prototype the research of the legend keeps.
Decision. A label is declared by its page, `:Box |~~ … ~~|`: a node
whose value is a page is a label, a value put under it keeps every law
its page holds under `::holds`, each run on the value under the label,
and a value that breaks one is refused under the label's address. A
name declared under a label whose value is a quote resides on the label
and runs on its value when a step names it, resolving its names through
the labels of its subject and the tree of names as it stands, so the
names under one label see each other whatever their order. A call that
names it with modifiers builds its object, the values of the modifiers,
each computed against the subject, as a vector under the name's
address; each name declared under that address is a part, a quote read
from the object, checked by the laws of its own page and bound by its
name in the body, and the whole object is bound as `object`. A part
read with a default reads it softly with the default as a value that
never runs, `~(at 0 0)`, `~(at 2 ~())`, `~(/0 | at :note "")`, so `at`
takes a default for a place it does not find, and a null the call gives
stays null for the laws to judge. A part that reads the whole object or
its tail takes any number of values; the parts that read places alone
read as many values as the places, and an object with more is refused
under the address of the call's name, the refusal naming the form that
fits [D165]. A word several kinds answer declares its parts once, under
its contract on any value, and each kind holds its primitive. A refusal
is named by the address of what refused, a part's law under the part,
`::Box/put/weight/HoldsNotMetError`, a primitive's own under the name
of its call. That the answer of a call goes back under the subject's
labels is marked on the call's page, `::keeps~()`; `:returns` with a
kind leaves. A bare name the reader declares takes no word of the
vocabulary, the name of a verb or of a name under a label, and is
refused where it is declared with the addresses of the word.
Source. The model, in the session of D164: the prototype in a worktree
of `e283af3`, whose patch and files `docs/research/legend/` keeps, ran
each rule. `[1] | at 2 | coalesce ~()` answered `null`, since
`coalesce` runs a quote it is given, and `[null] | at 0 | coalesce 7`
answered `7`, a given null taken for a missing one, which is why a
default is a value `at` holds. `:filter 5 | [1 2 3] | filter ~(gt 1)`
was refused and `:first 9 | {:a [1 2]} | /a | first` answered `9`,
which is why a reader's bare name takes no word of the vocabulary.
Set aside. A default through `coalesce`, which runs a quote and skips
an error. A name under a label resolving in the scope it was declared
in, under which the first host source of the prototype read a label
declared after it as unknown. The answer re-minted under the subject's
labels whenever it has the payload's shape, which turns the first
vector of a vector of vectors into a value of the subject's label.
Requirements. `::Box[0 2 3 4]` is refused under `::Box` when the page
holds `::holds~(length | gt 0)`. `::Box[1 2 3 4] | put "x"` is refused
as `::Box/put/weight/HoldsNotMetError`. `[] | at 0 7` answers `7` and
`[null] | at 0 7` answers `null`. `:filter 5` is refused.
