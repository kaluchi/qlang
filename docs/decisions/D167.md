# D167 · The catalog is written as names: a call computes its modifiers up to the first failure, and a primitive a host declares only as a name

Domain. Language.
Decided by. The model, rewriting the catalog under [D164] and [D165]
and running every rule against its cases.
Decision. Every word of the catalog and of the command line is a name
under the label of its subject. A call computes its modifiers in their
order up to the first that answers a failure, and computes none after
it. A host declares a primitive only as a name under a label, the
recipe of its function, `impl ::builtin{}`, or the value of the name
alone, `:any/x ::builtin{}`: a `::builtin{}` written in a word's recipe
is the value it is [D34],
and an implementation handed for a word or for a `::builtin{}` under no
label is refused; the registry of the refusals of places leaves. An
anchor reads the name under its subject's address first, and a path of
anchors each name under the address the anchor before it reached.
Source. The model, in the session after D164: the catalog converted by
script from the heads of `725c0ff`, every case of the suite run after
it.
Set aside. Every modifier computed before an error among them is looked
for, which ran the steps after a failed one.
Replaces in part [D73], under which a `::builtin{:impl}` step called its
primitive only in a verb declared in the module of a noun, and a
descriptor that named the primitive of a verb was refused with
`::BuiltinImplOfVerbError`.
Replaces in part [D77], whose rest named a refused value by its index
from one.
Requirements. A host source declaring `:shout ::builtin{}`, under no
label, with an implementation is refused. `::vec | doc [:take :count]`
answers the page of `::vec/take/count`. A call whose modifier answers a
failure computes no modifier after it.
Pruned of what [D168], [D169], [D173], [D220], [D223], [D234], [D248],
[D253] took.
