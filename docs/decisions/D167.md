# D167 · The catalog is written as names: a part that takes code, a place the evaluator reads, and a primitive a host declares only as a name

Domain. Language.
Decided by. The model, rewriting the catalog under [D164], [D165] and
[D166] and running every rule against its cases.
Decision. Every word of the catalog and of the command line is a name
under the label of its subject, a host's primitive or a quote, and the
parts of its args are names under it. `is` answers whether the walk of
a value's tags reaches one of the kinds; an invariant of one step
`is ::k …` is that walk, which hands a part on as the value of the kind
it reached, and a part whose invariant asks for a quote takes code, as
does each element of the part that reads the args whole, `~(/)`; a
selector that reads from the end or computes is code over the args. An
invariant `every ~(is ::k …)` is the walk of each element: it refuses
naming the element's kind and its index from zero, the args being a
value as any vector [D164], and hands a vector on as the vector of the
values of the kinds the walks reached and a set as the set of them, a
quote and a doc, whose elements are steps and segments, as they are; a
part is handed by the first of its invariants that asks for kinds. A
call computes its modifiers up to the first that answers a failure;
where a part that asks for code reads that place, by an invariant `is`
of a quote or, for the part that reads the args whole,
`every ~(is …)` of one, the part refuses the error as its value, so
`filter /active` names the quote it wanted, and anywhere else the
failure is the answer. A place is a whole number: a selector of one
step that reads one, `~(/0)` or `~(at 1 null)`, is read by the
evaluator itself as `at` reads it, so `at` reads its own parts;
`~(/0/k)` counts its first place, and any other selector, `~(/-1)`
among them, runs over the args. A quote's parts are bound by their
names in its body. A host declares a primitive only as a name under a
label, `:any/x ::builtin{}`: a `::builtin{}` in a word is a step [D73],
and an implementation handed for a word or for a `::builtin{}` under no
label is refused; the registry of the refusals of places leaves. An
anchor reads the name under its subject's address first, and a path of
anchors each name under the address the anchor before it reached.
Source. The model, in the session after D164: the catalog converted by
script from the heads of `725c0ff`, every case of the suite run after
it. A law `:default #[::any ::null]` read as `isA ::null` refused `[1 2]
| at 5 0`, which is why a set of kinds with `::any` among them writes
no law. `~(mul 2) | eq ~(mul 2)` answered false while every quote was
closed into code, which is why only a part that asks for a quote takes
code. `[3 1 2] | sort` ran past the depth budget while `at`'s own default
read `~(at 1)`, which is why a place is read by the evaluator, and the
law of `isA`'s own part, `count | gt 0`, called `gt`, whose part asked
`isA`, which is why the law of one step `isA` is the walk. `~(/0 | div
0)` answered the place and dropped the division while every selector
that began with a place was read as one, which is why only a selector of
one step is. `:any/quiet ~(@out)` was declared without its mark.
Set aside. Each quote closed into code whatever the part's invariant. A
place read by calling `at` on the args. Every modifier computed before
an error among them is looked for, which ran the steps after a failed
one. Every selector that reads no place taken as the args', which closed
into code the elements of a part `~(/-1)` read. The values of the args
counted from one, as [D77] counted the rest of a head, which the args as
a value replace.
Replaces in part [D77], whose rest named a refused value by its index
from one.
Requirements. `[1 2] | at 5 0` answers `0`. `~(mul 2) | eq ~(mul 2)`
answers true. `5 | apply /nope !| [type /actualType]` answers
`[::any/apply/code/HoldsNotMetError ::proj/SubjectNotProjectableError]`.
`:Box |~~ B ~~| | :Box/half |~~ Half. ::holds~(isA ::string) ~~| ~(/0 |
div 2) | ::Box[4] | half !| type` answers
`::Box/half/HoldsNotMetError`. `:any/quiet ~(@out) !| type` answers
`::bind/EffectMarkMissingError`. A host source declaring `:shout
::verb~(::builtin{})` or `:shout ::builtin{}` with an implementation is
refused. `5 | cond true ~("yes") !| [type /index /actualType]` answers
`[::any/cond/clauses/HoldsNotMetError 0 ::boolean]`. `5 | add
::Width(2)` answers `7`. `::any/take | manifest` answers
`#[::any/take/count]`, and `::map/at | manifest` answers
`#[::map/at/key]`. `:any/f ~(1) | :any/f/n ~(/0 | @out) !| type`
answers `::bind/EffectMarkMissingError`.
