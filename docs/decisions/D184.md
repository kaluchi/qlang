# D184 · An error a host prints is an alert: the subject where it arose an excerpt, each subject it passed a marker

Domain. Host.
Decided by. The model, at the maintainer's word that elision is the
repair of a failure printed whole and that the model works it out.
Decision. A host shows an error as an alert: its tag and its facts in
the order the catalog declares them, the data the error carries cut to
what places the failure, while a value it answers still prints whole
[D120]. The subject of the first stop of the trail, where the failure
arose, and every other fact print within an excerpt of three hundred
characters each, cut as `elide` cuts a value, a string past the excerpt
giving way whole with its head. The subject of every later stop, which
the failure only passed, gives way whole to an `::elision` marker where
the marker prints shorter. An error among the facts is an alert in its
turn, and a value an alert already shows gives way whole the second
time. Every marker's `:read` continues the query beneath `!|`, `!|
/trail/1/subject`, and `!| /actualValue !| /trail/1/subject` for an error
among the facts, so the error stays whole in the language and each part
of it one projection away. A budget asked for, `--budget=N`, applies over
the alert. The command line prints an error so in script mode, under
JSON and in the REPL, and the first page says it before an answer meets
a marker. Over the thirty failing final queries the runs of [D181]
recorded on set T, the alerts print about a third of the characters the
errors printed whole.
Source. «а проблема известная .. и для этого и нужен elide -  но вот
какой - непонятно .. я бы первым делом actualValue срезал или ещё как ..
я не смотрел просто как ты там реализовывал все» (maintainer,
2026-10-10 21:05, session 22b934f8), after the model measured a failing
query of the benchmark printing its error at nearly twice the size of
its input, every stop of its trail holding its whole subject; and «ок,
главное что ты понял в чем дело -- дальше сам с elide разбирайся»
(21:14). The rule, the excerpt and the order are the model's.
Set aside. A budget the host applies to an error unasked, by size, the
thousand characters of [D109], which [D120] set aside: it cuts the
largest part first, keeping half of a subject the reader holds and
cutting the record where the failure arose. Cutting `actualValue`
whole: it is left out already where it is the subject of the first stop
[D85], [D172], and where it stays it is the value refused, such as the
failure a modifier computed at the call, whose tag names the cause.
Dropping the subjects from the trail, which would leave a part no
projection reads back [D85].
Replaces in part [D120], under which the command line printed an error
whole unless a budget was asked for.
Replaced in part by [D210], under which an error at rest among the
facts of an alert is a value cut within its excerpt.
Requirements. `elideAnswer` without a budget answers a value as it is
and an error as its alert, whose markers' reads answer the parts they
stand for; the command line and the REPL print an error as its alert.
