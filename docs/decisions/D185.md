# D185 · The first page tells the language whole, in the order its parts rest on each other, in base forms, the argument model one rule

Domain. Language.
Decided by. The model, at the maintainer's word that the first page is
redone whole, teaches the base forms and no shortcut, and says how code
is handed to a word; he read the page and left it to the benchmark.
Decision. The first page, `::qlang | doc`, tells the language as one
picture in the order its parts rest on each other: the pipe, values and
their kinds, reading parts, commands, code, building answers, names,
elements and order, conditions, text, failures, asking, a worked task,
and the chapters. Each section says its rule once with an example whose
answer it states, and every example runs as the page writes it. The
argument model is one rule: every modifier is computed once, at the
call, against the subject of the step, and a quote computes to itself,
so a word receives code unrun and runs it where it needs; `map` runs its
code on each element beside `filter`, `sort`, `groupBy` and `reduce`, and
`[{:n 1}] | map /n` is told as the modifier read from the vector itself
and refused. Code is written in its base form alone, `~(…)`, never `~name`
or `~/k`. A rule stands in the section it rules, not in a list of
invariants ahead of the words it speaks of; the words of a kind are
found by `manifest`, not listed; a name is read back by its bare word,
its keyword staying a keyword; a part read strictly fails where it is
missing while `at` reads softly; the conditions of `allOf`, being
modifiers, are all computed at the call; and `keyword` turns a keyword
and a string into each other. Kinds of one's own, invariants,
args, failure literals, the links and snippets of a page, comments and
the lines of a query joined at the top level are left to the chapters.
The page prints about three quarters of the characters of the page it
replaces. Its measurement on set T against [D184] speaks for the page and
for the model's reading of the misses of set T before writing it alike,
since the misses of [D181] showed the readings the page corrects. The
page first measured had dropped the sentence on `keyword`, and its
children spent calls finding how a keyword becomes text; the page holds
it, and the second measurement states that reason [D183].

which speaks of words a reader has not met. The lists of the words of

Replaces in part [D131], whose page opened on the invariants and listed

Requirements. Every example the first page states the answer of answers
it as the page writes it, the task over the input the page gives; the
page writes code in its base form alone; and the rules it tells hold:
a modifier read from the subject of its step, code without its quote
read from the whole subject, a name read back by its bare word, every
condition of `allOf` computed at the call.
