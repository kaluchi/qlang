# D198 · A keyword that `join`, `append` and `prepend` write into text is its name

Domain. Language.
Decided by. The model, at the maintainer's word on what the children of
the benchmark stumbled on and on the goals it chooses itself.
Decision. Where `join`, `append` and `prepend` write a value into text,
a keyword is written as its name, as the JSON channel writes it
[D148]: an element and the separator of `join`, the suffix of `append`
and the prefix of `prepend` on a string, so `{:host "x"} | entries |
map ~(join "=")` answers `["host=x"]` and `"x" | append :a` answers
`"xa"`. Their refusals name the two kinds they take,
`vec/join/ElementNotStringOrKeywordError`,
`vec/join/separator/NotStringOrKeywordError`,
`string/append/suffix/NotStringOrKeywordError` and
`string/prepend/prefix/NotStringOrKeywordError`, and their pages send a
value of another kind to `print`. A word that reads text, `endsWith`,
`contains`, `split`, refuses a keyword, and a verb of strings refuses a
keyword for its subject [D139]: the page of
`call/KindAnswersNoVerbError` names the turn, `:host | keyword | append
":80"`.
Source. The calls of every run on set T, read for it: the children
joined the pairs of a map's entries, `[/0 "@" /1] | join ""`, whose key
is a keyword, and were refused five times as
`vec/join/ElementNotStringError`, whose page sent them to `map ~print`,
which writes `:a`, so one wrote `/0 | print | drop 1`; six calls more
appended to a key, `/0 | append "@"`. The maintainer's word on them,
«да, давай с этим что-то сделаем .. что-то на старте добавим
переформулируем, а что-то может в языке или ещё где-то реализуем»
(maintainer, 2026-10-11 02:25, session 22b934f8), and on the goals of
the session, «потом по qlang себе ищи задачи сам» (maintainer,
2026-10-11 02:52, session 22b934f8).
Set aside. A number written into text by `join` as its literal, which
no child stumbled on and whose text `print` writes; and the verbs of
strings answering for a keyword subject, which [D139] set aside.
Requirements. `join` writes a keyword element and a keyword separator
as their names, and `append` and `prepend` a keyword as its name; the
laws of the three words hold it, and a case of `join`.
