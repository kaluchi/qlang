# D2 · The effect marker leaves the language: no name begins with `@`, and the words of a host take their plain names

Domain. Language.
Decided by. The maintainer; the purity of constructors, the place of
performance and the letters of a name are the model's.
Decision. The `@` convention, its checks and its flags leave the
language and are not relocated into a host convention: a name is
written in the letters of [QSNAM#letters], a key of a path and a tag
alike, `{"имя": 1} | get /имя` answering `1`, so `@out` does not parse,
and no declaration checks what its
body calls, so a word whose body calls a word of a host is a word like
any other, `:any/quiet ~(out) | 1` answering `1`. The words of the
command line take their plain names: `in` reads standard input, `out`
writes a string as a line of standard output, `err` as a line of
standard error, and `tap` shows a value on standard error halfway
through a query, each an explicit step at the boundary of the host,
performed when it runs; the sister project's words take theirs. The
parser stamps no effect on its tree, the highlighter paints none, the
language server marks none, and the editor's grammar reads `@` as no
letter of a name. A host that wants the provenance of a value visible
tags the value. A tag may describe an effect, a write the host is to
perform, and such a value is performed only by an explicit step at the
host boundary; a tag's constructor is pure, and reading or constructing
a literal performs nothing.

Set aside. The marker as a host naming convention: every `@`-name stays
a different name from its plain twin, reading its document means
remembering the sigil, and the core has no consumer of purity. `@` kept
as a letter of names with no meaning, which leaves every word of a host
a second spelling. A refusal of the parser that names the plain word
where `@` stands, a production of the grammar for a habit no reader of
the pages forms.
Requirements. The cases that name this record: a word calls a word of a
host with no mark; the command line's words answer
under their plain names.
