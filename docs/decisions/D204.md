# D204 · The REPL gathers a paste over chunks and reads Alt+Enter in both spellings

Domain. Command line.
Decided by. The model, on the goals the maintainer left it to choose.
Decision. In a terminal the line editor of the REPL reads a chunk of one
character, or one that begins with an escape, as keys, and any other
chunk as text. Text whose first line feed is not its last character
starts the gathering of a paste that a host hands over in several chunks
with no brackets around it, unless a bracketed paste or an escape
sequence is under way; each chunk of text that arrives within the window
`PASTE_FLUSH_MS` after the last joins it; and the paste lands at the
cursor as one, its line breaks kept, and waits for a submit, so a reader
extends it before it runs. Keys end the gathering and are read as the
keys they are: an arrow moves the cursor, Alt+Enter submits the paste,
and Enter, a carriage return handed over alone, submits. A bracketed
paste is read up to its end marker, whatever chunks carry it and however
long they take. An escape pending alone before text that does not begin
with `[` is the Escape key, which does nothing, so a paste after it
gathers, and before `[` it opens a sequence split after its escape,
which stays one key. ESC then CR and ESC then LF are both Alt+Enter,
which submits as Enter does.
Source. d5b93889 made the gathering for the paste its message says the
user reported, a clipboard paste that PowerShell on Windows handed over
in many small chunks, where a chunk with no line feed fell to the
reading of keys and each carriage return of a CRLF in it submitted a
half-formed cell, and set its window above the gaps between the chunks
of one paste and below the time a reader takes between two keys.

Set aside. Bracketed paste alone, under which a host that sends no
brackets around a paste, though the editor asks for them, hands each
carriage return of the paste over as Enter; a gathering that a chunk of
one character joins, under which Enter pressed within the window after a
paste would join it as a line break; a gathering that a chunk beginning
with an escape starts or joins, under which a key read with it lands as
text and a bracketed paste is cut by a pause; and one spelling of
Alt+Enter, under which the other is dropped with nothing done.
Requirements. A paste a host hands over in chunks lands as one; a chunk
of one character ends the gathering, Enter, a carriage return handed
over alone, submitting; an arrow and Alt+Enter end it and act; a chunk
that begins with an escape is read as keys, a line feed in it among
them; a bracketed paste lands whole across a pause past the window; a
paste after the Escape key gathers; an escape sequence split after its
escape stays one key, a begin marker among them; and both spellings of
Alt+Enter submit; the tests of the line editor hold each.
