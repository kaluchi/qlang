# D204 · The REPL gathers a paste over chunks and reads Alt+Enter in both spellings

Domain. Command line.
Decided by. The model, on the goals the maintainer left it to choose.
Decision. In a terminal the line editor of the REPL gathers a paste that
a host hands over in several chunks with no brackets around it. A chunk
longer than one character whose first line break is not its last
character starts the gathering, unless a bracketed paste or an escape
sequence is under way; each chunk of several characters that begins with
no escape and arrives within the window `PASTE_FLUSH_MS` after the last
joins it; and the paste lands at the cursor as one, its line breaks
kept, and waits for a submit, so a reader extends it before it runs. A
key, a chunk of one character or one that begins with an escape, ends
the gathering and is read as the key it is: an arrow moves the cursor,
Alt+Enter submits the paste, and a line break handed over alone submits
as Enter does. An escape pending alone before a chunk of several
characters that does not begin with `[` is the Escape key, which does
nothing, so a paste after it gathers. ESC then CR and ESC then LF are
both Alt+Enter, which submits as Enter does.
Source. d5b93889 made the gathering for the paste its message says the
user reported, a clipboard paste that PowerShell on Windows handed over
in many small chunks, where a chunk with no line feed fell to the
reading of keys and each carriage return of a CRLF in it submitted a
half-formed cell, and set its window above the gaps between the chunks
of one paste and below the time a reader takes between two keys.
b314edff read Alt+Enter in both spellings, since some terminals send ESC
then CR and others ESC then LF, as the submit for a host that keeps
Ctrl+Enter, the submit of its key map, for itself; 5f40a15d gave Enter
the submit and Ctrl+Enter and Ctrl+J the line break, which answers that
host with Enter, and kept Alt+Enter as a second key that submits.

these reasons. The fifth review of the series of 2026-10-11 asked that

the seventh finding), and the sixth found the record wider than the code

(`docs/research/reviews/2026-10-11-the-gathering-of-a-paste.md`, the
first two findings). The maintainer's word on the goals of the session,
«потом по qlang себе ищи задачи сам» (maintainer, 2026-10-11 02:52,

Set aside. Bracketed paste alone, under which a host that sends no
brackets around a paste, though the editor asks for them, hands each
carriage return of the paste over as Enter; a gathering that a chunk of
one character joins, under which Enter pressed within the window after a
paste would join it as a line break; and one spelling of Alt+Enter,
under which the other is dropped with nothing done.
Requirements. A paste a host hands over in chunks lands as one; a chunk
of one character ends the gathering, a line break handed over alone
submitting; an arrow and Alt+Enter end it and act; a paste after the
Escape key gathers; and both spellings of Alt+Enter submit; the tests of
the line editor hold each.
