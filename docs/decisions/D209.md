# D209 · An error no step raised holds no trail

Domain. Language.
Decided by. The maintainer, on the reading the model laid out to him.
Decision. An error holds the facts of its site and, from the first step
that raised it or handed it on, its path under `:trail`; an error no
step has raised or handed on, one an error literal writes into a
container among them, holds no `:trail`, and an error literal or a map
raised that writes an empty `:trail` holds none either. Its literal and
the descriptor `!|` opens print alike, `[!{:a 1}]` and `::error{:a 1}`,
the printer writing an error's facts and its path as it holds them. The
verb `trail` answers the path, `[]` for an error that holds none, while
`/trail` reads the key and is refused where there is none. A map that
writes its `:trail`, an empty one among them, resumes that path when
raised, so the ring of atoms writes the path of an error it takes apart,
an empty one among them, and builds the error back as it was.
Source. The fifth milestone asked that `:trail` print the same way on an
error value and on its materialized descriptor, where the literal hid an
empty trail and the descriptor showed it, and the audit laid out three
ways among its open questions: the literal writing the empty path, the
descriptor holding none, or the two as they stood. The model recommended
the second: «ок, давай как ты рекомендуешь .. а это сложно сделать?»
(maintainer, 2026-10-11 14:49, session 22b934f8).
Set aside. The literal writing an empty path, `[!{:a 1 :trail []}]`, a
key in the print of every error a reader writes in a container and a
print unlike its source; the printer hiding an empty `:trail` in a map,
which would print a descriptor as a text that reads back as another map;
and the two as they stood, which left the line of the milestone unmet.
Replaces in part [D85], under which the step of an error literal held an
empty `:trail` where the literal wrote none.
Requirements. The cases of D209 in
`core/test/conformance/19-error-values.jsonl`: an error no step raised
prints without a trail as its descriptor does, holds its facts alone,
answers `trail` with `[]` and refuses `/trail`; a raised error holds its
path; and a literal that writes an empty trail holds none.
