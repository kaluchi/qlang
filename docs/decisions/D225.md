# D225 · Every record is held against each new baseline, and the code and the cases cite only what is in force

Domain. Process.
Decided by. The maintainer.
Decision. A record is held against the tree of every new baseline of
the audit, critically: one whose form the language has left is closed
rather than carried out in the form it was written in, one a newer
record contradicts is closed, and an idea or an intention is no
decision and no requirement. The move to a new baseline is stricter,
more critical and regular, by a criterion the model finds [D226], a
clean desk: however a shift left the work, the next one starts in
order. The
source code and the conformance cases cite only the decisions in force
now, and none that was replaced, set aside or never decided, not even
to say what the code does not do; a record holds as many such sayings
as it needs; and a page of the catalog, the public interface of the
language, cites no record, the records a source exists for named in the
comment above its pages [D237].
