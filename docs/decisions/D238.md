Decision. The language and its tooling live in one repository as npm
workspaces, each folder the suffix of its package under the `@kaluchi/`
scope: `core` the language, `cli` the command line and its REPL, `lsp`
the language server, `site` the site, private, and `vscode` the
extension of the editor; `npm install` at the root links them. The core
is pure JavaScript with no dependency at runtime and no `node:*` import
under `core/src/`, since it ships to a browser, to Deno and to Bun, which
`eslint.config.mjs` holds. The catalog under `core/lib/qlang/` is read
at runtime through the `imports` of the core's `package.json`, under
`#qlang/load-source`: `core/src/load-source-web.mjs` in a browser, Deno
and Bun, `core/host/load-source-node.mjs` under Node. The parser is
built from `core/src/grammar.peggy` by `core/scripts/build-grammar.mjs`,
`npm run build`. A workspace depends on a sibling by the range `^x.y.z`
of the sibling's version, which `scripts/workspace-manifests.mjs` writes
and `check:conventions` holds, so a consumer resolves one core. The root
of the core's package, `core/src/index.mjs`, exports what the command
line, the language server, the site and the sister project read.
