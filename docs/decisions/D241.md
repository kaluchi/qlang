Decision. `cli/src/bin.mjs` is the one file of the command line that
touches `process`: it hands the arguments and the streams to `main.mjs`
and exits with the code `main` resolves, so every branch worth covering
lives where a test reaches it. The REPL paints what it prints by
`cli/src/highlight-ansi.mjs`, a layer of colour over the core's
`tokenize`. The language server runs over stdio and answers `initialize`
with its capabilities, which `lsp/test/server.test.mjs` holds; the
extension of the editor, `vscode/src/extension.js`, launches it and is
published to the Marketplace. The site is built by Astro,
`site/astro.config.mjs`, its examples split into prompts, answers and
comments by `site/src/lib/format-example.js` and painted by
`site/src/lib/qlang-highlight.js` from what the core's parser reads.
