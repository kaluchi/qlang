# D250 · A path is written by `put`, `update` and `delete`, followed as `get` follows it

Domain. Language.
Decided by. The maintainer, that a value is written by its path as it is
read; the words, their strictness and the tags laid again are the
model's.
Decision. `put /a/b v` answers the subject with `v` laid at the path: a
key the last map on the path lacks is added, and a key it holds or a
place a vector holds is replaced, `{:a {:b 1}} | put /a/c 2` answering
`{:a {:b 1 :c 2}}`. `update /a/b ~(add 1)` lays anew the part at the path
by what its code answers for it, the code a quote or a path, and an
error the code answers is the answer. `delete /a/b` takes the part out, a
key from a map or a place from a vector, the elements after it moving
up. Each follows the path as `get` follows it [D248]: a key or a place
missing on the way is refused there, `::path/KeyNotInMapError` with the
path in `:path`, and for `update` and `delete` the part itself must be
there; a vector grows by `append` and keys that may be absent leave a map
by `minus`. A key is the path of one segment, `put :a 1`. Every container
on the way is built again and laid under the tags it stood under, their
constructors and invariants run as `within` runs them, so a set is
ordered again and a value that breaks the invariant of its tag is
refused under it.
Source. «1 сам реши как лучше с прайорами состыковать .. minus может быть
не самое лучшее есть же дроп какой-то ты сам предлагал .. изначально»
(maintainer, 2026-10-13 04:12, session d65e4c1d), on the model's finding
that the value read as a file system had no word that writes it, and
«(put/update/delete)  делай» (04:40), on the names the model chose. `get`,
`put` and `delete` are the verbs of HTTP over a path, which `get` took
its prior from, and `delete obj.a` deletes a field in JavaScript;
`update` is the word of Clojure and lodash for a part laid anew by a
function.
Set aside. `drop /a/b`: `drop` counts the elements a vector leaves out,
`drop 1`, and the word of a vector answers a vector before a word of
`::any` does, so `drop /1` would never reach it, and beside `drop 1` it
would read as the place taken out. `minus /a/b`, the word of a map that
takes keys and sets of them. `set`, the name of a kind. Maps built on
the way where a key is missing, as Clojure's `assoc-in` builds them,
which build a branch out of a misspelled key in silence. A place past
the end of a vector that `put` appends to, a second spelling of
`append`. `delete` of a key that is not there answering the subject, as
JavaScript's does, which hides a misspelled key.
Rests on [D248], under which a path is a value the word that takes it
reads, and [D30], under which every value a write answers prints as the
literal that reads back.
Requirements. The cases that name D250 in
`core/test/conformance/45-a-path-is-written.jsonl`, and the laws of
`put`, `update` and `delete`.
