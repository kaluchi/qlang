# D257 · Open: the value as a file system

Domain. Language.
Question. A path that is a value makes any value a tree a query lists,
reads and writes [D248], [D250], `paths` its outline, and what that
opens beyond them is intention, no decision. The outline with the kind
at each path is a schema inferred from the data, against which a query
writes the rest of its pipeline without reading the data: «оглавление -
бесплатная выведенная схема для всего, прям уф .. .. это не заглядывая в
данные можно смело писать дальше пайплайн..» (maintainer, 2026-10-13
01:24, session d65e4c1d). A set of paths is a mask: `delete` takes a
part out by its path [D250], a mask of several would take them out at
once, and `elide` shows a selection and leaves at the path of each part
it left out a marker, the budget a selection the reader names, in
characters or, once a host counts them, in tokens, «элайд как такая
форма решейпинга/вымывания .. хотите в символах .. а если дойдут
когда-то руки до подключения токенайзера - то даже в токенах все можно
посчитать и сообщить..» (01:24). An alert prints the path of the
culprit, `:at`, where it prints an excerpt of the subject [D7]. A set of
paths under `get` selects with the nesting kept, the selection set of
GraphQL. The strings of the data that write JSON Pointer, `$ref` and
`href`, are followed as links. And a path takes the wildcard, `//` and
`..`, for which the grammar keeps signs to spare. Each waits on a task
that asks for it.
Source. The work of [D248] and [D250], and the maintainer's words the
question quotes; the audit held it in its open chapter from 13 October
2026.
Alternatives. Each of them taken alone where a task asks for it, as
[D248] and [D250] took the path, its reads and its writes; or none, the
reads and the writes of a path standing as they are.
