# D259 · Open: mounting a namespace too large to declare

Domain. Language.
Question. The sister project's types are tens of thousands of names,
which no source declares; the intention is that a host serves them on
demand, the way a file server was mounted into a namespace of Plan 9: a
tag no declaration names is asked of the mounted namespaces in order,
the first that knows it answers, and the order of mounting and the rule
of ownership settle any overlap. The core would know nothing about Java,
only how to ask a mounted namespace, and a Java type would be a tag,
written in Java's own spelling, copied from a stack trace and pasted
into a query, its source, its page, its record and its relations read as
any tag's:

```qlang target
> ::app.m8.web.servlet.gwt.orgstructure.functask.ConfirmFtNewEmpHandler | source
```

The slash is accepted inside a tag's name and the dot is not:

```qlang
> ::app/m8/web/Foo | type
::tag

> ::app.m8.web.Foo | type
::quote/ParseError!{ … :found "." … }
```

The dot is unused elsewhere in the grammar, so admitting it inside a
tag's name is local to the grammar, and a quoted form, `::"…"`, mirrors
the quoted keyword and covers what Java allows and an identifier does
not, the `$` of a nested class among them. A tag name is the address of
a name of the root [D153], so a mount is a noun whose names a host
answers on demand, and `manifest` lists them beside the declared nodes
[D61]. A member of a type is a record under the host's tag that points
at its type, `::JdtMethod{:of ::app.m8.Foo :sig "bar(int)"}`, and the
verbs the sister project declares under any value shrink to about a
dozen: the lookups become the tag literal, the accessors of the
containing element fields whose values are tags and therefore links, the
enumerations by scope one verb over any containing node, the relations
one verb beside a few named ones. A namespace is also what an agent
sees: a session, and a sub-agent inside it, is given the namespaces its
task needs, so its focus is built from what it is given. What is open: whether a host needs it before the sister
project's redesign, how a host declares the noun it answers on demand,
and the exact record of a member.
Source. The sister project's types, which no source declares; the audit
held it in its open chapter from its first version.
Alternatives. The dot admitted inside a tag's name, local to the
grammar, or a quoted form, `::"…"`, which mirrors the quoted keyword and
covers what Java allows and an identifier does not; and the mount a noun
whose names a host answers on demand, which `manifest` lists beside the
declared nodes [D61], or the lookups the sister project declares under
any value as they stand.
