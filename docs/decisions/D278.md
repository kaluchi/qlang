# D278 · Code held as data runs in a lane of its own, and a quote written in a step reads the names of that step wherever its call runs it

Domain. Language.
Decided by. The model, on the maintainer's words: the steps of a query as
a past, a current step and a future, the call of a function a lane of its
own whose past is its inputs, and the cost of an open quote whose meaning
is read from a past far from it; his refusal of a quote rewritten where
it is declared; and a word of the host and a word written in the
language answering alike [D200]. The model's: the two codes and the
road the mark of a step takes, the lane of held code and its tree, the
value of the reader withheld there by a refusal of its own, and the
cases; a check of the design by a second model, which found the roads,
the tree of the lane and the withheld value.
Decision. Code a verb runs is code of a step or code held as data.

A quote written in a step, an object of a call or a part of a template
an object writes, is code of that step: it reads the names of the step
that wrote it wherever its call runs it, a word of the host and a word
written in the language alike, by whatever road the word reaches it, an
input that holds it, a name the recipe declares from it, `args`, an
input of the args whole and the objects `apply` hands a function. The
mark of the step rides on the value the call receives, which prints and
compares as the quote it is, and it ends with the call: a quote the call
answers is data again. So `:k 10 | … | [1 2] | w ~(add k)` reads the `k`
of the step that wrote the quote, and a word whose input is named `k`
shadows nothing in it.

Any other code, a quote held in a name, a field, a vector or a page, a
law and a snippet among them, a quote a call answered and the steps a
trail skipped, runs in a lane of its own, as the call of a function
does: its past is the subject it runs on and its tree, the words, the
nodes and the labels of the root and of the reader and the names it
declares itself. A value a reader named is withheld from it: read there,
by a step, by a tag or as the noun of a declaration, it is refused under
its name, `::call/ValueWithheldError`, so it never falls to a word, to a
value of the root of the same name or to a tag no kind answers, while a
tag reads a label of the root before any name of the reader there as it
does anywhere [D153]. The meaning
of held code is its text and the vocabulary, as a literal's is its text
[D279]: a step around a call shadows nothing it reads, a name declared
after it is read by none, and `:big ~(gt lim) | :lim 4 | [1 5 10] | filter big`
is refused under `lim`. A value held code needs is an input of a
function, `apply f [4]`, or written into its code by `fill`, and code
that calls itself is a word, `:number/fact ~(… fact …)`. The
declarations of held code are its tree, which `doc` and `binding` read
there; a recipe's stay out of the tree of the query [D200].

Set aside. The names read where the quote runs, as they were, under
which the meaning of a held quote is read from the past of whatever step
runs it, the cost the maintainer named. A quote that reads a name its
scope does not hold refused where it is declared, which leaves the
shadow around a call. The names bound where the quote is declared,
written into its head as declarations, the hidden rewrite the maintainer
refused. The mark of a step held by the input alone, which a recipe
loses by a name it declares, by `args` and by an input of the args
whole; and a mark that outlives the call, a scope a quote carries that
its print does not show.
Requirements. The cases that name D278 in
`core/test/conformance/20-code-is-a-quote.jsonl`: a held quote refusing a
value of the reader, one named as a word among them; a quote handed to a
word reading the step that wrote it by every road and shadowing no input
of the word; a quote a call answered held again; held code reading its
own declarations; and a tag, an axis and the noun of a declaration in
held code refusing a value of the reader, a label of the root kept.
Replaces in part [D200], code held as data run in the tree of names of
the query; [D251], a quote held in a name, an input or a page run in that
tree, and its recursion by a name.
