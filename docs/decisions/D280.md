# D280 · What the work learns about itself, collected as it goes

Domain. Process.
Decided by. The maintainer: the insights the work meets collected as it
goes and written into a numbered record. The model's: each insight, read
from the work that showed it, and the place of it in the tree.
Decision. The work keeps here what it learned about how it works, each
insight a rule the next session holds, written when the work that showed
it lands, with the place of the tree that shows it:

- A form rewritten by machine is read against the parse the old grammar
  gave. Turning a literal that computed into the template of `get`
  [D279] changed the role of parts the rewrite never touched: a quote or
  a path the literal held as data became code the template runs or a
  path it reads, the glue of the ring of atoms among them
  (`core/test/qlang/atoms.qlang`), and an error literal became a template
  `get` does not enter, its quotes left unrun in the sister project. Each
  part whose role a rewrite changes is found by walking the old parse and
  set by hand.
- The coverage of the gate reads the design, not only the tests. A line
  no case reached was a template laying a tag over a payload its
  constructor never checked (`relaid` in `core/src/runtime/path.mjs`),
  and a branch no case reached was the check of a kind read for an error
  no check answers (`underKind` in `core/src/eval.mjs`).
- A rule the parser holds, it holds in the code of a doc. A refusal
  turned off inside a doc, where a refusal would stop the whole read, let
  a literal that computes stand in a snippet, which ran; a predicate that
  fails the rule reads such a span as prose there and refuses it
  elsewhere (`readsAsLiteral` in `core/src/grammar.peggy`).
- A printer decides a spelling by the kind of the value. A pattern over
  the text of a print copies a rule of the grammar and misreads a print
  a kind writes its own way; the kinds that take `#` after a tag are
  named once, by their kinds (`KINDS_AFTER_HASH` in
  `core/src/runtime/print-value.mjs`).
- A rule is said of what it governs. The `#` of a tagged payload is a
  rule of a literal's first character, a string and a keyword touching a
  tag by their own signs though they are atoms as a number is [D42]; the
  word scalar said it of a kind of value, and the maintainer's question
  of the terms showed it [D279].
- A record written before its code is read again after the last commit
  of its branch. The record of the closed literal stated what a template
  enters, and the gate showed the better reading the same day: a
  container under a tag read and laid back through its constructor
  [D279].
- A design of scope is checked by a second model on counterexamples
  before its record is written, and again when a review moves it. The
  first check of the lane of held code [D278] found three holes the first
  reading had: the roads a quote takes into a recipe beside its input,
  the reader's tree the lane would have kept, and the value that would
  fall silently to a word of its name. The second found every road an
  origin held by an input alone loses.
- What a rule takes from code is withheld by a refusal of its own, never
  hidden: a name a rule takes away and leaves unbound falls to another
  meaning of the name, a word or a value of the root, and answers
  without a word of what happened (`refuseWithheld` in
  `core/src/runtime/nouns.mjs`).
- A fact of a call is kept by the call, never by a value it received. A
  mark of the step put on a copy of the quote rode every road of the
  call, but it was a scope the value carried that its print does not
  show, against the maintainer's word on a hidden env in a quote, and
  the copy dropped the tree the parser read, so every quote of every call
  was printed and parsed again, which the review timed; the origins a call keeps for its run, the nearest call first, give every
  road the step that wrote a quote and leave the quote the value it is
  (`withCall` and `originIn` in `core/src/state.mjs`).
- A fact moved from a value onto a name loses every road the name does
  not take. An origin held by an input alone read the args a word takes
  whole with none of the reader's names, a refusal of correct code or a
  silent fall where the reader named a value as a word
  (`a-word-that-reads-its-args-whole-runs-the-readers-quote-in-its-step`
  in `core/test/conformance/20-code-is-a-quote.jsonl`).
- A refusal of the read of a name holds on every road the name is read
  by. The lane withheld a value of the reader from a step alone, and a
  tag over the name laid itself as a tag of identity, an axis answered
  an unknown name and a declaration under it answered no noun; the roads
  are the callers of the lookup they share, each held by a case
  (`a-tag-in-held-code-reads-no-value-of-the-reader` and its kin in the
  same file).
- A clause copied from the code beside it is held by no case where no
  road reaches it. The guard that a name of a scope holds a record came
  into the lane from the scope a recipe opens, and every road that
  writes a name writes a record, so the guard left both places rather
  than a case inventing a road (`isNodeOrLabel` in `core/src/eval.mjs`).
- The prune of a decision ends with a walk of every record in force
  against the tree, a range to each reader, not with a search of its own
  words: the closed literal [D279] and the lane [D278] each left
  sentences in records they never named, which spoke of the old form in
  the old words.
- A clause is cut in a copy no other runner writes. Two runners that cut
  clauses in one shared folder ran each other's cuts, and a log of cuts
  counts only from a folder of its own runner.
- A cut is read by the name of the test that failed, never by a count. A
  cut that failed one test was twice a test timing out under the runs
  beside it, and the coverage of the gate found the clauses no case
  reached; the runner names the failed tests
  (`a-quote-a-word-of-the-language-opens-reads-the-step-that-wrote-it` in
  `core/test/conformance/20-code-is-a-quote.jsonl` holds the road one of
  them stood for).
