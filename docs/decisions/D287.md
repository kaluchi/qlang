# D287 · The refusal of a holder's kinds is named by its role, the kinds a fact

Domain. Language.
Decided by. The maintainer, between the ways the model laid out, the
name by the role with the kinds as a fact; the name, the fact and the
holders it covers are the model's.

Decision. A value of none of the kinds a holder takes is refused under a
name of the holder's role alone, and the kinds it takes ride the refusal
as the fact `:expected`, a set of tags, beside `:actualType`: an input, a
field and the answer refuse as `…/KindNotTakenError` under their names, a
payload as `…/PayloadKindNotTakenError` and an element of a holder of
each element's kinds as `…/ElementKindNotTakenError`, the payloads of
the core's own kinds among them, `::number/PayloadKindNotTakenError`. A
kind that joins a holder changes no tag a reader's catch, a law or a page
compares with:

```qlang
> {:a 1} | has [1] !| get [~(type) /expected /actualType]
[::map/has/key/KindNotTakenError #[::keyword ::number ::path ::string] ::vec]
```

The subject of a word keeps the name of the label the word resides on,
`…/SubjectNotNumberError`, which the word's address names as well, so it
moves only with the word; and a refusal a primitive names by a role of
its own, `ConditionNotBooleanError`, keeps the name its writer gave it.
Source. The outside audit of the tree `cbaaeb2d`, its finding 3.5,
`docs/research/outside-audit/2026-10-13-cbaaeb2d.md`, “Тег ошибки — это
публичный API (ловушки, законы, документация), а он зависит от деталей
сигнатуры”; «и ещё пока не забыл по поводу
NotKeywordOrNumberOrPathOrStringError - вроде как нам на это указывал
один из ревьюверов раньше... что ошибки часть публичного апи .. а такие
сборные на лету имена очень хрупки при развитии .. у нас этого как-то
записано было? в открытых вопросах или где» (maintainer, 2026-10-14
22:53, session d65e4c1d); and, to three ways laid out, the name as it
stood, one name by the role with the kinds as `:expected`, and a name
the writer gives in the chain, «мне тоже второй вариант» (23:01).
Set aside. The name as it stood, which moves with every change of the
kinds; a name the writer gives in the chain, a name to choose for each
input and a refusal of a chain that names none.
Requirements. The cases that name D287.
