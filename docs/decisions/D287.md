# D287 · Open: the name of the refusal of an input's kinds

Domain. Language.
Question. The refusal of a value no kind of an input takes is named by
the kinds the input takes, joined in their order, `Not` before them and
`Error` after: `#[::null ::path ::quote]` refuses as
`…/key/NotNullOrPathOrQuoteError` [QSBLD#input]. A tag of a refusal is
what a reader's catch, a law and a page compare with, and it moves with
the signature: an input that comes to take one kind more refuses under
another name, and every `!| type | eq …` written against the old one
stops matching without a word. [D284] moved one so,
`::map/has/key/NotKeywordOrPathOrStringError` becoming
`::map/has/key/NotKeywordOrNumberOrPathOrStringError`:

```qlang
> {:a 1} | has [1] !| type
::map/has/key/NotKeywordOrNumberOrPathOrStringError
```

The names of this shape the catalogs declare, each address once:

```sh
$ grep -rhoE "(::|throws :)[A-Za-z/]*/(Element|Payload)?Not[A-Z][a-z]+(Or[A-Z][a-z]+)+Error" core/lib cli/lib | sed -E 's/^(::|throws :)//' | sort -u | wc -l
100
```

Source. The outside audit of the tree `cbaaeb2d`, its finding 3.5,
`docs/research/outside-audit/2026-10-13-cbaaeb2d.md`, “Тег ошибки — это
публичный API (ловушки, законы, документация), а он зависит от деталей
сигнатуры”, whose fate in that folder's README let the rule stand and
left the question to the maintainer with no record to hold it; «и ещё
пока не забыл по поводу NotKeywordOrNumberOrPathOrStringError - вроде
как нам на это указывал один из ревьюверов раньше... что ошибки часть
публичного апи .. а такие сборные на лету имена очень хрупки при
развитии .. у нас этого как-то записано было? в открытых вопросах или
где» (maintainer, 2026-10-14 22:53, session d65e4c1d).
Alternatives. Three, each with its cost.
- As it stands: the name tells the kinds at a glance and needs no
  writing, and it moves with every change of the kinds, the move the
  reader's catches pay for.
- One name by the role, `…/key/KindNotTakenError`, with the kinds taken
  as the fact `:expected`, a set of tags, beside `:actualType`: the tag
  stays put while the kinds grow, a catch of the refusal reads
  `!| get /expected` for what the habit read from the name, and the
  hundred addresses and their cases and laws are written again once.
- A name the writer gives in the chain, `throws :key/NotAKeyError`,
  required where an input names more than one kind: a name of the
  reader's meaning that outlives the kinds, at the cost of a name to
  choose for each input and a refusal of a chain that names none.
