# D4 · A modifier holds a value, and a word is a declaration the runtime executes

Domain. Language.
Decision. A modifier holds a value; code handed to a word is an explicit
quote, or the input takes code by its kinds. Every word, a host's or
written in qlang, is a function of its subject's label, its inputs with
their kinds and invariants, its answer and its page, and the runtime
executes it: the subject and the inputs are checked before the
implementation runs, code is closed at the call, and the answer is
checked after. The arity dispatch of predicates and the second calling
convention go. A host's primitive is a plain function over checked
values, delivered with the source that declares it as
`{ uri, source, impls }`; the dispatch wrappers and error factories stop
being an interface.
Source. The model, 15 September 2026, at the maintainer's request; the
interface of hosts was added by the model on 23 September 2026 when the
reading of the whole tree showed the wrappers to be that interface.
The parameter written `~(f)` and the rules of forks were accepted in
passing: «с ~(f) синтаксисом параметров наверное тоже всех устроит, как
и те правила с форками» (maintainer, 2026-09-22 01:30, session
96f3df79).
Set aside. Lazy parameters by default, which produce the `m(it)` answer
of forty; keeping the wrappers and adding declarations beside them,
which is a second spelling of every calling shape.
