# D5 · One binding form, and the binding is a record

Domain. Language.
Decision. One form, `:name body`: a body is evaluated once at
declaration against the current value, a quote answering itself, so a
name holds a value, code among them [D44], and a label is declared
through the same form; `as` and the snapshot go. A declaration
produces a binding value that carries its name, its docs, its value, its
source and the source it came from, and the axes are projections of that
record [D63].

session f4f0c99b); `:n /` in place of `as`, «да, выглядит что ты прав..
