# D61 · Reflection starts from the noun

Domain. Language.
Decision. What a session sees first are the nouns it can talk to.
`env` answers the session's own names alone [D36]; `manifest` answers
the nouns a session can reach, the kinds of the core, a host's nouns
and the mounted namespaces; and a verb is listed under the kind it
lives on [D34], so the verbs of strings are an answer of `::string`,
and the reverse index the self-description asks for, what can be done
with a value, is its kind. The axes read a name and a value alike: a
keyword or a tag name reads the binding it names, and every other value
reads the declaration of its kind, the kind `type` answers, so `5 |
docs` is the page of numbers, `::Box#[3 1] | docs` the page of `::Box`,
and the `:kind` field of a map names nothing, `{:kind ::set} | docs`
being the page of maps. `docs` is a verb whose contract the core owns
and a kind implements [D34]: the core answers the page of the kind, and
a host's noun may answer its own, a Java method its Javadoc.
Source. «и давай по qlang ещё посмотри плиз как там | docs и прочие из
этой группы сейчас отрабатывают на примитивах .. и просто тэгированных
значениях когда там несколько тэгов ..  возможно стоит добавить какую-то
поддержку "рефлексии" сюда а не только на кейвордах и тэгах..»
(maintainer, 2026-09-25 05:01, session 86982eb5); «env и всякий там
манифесты что ли просто показывает доступные для общения существительные
..» and «а сейчас эти глаголы торчат и непонятно к чему относятся.. и
математика и строки и остальное по примитевам.. все без субъекта
вывалено наружу..» (05:39); and the reason, «существительные на первом
месте реально много слов экономят ..», a thing that «(в каком-то смысле
вещь надиктовывает тебе свой интерфейс для взаимодействия)», and «а если
бы можно было напрямую сказать "телик открой ютуб", "туалет потуши свет"
то общение было бы короче и предметнее..» (06:00). The reading by kind, the end of the `:kind`
field and `docs` as a contract, the model, the same morning, from the

refused a tagged vector, and `manifest | first | docs` answered the page
of `::builtin` for every operand.
Set aside. The axes on names alone, which refuse the first attempt of a
session that holds a value it does not know. Every layer of a stack read
at once, which blurs the one kind `type` answers, the layers beneath
being one `payload` away. A verb of its own for the reverse index, which
grows the catalog by a verb where the kind already answers.
