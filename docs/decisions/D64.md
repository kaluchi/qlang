# D64 · The kind a verb answers stands after the tilde

Domain. Language.
Decision. A verb literal writes the kind it answers right after the
tilde and what it takes in the brackets: `~::vec[::string :width
::number](split " ")` takes a string and a width and answers a vector,
the short spelling of `::conduit{:slots [::string :width ::number]
:returns ::vec :body ~(split " ")}` [D57]. The brackets hold the
subject's kind first when the verb has one, then the slots, each name
followed by its kind when it has one [D45], [D60], so a kind at their
start is the subject's, a kind after a name is the slot's, and no rule
of position remains; a verb that declares no result is written
`~[…](…)` and answers any value. A body that is a `::builtin`
descriptor is host code: `~::number[::vec](::builtin{:impl
:qlang/prim/count})`, the count of a vector, is the short spelling of
`::builtin{:slots [::vec] :returns ::number :impl :qlang/prim/count}`,
so a built-in and a declared verb are one literal and `spec` answers
the same fields for both. In the place of a kind, in
a head as in a schema [D6], a tag name stands for its kind and a set is
one of its members, a kind where the member is a tag name and the value
itself otherwise, so `#[::vec ::set ::map]` takes a value of any of the
three and `#[:in :out]` one of the two keywords. A modifier left out at
the end of a call is null, so a trailing slot whose kind admits null is
optional, `:key #[::quote ::null]` for the key `sort` takes or does
without. A vector of slots in the place of a slot is a group that
repeats, each of its names holding the vector of what it took, in
order, so `cond` declares `[[:test ::quote :then ::quote] :else
#[::quote ::null]]`, its pairs repeating and its default trailing. A
verb takes few positional modifiers, since their place is their role,
and the options beyond them are one slot whose kind is a record, each
field documented by its own kind [D40], [D50].

performs, whose trailing odd modifier is its default.
Set aside. The result last in the head, the form of D57, with its rule
of the two ends and the `::any` a result needs after a slot without a
kind. Groups of brackets as alternative signatures of one verb, the
maintainer's `[…][…]`: one body behind several heads has to find out
which head was called, where a slot that admits null says it in its
kind, and alternatives told apart by the kind of a modifier are the
overloading D9 set aside. A mark for an optional slot, or a default
written in the head, a value inside a list of kinds [D57]. A mark for a
last slot that gathers the rest, where a vector of slots says it with
the brackets the head already has. An arrow before the result, which the
maintainer declined in D57.
Replaces in part [D57], under which the result's kind stands last in the
head and a result after a slot without a kind follows `::any`.
Replaces in part [D6], under which a set in a schema is an enumeration
of keywords.
