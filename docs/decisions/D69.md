# D69 · A binding runs its body where it stands, so the marker of an effect binds a verb alone

Domain. Language.
Decision. A declaration evaluates its body once, where it stands,
against the current value [D44], so an effect its body calls fires
there and the name holds the value it answered. The effect marker
therefore binds a verb alone: a verb whose body calls an `@`-name is
declared under an `@`-name and is refused under a clean one, at its
declaration and at its call [D68], while `:result @callers` names the
answer of a call already made, as `@callers | as :result` does. The
vector of parameters after a name leaves the grammar with the conduit
[D67], and a vector after a name is its body, `:xs [1 2]`. In the head
of a verb a group around one literal is a literal, so `:depth
::Depth(3)` declares a default as D67 writes it. A session
serializes every binding as its value, a verb as its quote under its
tag, and gives each verb it restores the restored session for its
scope, so a name a cell shadows after the restore leaves the verb's
body alone. The language server labels a binding a verb when its body
is the verb literal and a value otherwise.
Source. The maintainer handed the implementation of D67 to the model
without a round of questions: «делай автономно, я потом гляну ревью ..
не переспрашивай» (maintainer, 2026-09-25 21:09, session 86982eb5). The
readings are the model's, made while it wrote the one binding form,
each where D44 and D67 leave the mechanism open, and the review of the
branch is where the maintainer reads them.
Set aside. The refusal of an effectful body under a clean name for
every binding, which refuses `:result @callers`, a value whose effect
has already run. A restored verb that resolves where it runs, under
which a cell that shadows `mul` after the restore changes what a
restored `double` answers. A session format that keeps a kind for each
binding, now that a binding has one kind. A refusal of its own for a
vector of keywords followed by a body, which keeps the conduit's
spelling alive as an error message.
