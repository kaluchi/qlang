# D7 · The page of a refusal is a procedure, and an error prints as an alert

Domain. Language.
Decision. The page behind each refusal is a procedure: what it means,
which fact names the culprit, the usual cause, the recovery through
`!|` as a runnable example, and the refusals it is confused with. An
error prints like an alert, its tag, its facts and a short excerpt, with
the full value one projection away; an unresolved name names the
nearest known names, and a parse error the continuations a reader could
have meant.
