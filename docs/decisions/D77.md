# D77 · The verbs of control reside on any value, and a refused value of a rest names its index

Domain. Language.
Decision. `if`, `coalesce` and `cond` reside on `::qlang/any` [D62],
[D72]. `if` takes a boolean condition and two slots of code, `:then`
and `:else`; `coalesce` gathers its alternatives and `cond` its clauses
in a rest of code, `* :alternatives ::quote` and `* :clauses ::quote`.
The code of a rest reaches the primitive closed at the call, as the code
of a slot does [D73]. A value of a rest that the head refuses is refused
with the refusal of the kind, which names the rest's slot and the index
of the value in the rest, counted from 1: `5 | cond true ~("yes")`
answers `::VerbCodeNotQuoteError` with `:slot :clauses :index 1`. The
refusals of a clause and of an alternative that the implementations of
`cond` and `coalesce` raised leave with them. A condition of `if` that
answers an error answers the call, as a modifier of every verb does
[D68], and the head checks the condition before the branches. The
wrappers `higherOrderOp` and `higherOrderOpVariadic`, and the sentinel
of an unbounded count, leave with the last operands built on them.
Source. The maintainer handed the milestone to the model without a round
of questions: «делай автономно, я потом гляну ревью .. не переспрашивай»
(maintainer, 2026-09-25 21:09, session 86982eb5). The readings are the
model's, made while it moved the verbs of control onto `::qlang/any` by
D72, where a rest of code had reached its primitive open and the head
named no value of a rest.
Set aside. A refusal a site declares for its rest, which would keep a
class per operand for what the kind already says. The branches checked
before the condition, as the implementation of `if` checked them, where
the head checks its places in the order it declares them.
