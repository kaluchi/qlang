# D80 · A host declares its words under the labels of their subjects and hands their primitives beside the source

Domain. Host.
Decision. A host's source declares each of its words as a name under the
label of its subject whose value is `::builtin{}`, and the host hands,
beside the source, `impls`: for each name, a plain function over the
values of its parts, the subject first and the parts in their order
[D4], [D72]. The root records each function beside the word of its name,
which calls it once its parts are checked, and refuses an implementation
handed for a name the source declares as no word. The dispatch wrappers
`valueOp`, `nullaryOp`, `overloadedOp` and `stateOp` left with the
operands of the hosts that were built on them, and the core exports no
dispatch module. The command line and the sister project land the
interface in the same move.
Source. The maintainer handed the milestone to the model without a round
of questions: «делай автономно, я потом гляну ревью .. не переспрашивай»
(maintainer, 2026-09-25 21:09, session 86982eb5), and the interface of
hosts was settled by D4 as `{ source, impls }`. The readings are the
model's, made while it moved the operands of the command line and of the
sister project onto verbs.
Set aside. An implementation handed for an undeclared name ignored,
which lets a misspelt name drop an operand in silence.
Pruned of what [D92], [D153], [D167] took.
