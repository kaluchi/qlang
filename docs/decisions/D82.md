# D82 · A value comes apart to the end into the set of its atoms

Domain. Language.
Decision. A value comes apart [D42] into the set of its atoms, null,
booleans, numbers, strings, keywords and tag names, each once and in the
one order, taken to the end: the keys of its maps and the tags over its
payloads are atoms as its other leaves are. The shape is a quote of
projections into that set and of the steps that build the value from
what they read: a vector is the vector of the shapes of its elements; a
map is built from the pairs of its keys and values by `indexBy`; a
tagged value, the set and the quote among them, from its tag and its
payload by `tag`, so code comes back through the constructors of its
steps; an error from its descriptor, which the fail track reads, by
`error`; and a doc from its text by `parse`. `["x" [1 1] {:b :a}]` has
the atoms `#[1 "x" :a :b]` and the shape
`~([/1 [/0 /0] ([[/3 /2]] | indexBy ~(first) * last)])`. The step of an
error literal holds a null `:trail` where the literal writes none, as
every error does, so the error its fields build is the step. The program
that takes a value apart and builds it back is qlang in the test tree,
and the test of the ring runs it over every example of the catalog and
every literal the conformance cases expect; an example it cannot build
back is an open part the test lists with its reason, today the error
literal whose trail is no quote, which `error` refuses to build.
Source. «я думал атомы будут в сете лежать #[] и я бы до конца разбирал..
до тэгов и кейвордов» (maintainer, 2026-09-26 05:17, session 86982eb5),
reviewing the model's first reading, which kept the keys and the tags in
the shape; the ring's time is no argument against it: «преждевременная
оптимизация мешает развитию и разработке» (maintainer, 2026-09-26 05:17,
session 86982eb5).
Set aside. The shape as the literal of the value with a projection for
each atom, its keys and its tags kept whole in it, which reads as the
literal and runs the ring in less time. The atoms in a vector in the
order of the literal, one per occurrence. The ring as verbs of the
catalog, which no task asks for [D22].
Replaced in part by [D85], under which the step of an error literal
holds the empty trail where the literal writes none, and the open part
is the error literal whose trail is no vector of stops.
