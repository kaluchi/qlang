# D82 · The shape of a value is its literal with a projection for each atom

Domain. Language.
Decision. A value comes apart [D42] into the atoms its literal holds,
null, booleans, numbers, strings, keywords and tag names, in the order of
the literal, the values of a map in the one order of its keys, and a
shape, the literal with a projection in the place of each atom:
`["x" [1 1] {:b :a}]` has the atoms `["x" 1 1 :a]` and the shape
`~([/0 [/1 /2] {:b /3}])`. The key of a map and the tag over a payload
belong to the shape, so a tagged value, the set and the quote among
them, is its tag over the shape of its payload and comes back through
its constructor, code through the constructors of its steps; an error is
the shape of the descriptor the fail track reads, handed to `error`, and
a doc is its text, handed to `parse`. The step of an error literal holds
a null `:trail` where the literal writes none, as every error does, so
the error its fields build is the step. The program that takes a value
apart and builds it back is qlang in the test tree, and the test of the
ring runs it over every example of the catalog and every literal the
conformance cases expect; an example it cannot build back is an open
part the test lists with its reason, today the error literal whose trail
is no quote, which `error` refuses to build.
Source. The maintainer handed the milestone to the model without a round
of questions: «делай автономно, я потом гляну ревью .. не переспрашивай»
(maintainer, 2026-09-25 21:09, session 86982eb5). The readings are the
model's, made while it wrote the ring; the shape as the literal with its
atoms taken out is the model's picture of 23 September, which D42 cites.
Set aside. Keys and tags among the atoms, a shape of projections alone
that builds each map from the pairs of its keys and values by `indexBy`
and each tagged value from its tag and its payload by `tag`: it reads as
no literal, and it took the ring twice as long. The ring as verbs of the
catalog, which no task asks for [D22].
