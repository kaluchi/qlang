# D83 · The doc of a declaration is the doc literal in its slot

Domain. Language.
Decision. The doc forms `|~~| …` and `|~~ … ~~|` are one literal, the
doc, wherever they stand, and a declaration's page is the doc literals
in its slot, between its name and its body, joined in the order they are
written, which `doc` answers [D119]: `:x |~~ note ~~| 42` documents
`x`. The syntax tree holds each as the `DocLit` node it is anywhere
else, and the step of the declaration in a quote holds them as the doc
values they are, `~(:x |~~ note ~~| it) | first | get /docs` answering
`[|~~ note ~~|]`, as the record of the binding does [D5]. A doc written
before a declaration is refused where it stands, a parse error that
names the slot, since no step reads a doc the step before it hands on;
a doc that opens a query is the doc value it is [D125], and one a pipe
leads to, `| |~~ … ~~|`, a value written as a later step, is refused
[D248].
Source. The maintainer handed the milestone to the model without a round
of questions: «делай автономно, я потом гляну ревью .. не переспрашивай»
(maintainer, 2026-09-25 21:09, session 86982eb5), and the audit names
the repair, documentation given its own slot with its own literal. The
maintainer's docs stand between the name and the body wherever the
maintainer writes one: «:depth |~~ levels of callers to walk ~~| ::number»
(maintainer, 2026-09-24 07:09, session 86982eb5). The refusal is the
model's reading, made while it rewrote the grammar.
Set aside. A doc before the name kept beside the slot [D5], a second
place of one doc that every reader of a declaration would read twice. A doc
before a declaration read as a doc value handed to it, under which a
doc written as the reference taught it would leave its declaration
undocumented without a word.
