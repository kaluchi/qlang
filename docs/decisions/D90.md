# D90 · A fold runs code of any shape on the pair of the value so far and the element, a quote of one word its short form

Domain. Language.
Decided by. The maintainer, on the model's reading of the two inputs;
the short form of one word the model's.
Decision. `reduce` takes a quote of any shape. A quote of one word, by
its name or its address, is the short form: the fold calls the word as
the pipe calls it, the value so far its subject and the element its
first arg, `[1 2 3] | reduce 0 ~(add)` answering `6` [D224]. Any other
code runs on the pair of the value so far and the element, and what it
answers is the value so far after that element:
`[{:x 1} {:x 2}] | reduce 0 ~(sumOf /0 (get /1 | get /x))` answers `3`, and
`[1 2 3] | reduce 0 ~(:acc (get /0) | :el (get /1) | acc | mul 10 | add el)`
answers `123`. A vector, a set and a map fold alike, the values of a map
its elements. No part completes the last step of its code with the
element, so `[1 2 3] | reduce 0 ~(mul 2 | add)` runs `mul 2` on the pair
and is refused, and a fold of several steps needs no word declared
first.
Source. The short form, the model, 27 September 2026, under [D89], from
the probe `[1 2 3] | reduce 0 ~(mul 2 | add)`, which the tree refused
while D4 still chose a trailing modifier and no case stated it; the
page of the refusal in the catalog already named a verb whose first
slot takes the element, and so did the reading of the verb's
implementation [D68]. The pair, «2 два входа про reduce ? - если да то
делай» (maintainer, 2026-10-12 03:41, session dda915a5), answering the
model's card of the questions the fourth outside audit left, whose
first, two inputs, all four audits named first; the pair is the fourth
audit's proposal, which [D233] recorded. The cases named both where
[D233] widened the code this record took and left it standing; [D233]
merged into this one, the earliest record of the axis [D237],
«глядишь так и утрясем этот шум из многих мелких ситуативных десиженов и сделаем что-то нормальное..»
(maintainer, 2026-10-12 07:26, session dda915a5).
Set aside. Completing the last step of the quote with the element, the
way `xargs` completes the command it was given, which D4 chose when the
reducer and the comparator were two calling shapes of code: a second
convention of application, special to one operand since the comparator
left [D16], for a fold code of any shape already writes. The element
bound under a name the fold chooses, a name no declaration writes. The
code run on the value so far with the element as its args, a second
reading of a quote that only a fold would know.
Requirements. The cases that name this record in
`core/test/conformance/11-the-words-of-vectors.jsonl` and `32-a-refusal-names-its-site.jsonl`: code of
several steps, a literal, a path, a name of a value and a name
nothing declares run on the pair; a set and a map fold the same way; a
failure of the code answers the call; and a quote of one word keeps its
short form.
