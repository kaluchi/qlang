# D90 · A reducer is the verb its quote names

Domain. Language.
Decision. The code of `reduce` names a verb by one word, a built-in such
as `add` or a verb the query declares, and the fold calls it as the pipe
calls it, the accumulator its subject and the element its first slot,
`acc | add element`; code of any other shape is refused with
`::ReduceReducerNotBinaryError`. A fold of several steps is a declared
verb, and `:step ::verb~(:el ::number | mul 2 | add el) | [1 2 3] |
reduce 0 ~(step)` answers 11. No slot completes the last step of its code
with a trailing modifier.
Source. The model, 27 September 2026, under [D89], from the probe
`[1 2 3] | reduce 0 ~(mul 2 | add)`, which the tree refuses while D4
still chose a trailing modifier and no case stated it; the page of the
refusal in the catalog already names a verb whose first slot takes the
element, and so does the reading of the verb's implementation [D68].
Set aside. Completing the last step of the quote with the element, the
way `xargs` completes the command it was given, which D4 chose when the
reducer and the comparator were two calling shapes of code: a second
convention of application, special to one operand since the comparator
left [D16], for a fold a declared verb already writes.
