# D93 · A probe answers its sentence, and every push runs the probes

Domain. Process.
Decision. A probe of the audit or of the entrypoint document answers
the sentence it stands under: a verdict, the things the sentence
names, or a quantity to the precision the sentence states, a sign or a
ratio to a tenth, so its answer changes when the sentence stops being
true and only then. It reads what the sentence names in a way that
fails when that is gone: the runner runs a shell probe with a pipeline
that fails where any command of it fails, and a probe lists the files
it reads with `git ls-files --error-unmatch`, which the runner requires,
so a file that moved reads as a failure and never as a repair. `npm run
ci` and the checks of every push run the probes that read the
repository alone; a probe whose answer changed, or a target the tree
meets, fails them, and the branch that changed the answer replaces the
sentence with the new fact and its probe [D58]. A probe that reads a
machine, the sister project or the environment keeps the date of its
answer and is run by hand. The probes run as tests, as [D31] proposed.
Source. «и ещё я сталкивался с подобным когда "комментарии
перевешивают" висящие в где-то в аудите со временем переставали быть
актуальными или наоборот была проведена работа, но она не была отражена
аудите», «типа если проба выдает сигнал - значит фраза "комментарии
перевешивают" не субъективная оценка.. а вполне себе измеримая
величина..» and «конформанс вроде как держит то что уже реализовано.. а
вот наши планы и оценки непонятно для меня как работают..» (maintainer,
2026-09-27 04:56, session d427ce7e). The rule is the model's, the same
day, from the first probe the runner found stale on a branch of the
model's own: the diff of the catalog, measured while the new module of
the command line stood outside the index, beside the claim that the
catalog alone had grown, which the decision records contradicted, since
the documents had grown too.
Set aside. Quantities compared within a tolerance, a second notion of
agreement kept in the runner where the sentence already states the
precision it needs. The runner run by hand alone, under which the
counts of the fourth version went stale unread. The paths a probe names
held by the check of anchors, a second place to keep beside the
probe's own failure.
