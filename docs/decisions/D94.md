# D94 · The parser reads a doc's segments, and a doc's text is its join

Domain. Language.
Decision. The parser reads the segments of a doc where it reads the
literal [D19]: a `~(…)` whose text reads as code is a quote, a span
between backquotes is prose whole, and the rest is prose [D43], so no
second reading of a doc's text is left to the runtime. The value is the
vector of its prose strings and quotes under `::doc`, which counts,
addresses, slices and filters as every vector does,
`|~~ a ~(add 1) b ~~| | count` answering `3`, and whose quotes are its
`examples` [D63]. The fields `content` and `segments`, which a
projection read off the doc, leave with the map they were read from, and
the text of a doc is its `join`, a verb of `::doc` that writes each
quote where it stands, `|~~ a ~(add 1) b ~~| | join` answering
`" a ~(add 1) b "`. `tag ::doc` builds a doc from a vector of strings
and quotes and refuses any other element, so a doc comes apart into its
segments and back by `tag`, as a quote does [D82]. A tag written in
prose is prose: the segment a constructor built from `::tag(…)` inside
a doc leaves, and no doc of the catalog made one. The tagged JSON of a
doc is the list of its segments, a quote by its source.
Source. «хорошо, работай пока автономно по нашему процессу» (maintainer,
2026-09-27 06:52, session d427ce7e), approving the model's proposal to
take the target of D19 first. The readings are the model's, the same
day, from the check of D19 before its first edit: the suite and the
catalog read the text of a doc by the projection `/content`, the
segments were computed by a second reading of the text in
`core/src/doc-segments.mjs`, which the parser had already read as
balanced spans, and every doc of the catalog yields prose and quotes
alone, `::qlang | manifest * (docs * /segments | flat) | flat * type |
distinct` answering `#[::map ::quote]` over the nouns, their verbs and
their refusals alike.
Set aside. `/content` kept as a projection, which a vector cannot
answer, since a key on a sequence is refused as it is on a quote. A
verb named `text`, a second name for what `join` says. The vector's own
`join`, which asks for a separator a doc does not need and refuses a
quote among the strings it joins. The prose read again at each call of
`docs`, which D19 rules out.
