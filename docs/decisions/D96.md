# D96 · A value prints through the `print` its kind answers

Domain. Language.
Decision. Printing is a verb, `print`, which answers the text that reads
back as its subject [D30]. It lives on `::any`, where it writes the
forms of the core: an atom as its literal, a vector and a map by their
brackets around the print of each element, the set, the quote, the doc
and the error by their own brackets [D95], and any other value under a
tag as its tag before the print of its payload, a descriptor
`::builtin{…}` among them. A kind a module declares may answer `print`
in that module, and the print of a value finds the `print` of each part
by the walk of that part [D88], so a value prints as the prints of its
parts, each by its kind. A host declares it on its own tags [D62], and
the command line and every host print an answer through `print`, so a
host shapes how its values show; the compact form a host gives stays
one that reads back, through the constructor of its tag where a string
carries it. What a host leaves out of an answer it replaces by
`::elision` values before the print [D21], so the print itself stays
lossless. `pretty`, the command line's copy of the core's printer,
leaves.
Source. «а я думал что мы сможем как-то забороть ту же непонятную логику
печати значения отделим от хоста или ядра или где оно там ..  что б хост
мог переопределять как-то диспетчеризацию .. т.е. printValue лежит там
где-то на ::any и оно по сути используется при печати того что я вижу
cli (что б позже как-то можно было элиминацию сюда включать или ещё как
обойтись)» and «т.е. ::doc[" a " ~(add 1) " b "]   пойдет в эту печать
значения и станет |~~ a ~(add 1) b ~~|  .. что б как-то потом через это
и хостовые сущности представлять компактно..» (maintainer, 2026-09-27
08:27, session d427ce7e); «хорошо, так мне больше нравится» (08:40),
answering the model's proposal of a verb on any value whose default
writes the canonical form. The engine, a walk of the value that asks for
a kind's own `print` only where a module declares one, is the model's,
the same day.
Set aside. A printer that switches on the class of a value in the
runtime, which no tag and no host reaches, the state before. A printer a
host replaces whole, which spells the forms of the core again in every
host. A view apart from the literal that may lose what the value holds,
where the elision marker keeps a shortened answer a value that reads
back.
