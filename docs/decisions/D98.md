# D98 · An explanation is a value of its kind

Domain. Language.
Decision. `explain` answers an explanation, a value of the kind
`::explanation`: a map of the page of the error's site under `:doc` and
the error itself under `:error`, in that order, so its print shows the
page as a header above the error it explains, and reads back as the
value [D96]. The error it holds is the error `!|` opened, a value on
the success track, raised again by `raise` [D97]. The kind answers by
verbs of its own [D72]: `doc` the page, `error` the error, and
`quotes` the quotes of the page, which are its examples [D95].
`explain` computes the explanation from the facts of the error, and an
error holds no page.
Source. «это отвечало какнибудь а ля [ docs /]  - или ещё как завернуть
в ::explanation со своей структурой .. просто так предлагаю
порассуждать.. что  как будто бы значение сразу с красивой шапкой
документации там и т.п. приехало ..» (maintainer, 2026-09-27 10:32,
session d427ce7e); «хорошо, делай» (10:32), answering the model's
proposal of a kind whose default print puts the page first.
Set aside. A vector `[doc error]`, whose parts only the one who built
it can name. The page stored in every error, which puts a page in each
answer a host shows. A header the command line prints above every
error, which asks for a budget of what a session has been shown and
belongs to the host [D62]. `examples` as the name of the verb that
answers the quotes, which a tag name reaches on the noun it names
[D88], so `::explanation | examples` would read the page of an
explanation where it reads the examples of the kind.
Replaced in part by [D99], under which `quotes` resides on `::doc`
and an explanation answers them through its page.
