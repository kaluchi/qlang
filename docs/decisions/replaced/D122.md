# D122 · A snippet is a query a page shows to run and see

Domain. Language.
Decision. A quote under `::snippet` in a doc is a snippet, a query a
page shows its reader to run and see, `::snippet~({:a [5 6]} | get /a/-1)`.
It answers whatever it shows, where a law answers true and a link opens
a page [D121], [D175]. `::snippet` is a kind of the core with a page and
no constructor, as `::link` is, the role a tag gives a quote [D108].
`open` is a word of `::quote` and runs a quote beneath whatever tags
stand over it, so a link and a snippet open alike.
