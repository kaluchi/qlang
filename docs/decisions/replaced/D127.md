# D127 · A refusal says the form a reader meant

Domain. Language.
Decision. A refusal that meets a form a reader writes by habit names the
form that is right. A pipe written after a combinator, `[1] !| | count`,
is refused by the parser with the sentence that `|` stands in the place
of the combinator, and a set written with braces, `#{1}`, with the
sentence that a set is written `#[…]`. A tag whose path names no word,
`::any/links`, is refused with the addresses where a word of its last
name lives, `::doc/links`, among its `:addresses`.
