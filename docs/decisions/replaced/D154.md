# D154 · A tag name on a later line is the body of the declaration before it

Domain. Language.
Decided by. The model, answering the maintainer's question.
Decision. A tag name written on a line after a declaration's name or
doc is that declaration's body, `:w` and on the next line `::number`
declaring `:w ::number`, at the top level and inside a group or a quote
alike. A tag name opens no declaration of its own [D152], so it reads
only as the body. A keyword on a later line still opens a declaration
of its own, `:a` and on the next line `:b 2` declaring `:b` [D66].
Source. The maintainer's question
«почему qlang> :Box ::spec~(:w
::number)   с переносом на новую строку сломало подсветку в cli ?»
(2026-10-08 15:36, session 22b934f8), and the charge to settle it in
the source, «разберись нормально с исходным кодом и процессом»
(15:40). The model traced the refusal to `KindBody` in
`core/src/grammar.peggy`, which read a tag name as a body on the
declaration's own line alone because a later line once opened a
declaration of a tag, which [D152] refuses.
Set aside. A refusal that names the line, which keeps the break as
an error where only one reading remains. A tag name on a later line
read as the next step at the top level, `:w | ::number`, which pipes a
keyword into a tag name and answers nothing a reader wants.
Replaces in part [D66], under which a keyword or a tag name on a later
line opened a declaration of its own.
Merged into [D66].
