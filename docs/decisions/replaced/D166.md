# D166 · The mechanics of names under a label, the parts of a call's args, invariants and defaults

Domain. Language.
Decided by. The model, working out the mechanics of [D164] and [D165]
from the prototype the research of the legend keeps.
Decision. A label is declared by its page, `:Box |~~ … ~~|`: a node
whose value is a page is a label, and a value put under it keeps every
invariant declared under it, each run on the value under the label. A
name declared under a label whose value is a quote resides on the label
and runs on its value when a step names it, resolving its names through
the labels of its subject and the tree of names as it stands, so the
names under one label see each other whatever their order. A call that
names it with modifiers builds its args, the values of the modifiers,
each computed against the subject, as a vector under the name's
address; each name declared under that address is a part, read from
the args by its selector, held to the invariants declared under it and
bound by its name in the body, and the whole args are bound as `args`.
A part that reads the whole
args or their tail takes any number of values; the parts that read
places alone read as many values as the places, and args with more are
refused under the address of the call's name, the refusal naming the
form that fits [D165]. A refusal is named by the address of what
refused, a part's invariant under the part, a primitive's own under the
name of its call.
Source. The model, in the session of D164: the prototype in a worktree
of `e283af3`, whose patch and files `docs/research/legend/` keeps, ran
each rule. `[1] | query /2 | coalesce ~()` answered `null`, since
`coalesce` runs a quote it is given, and `[null] | query /0 | coalesce 7`
answered `7`, a given null taken for a missing one, which is why a
default is a value `query` holds. `:filter 5 | [1 2 3] | filter ~(gt 1)`
was refused and `:first 9 | {:a [1 2]} | get /a | first` answered `9`,
which is why a reader's bare name takes no word of the vocabulary.
Set aside. A default through `coalesce`, which runs a quote and skips
an error. A name under a label resolving in the scope it was declared
in, under which the first host source of the prototype read a label
declared after it as unknown. The answer re-minted under the subject's
labels whenever it has the payload's shape, which turns the first
vector of a vector of vectors into a value of the subject's label.
Requirements. `::Box[0 2 3 4]` is refused under `::Box` when the page
holds `::holds~(length | gt 0)`. `::Box[1 2 3 4] | put "x"` is refused
as `::Box/put/weight/HoldsNotMetError`. `:filter 5` is refused.
