# D182 · `map` runs its code on each element and answers what each answered

Domain. Language.
Decided by. The model, at the maintainer's word that `*` leaves for a
word, «хорошо, оформляй решения, строй план и делай .. распрощаемся с *»
(maintainer, 2026-10-10 19:02, session 22b934f8).
Decision. `map` resides on `::vec`, `::set` and `::map`, as `filter`
does, and a quote and a doc map as the vectors they are. Its part
`code`, `~(/0)`, is a quote, and a value computed at the call is refused
under the part with the repair, `map ~(add 1)`. It runs the code on each
element in order, in the scope of the call, the names a run declares
closing with it [D43]; the first error the code answers for an element
is the answer of the call, the elements after it left unrun, and the
call's stop joins the trail after the stops inside, as the stop of every
word that runs code does [D13], [D103]. Over a vector it answers the
vector of what each element answered, under no tag of the subject,
since the subject's tags speak of the elements it held; over a map the
map of what each value answered under the same keys; over a set the
vector of the images in the one order [D116]. The answer of `map` on
vectors and on maps is declared `::any`, since an answer declared of the
word's own label goes back under the subject's tags [D169]. A subject no
kind of whose walk answers `map` is refused by the call with the
addresses where the word lives [D169]. In the data form a step on each
element is a call, `::call{:name :map :modifiers [~(add 1)]}`, and the
form speaks with six tags [D8].
Source. The mechanics the leave of `*` asks for [D181], each carried
from the rule `*` kept: the body run in order on each element, its first
failure, the answer over a map and over a set.
Set aside. `map` on `::any` as one word, which keeps one page for every
container at the price of a refusal of the other values declared by
hand, where the words of a kind take theirs by rule. An answer under the
subject's tags, as `filter` keeps them, which would hold what the code
answered to the invariants of the elements it replaced, and make a quote
of what each step of a quote answered.
Requirements. The cases that name D182: `map` over a vector, a map and a
set, its first failure, its code refused without its quote, a subject of
no kind of `map` refused with its addresses.
Merged into [D116].
