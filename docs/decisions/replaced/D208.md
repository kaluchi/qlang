# D208 · The sign of the diff is read against what the work delivered, and no message carries a count the history answers

Left at 80a499d9, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 80a499d9:<path>`, not in today's.

Domain. Process.
Overrides [QSWRK#diff].
Decided by. The maintainer.
Decision. The sign of a diff by area, core sources, catalog, documents,
tests and tooling, is computed from the history,
`node scripts/measure.mjs`, and read over a piece of work in retrospect
against what it delivered, since a feature spreads over many commits:
less code at the same behaviour is a refactoring, less code with a new
feature the work to praise, about as much code with a feature good work,
and more code with features asks what they are worth to qlang, ground
laid for a later refactoring or a loss. No commit message, page or
record carries a count of lines, which the history answers to whoever
asks.
Source. Commit messages of 2026-10-11 carried counts their numstat did
not hold, and the model proposed to leave the counts to the history:
«окей, если все эти числа есть производные значения от коммита - то да,
незачем их куда-то там писать.. тем более когда потребитель неизвестен
(кому надо, кто смотрит, на что влияет?)..», «тут скорее речь была про
то, что сигнал этот важный для определения качества работы», «если кода
стало больше и фичи появились -- то тут уже как бы надо оценивать
ценность этой фичи/работы.. нужна ли она была так qlang-у .. или там
какой-то задел на будущее .. а ля площадка для будущих рефакторингов ...
или же все плохо..» and «но в целом ретроспективно это можно как-то
проанализировать и оценить» (maintainer, 2026-10-11 14:29, session
22b934f8).
Set aside. The counts written into the message of each commit, which the
history answers, for which no reader was named, and which a hand
measured wrong; and the sign judged commit by commit, where a feature
spread over many commits shows none.
Requirements. None of the conformance suite: a rule of work, held by the
review of a range, which computes its sign and reads it against what the
range delivered.
Dissolved into [QSWRK#diff].
