# D209 · An error holds the trail it flew or is written with, and `trail` answers `[]` for none

Left at d1ebd70d, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show d1ebd70d:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the reading the model laid out to him.
Decision. A raised error holds the facts of its site and the path it
flew under `:trail`, `"x" | add 1 !| keys` answering
`#[:actualType :trail]`; an error at rest holds the facts it is written
with, so `::error{:a 1}`, which no step raised, holds no `:trail`. An
error or a map that writes its `:trail`, an empty one among them,
resumes that path when raised, and the error at rest `!|` catches from
an empty path holds none, `{:a 1 :trail []} | raise !| keys` answering
`#[:a]`; so the ring of atoms writes the path of an error it takes
apart, an empty one among them, and builds the error back as it was.
The word `trail` answers the path, `[]` for an error that holds none,
while `/trail` reads the key and is refused where there is none.
Source. The fifth milestone asked that `:trail` print the same way on an
error value and on its materialized descriptor, where the literal hid an
empty trail and the descriptor showed it, and the audit laid out three
ways among its open questions: the literal writing the empty path, the
descriptor holding none, or the two as they stood. The model recommended
the second: «ок, давай как ты рекомендуешь .. а это сложно сделать?»
(maintainer, 2026-10-11 14:49, session 22b934f8).
Set aside. The literal writing an empty path, `[!{:a 1 :trail []}]`, a
key in the print of every error a reader writes in a container and a
print unlike its source; the printer hiding an empty `:trail` in a map,
which would print a descriptor as a text that reads back as another map;
and the two as they stood, which left the line of the milestone unmet.
Replaces in part [D85], under which the step of an error literal held an
empty `:trail` where the literal wrote none.
Requirements. The cases of D209 in
`git show d1ebd70d:core/test/conformance/19-error-values.jsonl`: an error at rest no step
raised prints without a trail, holds its facts alone, answers `trail`
with `[]` and refuses `/trail`; a raised error holds its path; and an
error or a map raised that writes an empty trail holds none once caught.
