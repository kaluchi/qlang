# D210 · A failure lives in the pipe alone, and an error at rest is a value like any other

Left at d1ebd70d, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show d1ebd70d:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the reading the model laid out to him.
Decision. An error has two states. At rest it is a value like any other,
a map of facts under `::error`, `::error{…}`, under the tag of the site
that refused, `::number/add/SubjectNotNumberError::error{…}`: a container
holds it, a step reads it, `print` writes it, and its print reads back as
itself. Raised, it is a failure, which lives in the pipe alone: `|`
passes it by, its path, `:trail`, written as it flies, a stop at the step
that raised it and at every level it leaves and the steps it skips
joining the last stop, and `!|` alone catches it, its step running on the
error at rest, a value from then on, which `raise` raises again,
resuming the path it holds. No value holds a failure. A literal whose
word answers one answers it, the first in the order written, the words
after it unrun, as a modifier and the code of `map` do, and so do the
facts of an error literal and the body of a declaration, which binds
nothing; a refusal that holds a failure computed at the call holds the
error at rest, and an explanation the error at rest `!|` caught. So a
read never raises, and the first stop of a trail is where its failure
arose. The step of an error literal, which a quote holds as data, is the
error at rest it spells, under the tag written before its bang as
written, and the quote prints it with its bang, so a quote is built back
from its steps and the ring of atoms closes. A failure prints as its
error at rest, the path it flew among its facts, `:trail []` for one
that flew no step, a refusal of the text of a query among them. A catch
whose label refuses the facts answers the refusal with a stop at its
step, a refusal the label throws among them.

Set aside. A read that hands on a raised error a container holds without
a stop, which keeps the failure in a value and the steps it skipped
there nowhere. The step of an error literal held as a raised error,
which a read of a quote raised. An explanation that holds the error
raised and prints it with its bang [D101], a failure in a value. A
failure printed without the path it never flew, whose print reads back
as a failure of the step that reads it.
