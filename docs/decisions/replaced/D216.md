# D216 · A child of the benchmark runs the command line, landing on the pages of the language and the command line

Domain. Benchmark.
Decided by. The maintainer.
Decision. A child of the benchmark runs the command line, and the
screen it is handed is the pages of the language and of the command
line as the language prints them, `[::qlang ::cli] | map ~([/ doc])`:
the page of the command line tells what a call reads and writes, which
every call of the child meets, and links the rest, conversion, budgets
and failures, which the child follows at need. The screen holds the
pages and not the tutorials, the pages with their laws, which set T
measured beside the examples in place and did not prefer. The blind mode
goes, a child that answers from the screen alone and runs nothing, and
with it the prediction of conformance cases, which ran such a child.
Source. No child of set U read `--help` or `::cli | doc`, the only
places that told what the command line writes. «вопрос ещё а на что мы
сейчас высаживаем модель? на tutorial или на doc ?  даже если не
[::qlang ::cli] | map ~([/ doc])  .. то сделать недостающий tutorial для cli
и нормально там по линкам и частям разложить..» (maintainer, 2026-10-11
20:10, session 22b934f8), «ну если туториал не использовался значит
[/ doc] достаточно будет я думаю» (20:20), and «слепой режим не нужен -
удаляй оно непонятно что тестирует» (20:24).
Set aside. The tutorial of each name, its page and its laws, the form
set T did not prefer; the page of the language alone with a link to the
page of the command line, which no child of set U followed.
Replaces in part [D142], under which children solved a set blind or with
the command line, and the predictions of conformance cases ran a blind
child.
Requirements. `node scripts/benchmark.mjs run` takes no mode, and the
screen a run fixes is what the tree prints for `[::qlang ::cli] | map
~([/ doc])`.
