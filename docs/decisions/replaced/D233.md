Decision. `reduce` takes a quote of any shape. A quote of one word, by
its name or its address, is the short form: the fold calls the word as
the pipe calls it, the value so far its subject and the element its
first arg, `[1 2 3] | reduce 0 ~(add)` answering `6` [D90], [D224]. Any
other code runs on the pair of the value so far and the element, and
what it answers is the value so far after that element:
`[{:x 1} {:x 2}] | reduce 0 ~(sumOf /0 (/1 | /x))` answers `3`, and
`[1 2 3] | reduce 0 ~(:acc /0 | :el /1 | acc | mul 10 | add el)`
answers `123`. A vector, a set and a map fold alike, the values of a map
its elements. The refusal of code that names no one word,
`reduce/reducer/NotBinaryError`, leaves, and a fold of several steps
needs no word declared first.
