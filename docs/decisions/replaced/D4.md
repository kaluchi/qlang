# D4 · A modifier holds a value, code is a quote a word applies, and a word is a declaration the runtime executes

Left at 95a0454d, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 95a0454d:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the model's proposals: a quote run
against the subject by `apply`, the order of the modifiers, the short
form of a quote, a combinator set off by whitespace, and the parameter
written `~(f)`. The model's: the reading of modifiers, the canonical
fold, the condition of `if` as a value and the clauses of `cond` as
quotes, the refusal of a group where code is taken, the rule for a doc,
and the interface of hosts.
Decision. A modifier holds a value: it is read by its own form and
evaluated at the call against the subject, a bare name and a group
included, so `take count` takes as many elements as there are. A
command's modifiers are forks against the subject at the call site,
evaluated as the quotes of a template of `get` are: results by position,
none seeing another. Code is a quote, `~(…)`, and a quote of a single name
may drop the parentheses, `~add`; the full form is the main one, which
the printer writes and the documents show. A quote runs only where a
word applies it, `apply` and `open` its subject [D108] and a word that
takes code the code of its part, which takes it by its kinds: `apply q`
runs the quote against the subject under the fork rule, a quote written
in the step where a group written there runs and a quote held as data
in a lane of its own [D278], and `eval` is no word of the language. A word that runs a part
per element, in its own order or only when that part is chosen, takes a
quote in that part and applies it: `filter ~(gt 1)`, `reduce 0 ~(add)`
as the canonical fold, the branches of `if` and the clauses of `cond`,
while the condition of `if`, which always runs first, is a value,
`if (n | lte 1) ~(1) ~(…)`. So `filter (gt 1)`, whose group computes a
boolean at the call, is refused, and the page of the refusal names the
tilde. A combinator is set off by whitespace on both sides, a line break
counting as whitespace and an opening bracket or the start of the text
standing for the space before it, so `|~`, `|~|`, `|~~` and `|~~|`
written together always open a comment or a doc, `|~(add)` refused
naming the word that runs code after a pipe, `| apply ~(…)`, and a
combinator written against its neighbour is refused with a message that
names the space. Inside a doc only `~(`
opens a quote, under the tags written before it, and the rest is prose.
Every word, a host's or written in qlang, is a function of its subject's
label, its inputs with their kinds and invariants, its answer and its
page, and the runtime executes it: the subject and the inputs are
checked before the implementation runs, code it is handed runs in the
step that wrote it or, held as data, in a lane of its own [D278], and the
answer is checked after, every word called one way, a predicate among
them. A host's primitive is a plain function over checked values,
delivered with the source that declares it as `{ uri, source, impls }`,
and no dispatch wrapper or error factory is an interface.

Set aside. Lazy parameters by default, which produce the `m(it)` answer
of forty; keeping the wrappers and adding declarations beside them,
which is a second spelling of every calling shape. Overloading `apply`
by the type of its argument, which two quotes make undecidable; the
price accepted, a declaration when the code arrives through the
pipeline, as in the replay of a trail. A slot of kind code that
captures its modifier and runs it later, the form first decided here,
under which a call reads only with the operand's declaration at hand
and a quote meant as data is run by the slot it lands in. A bare name
that stands for its binding without running it, as `+` does in
Clojure's `reduce`, which keeps `reduce 0 add` and makes `take count` a
refusal. The quote without a short form, which costs two brackets on
every reference, and the short form inside a doc too, where
`~/.jdtbridge`, `~5` and `~~struck~~` would need escapes and a forgotten
escape breaks a document silently. A new sign for a reference, `&add`,
which spells code a second way, and a new sign for a comment, `#`, which
trades the trap at `|~` for one at `#[`. A slot that takes a value or
code and runs code, as Smalltalk's `value` answers on any object, under
which a branch computed at the call silently does its work and a quote
held as data runs where it lands. A quote that resolves its names only
where it is applied, which lets a parameter capture a name of the
caller; a slot of kind code that closes what it receives, which leaves
open to that capture every declared pipeline whose declaration omits the
kind; a quote that carries its environment wherever it is evaluated,
which makes a quote held as data more than data.
