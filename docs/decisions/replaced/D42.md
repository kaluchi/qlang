# D42 · A value comes apart to the end into the set of its atoms and a shape, and the shape builds it back

Left at 0cfb95f2, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 0cfb95f2:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the readings the model laid out to him.
Decision. Every value comes apart into the set of its atoms and a shape,
and the shape applied to the set builds a value equal to the first. The
atoms are the values no verb takes further apart, null, booleans,
numbers, strings, patterns [D246], keywords, tag names and paths, which
have no parts a path reads [D248], each once and
in the one order, and a value is taken apart to the end: the keys of its maps and
the tags over its payloads are atoms as its other leaves are. The shape
is a quote that reads the value back from the set by `get` over a
template of the reads of its parts [D279]: an atom is read by the path
of its place in the set, `/n`; a vector is the vector of the reads of
its elements; a map is built from the pairs of its keys and values by
`indexBy`, and a tagged value, the set, the quote, the doc and an error
at rest among them, from its tag and its payload by `tag`, each of the
two a quote the template runs, so code comes back through the
constructors of its steps. `["x" [1 1] {:b :a}]` has the atoms
`#[1 "x" :a :b]` and the shape
`~(get [/1 [/0 /0] ~(get [[/3 /2]] | indexBy ~(first) | map ~last)])`. Both ways
are qlang in the test tree, written with the language's own verbs and
no primitive of the host language, and the test of the ring runs them
over every example of the catalog and every literal the conformance
cases expect.
