# D5 · One binding form names a value, code among it, writes the record of its binding, and declares a word under a label

Domain. Language.
Decided by. The maintainer, on the readings the model laid out; a name
declared once in a scope, the axes as projections of the record and the
roles of `as` spelled by the form are the model's, and so is the
refusal of modifiers given a name that holds a value.
Decision. One form, `:name body`, declares every name: a body is
evaluated once, at declaration, against the current value, so a name
holds a value, a quote body a quote held as a value,
`:q ~(add 1) | q` answering `~(add 1)`, and a label is declared through
the same form. The declaration hands its subject on unchanged, the
binding a branch to the side, `5 | :x |~~ note ~~| 1 | add 1` answering
`6`, and writes into the scope a record, `::binding`, that holds the
name, the docs of its slot, the value, the declaration's source and the
source it came from, `:x |~~ note ~~| 1 | ::x | binding | keys`
answering `#[:docs :name :origin :source :value]`; the axes read that
record, `source` its source, `doc` its page and `binding` the record
itself, `:x |~~ note ~~| 1 | ::x | doc` answering
`|~~ note ~~|`. A name with a path addresses a node of the tree of
names, `::vec/count | doc` reading the page of `count` on vectors, and
inside a namespace a declaration points at another by its name, a
refusal at the word it guards and an input at the word it is an input of,
so the metadata of a word is the set of declarations under its address
[D153].

A word is the same form under the label of its subject, a quote its
body, `:number/inc ~(add 1)`; it runs when it is mentioned, as a
built-in does, `5 | inc` answering `6`, and `~inc` hands it on as code,
`[1 2] | map ~inc` answering `[2 3]`. A value never runs by itself, and
a name that holds one takes no modifiers, `5 | :five it | five 42`
refused as `::call/ValueTakesNoModifiersError`:
`apply` runs a quote, and an input that takes code applies what it
receives, so a named quote goes into it bare,
`:adult ~(get /age | gte 18) | [{:age 30} {:age 12}] | filter adult`
answering `[{:age 30}]`. A name is declared once in a scope, and a second declaration
there is refused [D71]; a cell of the REPL opens a scope of its own
[D153]. Under these rules code moved into a declaration further left
answers as it did inline or is refused: a quote or a word means the
same wherever its names mean the same, and only a value, computed where
it is declared, follows the subject there, as its spelling shows.

The word `as` leaves the language, `[1] | as :x` answering
`::call/UnknownNameError`, and each of its roles is spelled by the one
form: a declaration whose body is `it` names the current value,
`42 | :x it | add 1 | x` answering `42`; one whose body is a group names
what the group computes, `[1 2 3] | :n (count) | n` answering `3`; a
word whose body calls another names it anew, `:vec/len ~(count)`; and
the same naming inside the code `map` runs names the element there,
`map ~(:item it | get {:key /id :record ~(item)})`.
