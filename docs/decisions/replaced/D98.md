# D98 · An explanation is a value of its kind, the page above the value it explains, and every value answers one

Left at 95a0454d, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 95a0454d:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the readings the model laid out.
Decision. `explain` is a word of `::any` and answers the explanation of
any value, a value of the kind `::explanation`: the page `doc` reads
for it under `:page`, then the value itself under `:value`,
`42 | explain | keys` answering `#[:page :value]`. It prints as a map
under its tag, the page above the value it explains, and reads back as
the value [D96]. `explain` computes the page from what it explains, and
an error holds no page: a name reads its own page,
`::number/add | explain`, a value the page of the kind it shows,
`42 | explain`, and an error `!|` opened the page of its site, the tag
it shows [D13]. The explanation answers the value by `value`, which for
an error is the error at rest that `raise` raises again, and its page
by `page`. `trail` stays on `::error`, a word of errors alone,
`42 | trail` answering `::error/trail/SubjectNotErrorError`.
