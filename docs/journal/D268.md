# D268 · Open: the boot of the root, and a lazy one

Domain. Implementation.
Question. The command line boots the whole root in each process, its
sources parsed and their declarations run. On 11 October 2026, on the
maintainer's machine, a run of `qlang '1'` took 0.74 to 0.84 s, five
runs each its own process: node's own start 0.08 s, the modules of the
core 0.06 s, the boot of the root, `langRuntime`, 0.63 s, and the
session of the command line with the query 0.02 s; within the boot the
parse of the sources, half a million characters, took 0.26 to 0.31 s and
the run of their declarations the rest. Every call a model makes pays
it, a run of the benchmark a dozen times. The maintainer asked whether a
lazy one pays: «потом уже переходи к ленивой загрузке.. потому как
непонятно как это скажется на производительности и остальном.. или
смысла нет там вообще.. т.к. есть операнды которые работают над всей
вселенной..» (maintainer, 2026-10-07 21:23, session 22b934f8). Words
read the whole root: a bare name the walk of its subject does not
answer, `residencesOf` in `core/src/nouns.mjs`; the words of
`::any`, which several sources declare, `namesUnderOf` there; `kinds`,
`kindNamesOf` there; and the names near a name a refusal offers,
`nearestNames` in `core/src/nearest-names.mjs`. So a query that fails,
the common query of a reader learning a tool, loads it all, and a loader
needs the names each source declares before it runs it.
Source. The model's measurement of 11 October 2026 and the maintainer's
question the text quotes; the audit held it in its open chapter from 7
October 2026.
Alternatives. The root booted whole, as it stands; the trees of the
sources kept beside them as JSON, which spares the parse, each checked
against a hash of its source, at the cost of an artifact the build
writes and the package carries, a site that boots in a browser parsing
still; and sources loaded by an index of their names, which costs the
loader and a rewrite of every reader of the whole root, and spares a
query that fails nothing.
