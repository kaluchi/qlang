# D272 · Open: the objects each command of a chain takes and the kinds of a key, spelled once

Domain. Implementation.
Question. What each command of the chain of a function or of a kind
takes is spelled three times: by the table the runtime reads a chain
with, `COMMANDS` and `KIND_COMMANDS` in `core/src/chain.mjs`;
by the inputs of the word of each command in the catalog, `:fn/takes`
and the rest in `core/lib/qlang/fn.qlang` and `:kind/wraps` and the rest
in `core/lib/qlang/kind.qlang`; and by the pages of
`::fn/SignatureNotCommandsError` and `::kind/SignatureNotCommandsError`.
The spellings part: the input `:kinds` of `takes` takes a vector, and the
table takes a vector of one kinds alone, the kinds of each element, so a
vector of two tags is taken by the word and refused by the table.

```qlang
> ::fn | takes :by |~~ x ~~| /0 [::number ::string] !| type
::fn/CommandNotTakenError
```

One spelling asks that no contract of a word be spelled outside the
catalog, the third condition of [the aim](AIM.md#state). A primitive that runs an input as code
names it a second time, `runs(['code'], …)`, which
`core/src/primitives.mjs` defines and the modules of the runtime call, and a
name no input of its word bears is passed over without a word.

The kinds of a key are spelled so too: the kinds of the input of each word
that takes a key, in its chain, `#[::keyword ::number ::path ::string]` of
`has`, `put`, `update` and `delete`; the kinds of a key alone, `isKeyAlone`
in `core/src/path-read.mjs`, and those `minus` and `inter` name as
`:expected`, `KINDS_NAMING_A_MAP_KEY` in `core/src/runtime/setops.mjs`; and
the kinds a key files under, the list of the words `toKeyword` lives on,
`TO_KEYWORD_ADDRESSES` in `core/src/runtime/convert.mjs`, which `groupBy`,
`indexBy` and `toMap` read. A boolean and a tag name a map files under are
read by their keyword alone:

```qlang
> [1 2 3] | groupBy ~(gt 1) | get [~(get true !| type) ~(get :true)]
[::any/get/path/KindNotTakenError [2 3]]
```
Source. The review of the branch `the-path-is-a-value`, its third
finding, `docs/journal/research/reviews/2026-10-13-the-path-is-a-value.md`;
and the review of the sixteenth batch of [D353], its first finding,
`docs/journal/research/reviews/D353~5.md`, which found the keys
`groupBy` files under a boolean refused where `get` reads a key.
Alternatives. The runtime reads the objects of each command from the
function of the word of the command, `::fn/takes` and the rest, the
table kept for the words the root reads before the sources of `::fn` and
`::kind` load, at the cost of an order of the boot in which those words
come first; the pages of the refusals link to the pages of the commands
and name no object of their own; the table stays the one spelling and the
words of the commands declare their inputs with no kinds, which the table
holds, at the cost of pages that tell less; and `runs` refuses a name its
word does not take, the table of a primitive's inputs read from its
function. For a key: a key read by the walk of its kinds to `toKeyword`,
the kinds of a key written once, by the words `toKeyword` lives on, `get
true` reading `:true`; at the cost of the words that read a key reading
the scope at their call, and of a chain with no word for the kinds of a
key, which writes its set of tags. Or the kinds of a key as they stand.
