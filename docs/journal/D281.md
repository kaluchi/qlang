# D281 · Code that is not written in its step reads no value of the text it was written in, refused under one name, the recipe of a verb among it

Domain. Language.
Decided by. The maintainer, who chose, of the roads the session put to him,
one refusal for a value of the text read by code that cannot read it, and
left its shape to the model: «ок на твое усмотрение» and «пот твою полную
отвественность, так что думай заранее хорошо и сам себя критикуй». The
model's: the values withheld those of the text a code was declared in, the
name of a verb calling itself, no verb of the name reached in their stead,
and the reading of a word of the host and of the server as they stand.
Overrides [QSBLD#recipe], [QSQUO#held].
Decision.

The recipe of a verb, and the conditions and the selectors of a verb or a
kind, read no value of the text they were declared in, as code held as data
reads no value of the step it runs in [QSQUO#held]: a bare name of such a
value is refused as `::call/ValueWithheldError` with `:name` the name, where
the name of a value nothing declared there is refused as
`::call/UnknownNameError` [QSNAM#reach]. One refusal names one cause, a
value of the text the code cannot read:

```qlang
> get [(5 | apply (:k 3; :number/f ~(k); f !| get [tag name])) (5 | apply (:k 10; :q ~(add k); apply q !| get [tag name])) (apply (:limit 10; :Box |~~ B ~~| (::kind | holds :TooWideError |~~ W ~~| ~(count | lt limit)); ::Box[1] !| get [tag name]))]
[[::call/ValueWithheldError :k] [::call/ValueWithheldError :k] [::call/ValueWithheldError :limit]]
```

A value stands over a verb of its name in every code its text writes: the
steps of the text refuse it as a later step, code that cannot read it
refuses it as withheld, and the verb is called by its address there,
`vec/count`, as [QSNAM#reach] writes it. No verb of the name is reached in
the stead of the value, so code never answers by a verb the reader did not
mean. The name of a verb calls the verb in its recipe, a value of that name
withheld from it. The values withheld are those of the text where the code
was declared, before it, and none of the text that calls it: a verb of the
root, whose sources declare no value, reads the root alone whatever values
a reader names, and a verb declared before a value, or in a text apart from
the call, reads the verbs of its own text:

```qlang
> get [(apply (:count 5; :vec/w ~(count); :vec/v vec/count; [1 2] | get [(w !| get [tag name]) v])) (apply (:count 5; :floor 3; [1 2 3] | get [size (drop 1)])) (apply (:vec/w first; :first 5; [1 2] | w)) (apply (:f 1; :vec/f (if (count | gt 1) (drop 1 | f) count); [1 2 3] | vec/f))]
[[[::call/ValueWithheldError :count] 2] [3 [2 3]] 1 1]
```

A word of the host reads the tree of names of the query that called the
verb, as [D200] gave it, so a verb written in the language answers as a
verb of the host does: `::k | tutorial` reads the page of a value of the
reader whose tag it is handed [QSNAM#owner]. A node of data under an
address, a quote a group hands back, held as data, and a law, which runs
as held code, stay as they are. The language server reads a name in the
body of a verb by the text alone, as [QSLSP#reach] writes it: the language
reads such a name where each call stands, and a verb called in several
places has no one reading a server could give.

Source. The question as it stood: a value read by a bare name refused in a

Set aside.
- The verb of the name reached where a value of it is withheld and a verb
  answers the subject: held code reading `:count 2; ~(take count)` would
  take three elements where its reader meant two, an answer in silence.
- A word of the host reading the scope of its step, the tree of the query
  leaving: a verb written in the language would refuse the page of a value
  whose tag it is handed, `::k | tutorial`, which a verb of the host reads.
- The values of the text that calls a verb withheld from its recipe: a verb
  declared apart from the call would lose the verbs of its own text, and
  its name would be withheld from its own recursion.
- A node of data under an address withheld as a value is: the helpers a
  reader keeps under a noun would become inputs.
- A quote declared under a name written into at its declaration, a law
  reading the name it stands under, and a quote a group hands back keeping
  the step it was written in: [D500] keeps a quote as it is written.
