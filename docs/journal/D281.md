# D281 · Open: the names a word of the host reads in the body of a word, those of the query that called the word or those of its own step

Domain. Language.
Question. Which names does a word of the host that reads the state of its
call read in the body of a word written in the language? Code reads the
words of the scope it runs in, a constant among them, and withholds from
held code the names `with` gives the code of one step [D421]. A word of the
host that reads the state of its call reads the tree of the query wherever
it is called [D200]: in the body of a word written in the language, `doc`,
`binding` and `env` read the names of the query that called the word, and
the names the body declares stay out of that tree, so a body cannot read
the page of a label it declares, while held code, whose declarations are
its own scope [D278], reads its own. The state a word of the host reads
carries the scope of its own step beside the tree of the query, so either
reading is at hand in the runtime:

```qlang
> :vec/w ~(:Box |~~ A box. ~~| | ::Box | doc | content) | [1] | w !| tag
::any/doc/UnknownNameError

> apply ~(:f ~(:Box |~~ A box. ~~| | ::Box | doc | content) | 1 | apply f)
"A box."
```
