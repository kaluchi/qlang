# D293 · Open: what a host builds on, and what it carries

Domain. Host.
Question. What does a host build on, and what does it carry of its own?
A host declares its refusals by their addresses with `declareRefusal`,
imported through the `errors` subpath of the core (`cli/src/streams.mjs`),
and declares their facts under their labels in its catalog, so the
declaration of a refusal is an interface of the runtime a host builds
on; the sister project imports none of them and carries two copies of
`fromPlain` of its own, each named `jsonToQlang`. The entry point of the
package exports what its consumers read, the slot of the headers among
it, and a subpath for the declaration of a refusal:

```sh
$ node --input-type=module -e "const core = await import('./core/src/index.mjs'); console.log(Object.keys(core).filter(name => /SYMBOL|SLOT|PREFIX|KEY/.test(name)).join(' '))"
TAG_HEADER_SYMBOL
$ node -p "Object.keys(require('./core/package.json').exports).filter(path => /error/.test(path)).join(' ')"
./errors
```

A raw-mode line editor and its tests are the largest piece of the command
line, and the REPL it serves saves no session; the noun of a project's
`.qlang/` folder waits for the sources a project ships; the sister
project onboards its user with a guide written by hand, which reads from
its catalog the first sentence of the page of each word it shows first;
one start command answering the first page, a renderer that withholds
the pages of the tags a session was shown, and an enrichment once a
session stand on no host yet.
Source. The scars of the refusals a host builds from the runtime, of the
concerns of a host inside the core and of the embedding surface, which
the audit held, `git show d8657d4e:docs/qlang-audit.md`, given to the
journal by [D292].
Alternatives. The refusals of a host as kinds its catalog declares, so
nothing of the runtime is exported for building words, and the surface
designed with the argument model, a session, a source as
`{ uri, source, impls }`, the parser, the printer and the JSON codec:
the command line and the sister project move their refusals into their
catalogs, and the `errors` subpath and the slot of the headers leave the
package. The surface kept as its consumers read it, held by the test of
the package root: a host keeps building words from the runtime, and each
consumer stays a second speller of its refusals. The concerns of the
command line, each a branch of the host's side: the REPL saving a session
as the source of its declarations, the line editor a library of the host,
the `.qlang/` noun landing with the first project that ships sources, and
the guide of the sister project generated from its catalog.
