condition of [the aim](AIM.md#state) asks, its comments handled in a few

A modifier written on a line of its own that opens with a keyword reads as
a declaration of its own [QSSYN#line]:

```qlang
> "{:mode :slow} | put /mode\n  :fast 1" | parse | open !| type
::any/put/value/NotGivenError
```

A block doc reads the lines of its prose after the first with the
indentation of its source, which `doc`, `explain` and the print of a page
show, which tells apart two docs of one prose, and which the language
server takes off by a `dedent` of its own, a reading of a doc beside the
parser's:

```qlang
> get [~("|~~ a\n  b ~~|" | parse | first | eq ("|~~ a\n      b ~~|" | parse | first)) ~(::vec/payload | doc | first | contains "\n            ")]
[false true]
```

The prose of a page, which `prose` answers and the hover of the language
server shows, leaves out each quote the page holds, a snippet among them,
so a sentence whose subject is a snippet, as the catalog writes what
`manifest` lists of a kind, reads there without its subject:

```qlang
> get [~(::number | doc | content | contains "::snippet~(::number | manifest) lists") ~(::number | doc | prose | contains "| manifest) lists")]
[true false]
```
