# D295 · Open: the grammar of the finish and its second spelling

Domain. Language.
Question. How does the grammar come to the proportion the fifth
condition asks [QSAIM#state], its comments handled in a few lines, and
what spells it for the editor? `core/src/grammar.peggy` holds the comment
and doc forms nesting in each other and in quotes; the refusals that name
a habit of another language as productions with their messages; a line
break that tells where a declaration ends; and two counters its
predicates raise and give back:

```sh
$ grep -oE "^[A-Z][A-Za-z]*Refusal\b" core/src/grammar.peggy
TagDeclarationRefusal
SpacingRefusal
$ grep -oE "let (docQuoteDepth|lookingAhead)" core/src/grammar.peggy
let docQuoteDepth
let lookingAhead
```

The editor carries grammars of TextMate written by hand, a second
spelling of the grammar beside the parser:

```sh
$ git ls-files --error-unmatch vscode/syntaxes/qlang.tmLanguage.json vscode/syntaxes/qlang-markdown.tmLanguage.json
vscode/syntaxes/qlang-markdown.tmLanguage.json
vscode/syntaxes/qlang.tmLanguage.json
```
Source. The scars of the grammar and of the documents that retold the
catalog, which the audit held, `git show d8657d4e:docs/qlang-audit.md`,
given to the journal by [D292].
Alternatives. Comments as whitespace in a few lines and one pipeline
production, the refusals moved to a pass over the parser's tree: the
grammar is written again, and the place of each refusal found again. The
editor's grammar generated from the tokens of the grammar: a generator,
run by the build. The editor's grammar reduced to what the language
server cannot give, the rest its semantic tokens: the server learns the
tokens, and an editor without the server paints less.
