# D297 · Open: what the runtime keeps of its own

Domain. Language.
Question. What does the runtime keep beside the language, and what of it
leaves? A session meets the tag and the facts of a refusal, while the
runtime makes a class of the JavaScript for each refusal, which a test
holds against its page; the registry of the primitives seals after the
bootstrap; the environment a reader lists holds the names the reader
declared beside keys of the runtime's own; and a count of `range` below
its bound that outgrows the memory of the host is refused by nothing;
and the facts of an error, which the language calls its payload and the
chapters its facts, the runtime keeps under a name of its own,
`descriptor`, which a host reads:

```sh
$ grep -oE "export const [A-Z_]+_KEY\b" core/src/env-keys.mjs
export const ROOT_KEY
export const QUERY_KEY
export const CALL_BINDS_KEY
export const WITHHELD_KEY
$ node --input-type=module -e "const { declareRefusal } = await import('./core/src/errors.mjs'); console.log(typeof declareRefusal('probe/SomeError'))"
function
```
Source. The tree a developer meets, as the audit drew it, and its list of
what leaves the tree as the repairs land, `git show
d8657d4e:docs/qlang-audit.md`, given to the journal by [D292]; the
fourth check of the chapters, the report of the work,
`docs/journal/research/spec-check/D323~1/QSWRK.md`, which
found the name of the facts.
Alternatives. A refusal made by one constructor of errors from its
address, with no class for each, the state of a call kept beside the
environment rather than under keys of it, and the registry given way to
the impls of the sources: the runtime is rebuilt at its seams, and the
tests that import the classes go with them. The classes kept as the
means of the runtime alone, the tag the interface: each refusal keeps two
spellings, its address and its class. The facts of an error kept under
the name the language gives them, at the cost of every host that reads
`descriptor`, the sister project among them, in one release.
