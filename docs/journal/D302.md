so it leaves the specification, `docs/spec/QSAIM-the-aim.md`, and stands
in the journal as `docs/journal/AIM.md`, read at the landing of a session
with the records in transit and the open records, whose choices it
weighs. It holds the mission, what the language is for and the measure
of quality, the satisfactory state and the principles a change is judged
by, each sentence read against the language as it stands: the core holds
two combinators and a state pair of value and scope; a foreign format
meets the language where the language meets the outside, JSON pasted as
a literal and written by `json`; and the clause of the second condition
that no markdown text restates the catalog, written before the chapters,
gives way to the third, one spelling, which holds a chapter and a page
alike. What the chapters hold already leaves it: the answer as data
filtered for a question and a command's one output [QSHST#effect], the
tag that leads to the legend of its payload [QSSLF#catalog], the language
that teaches from inside itself [QSSLF#page], a value whose print reads
back [QSPRN#print], a value at the head of a pipeline [QSSYN#step] and
the screen of the work [QSWRK#documents]; so do the rules of the work it
restated, the sign of the diff [QSWRK#diff], prose naming the invariant
[QSWRK#code] and the handle of a statement [QSWRK#journal]. The order of
the texts goes to the chapter of the work, the code that implements the
language ranked under its reference, so a parting of the two is the
