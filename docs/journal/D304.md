# D304 · Open: what of the reader's names reaches code

Domain. Language.
Question. Which of the names a reader declared does code read, the body
of a word and code held as data alike, and how is the rest refused? The
body of a word reads the nodes and the labels of the scope it is called
in and stands outside the reader's values [QSNAM#scope]; held code reads
the words, the nodes and the labels of its step and refuses a value
under its name [QSQUO#held]. The roads part five ways. A value under a
bare name is refused in a body as a name nothing declares and in held
code as withheld, while the same value under an address reaches both:

```qlang
> :k 3 | :number/f ~(k) | 5 | f !| type
::call/UnknownNameError

> :k 10 | :q ~(add k) | 5 | apply q !| get [~(type) /name]
[::call/ValueWithheldError :k]

> :Box |~~ B ~~| | :Box/k 3 | :number/f ~(Box/k) | 5 | f
3
```

A value named as a word closes that word to held code and leaves it to
the body of a word:

```qlang
> :count 5 | :q ~([1 2] | count) | apply q !| type
::call/ValueWithheldError

> :count 5 | :vec/w ~(count) | [1 2] | w
2
```

A label of the reader goes into a word of the root, where its bare name
meets a word the root's code calls, while a value of that name stays out:

```qlang
> :sum |~~ S. ~~| | {:a 1} | sumOf /a !| type
::call/ValueMeetsWordError

> :sum 5 | {:a 1} | sumOf /a
1
```

And a quote a group hands back unchanged is held as data, so it reads no
name of the step its parentheses stand in:

```qlang
> :k 10 | [1 2] | map (~(add k)) !| get [~(type) /name]
[::call/ValueWithheldError :k]
```

A law runs as held code [QSSLF#laws], so a law declared under a name of
the reader's data reads that name neither bare nor through its tag, and
proves nothing of the value it stands under:

```qlang
> :k |~~ Answers five. ~~| 5 | :k/answersFive |~~ k answers five. ~~| ::law~(k | eq 5) | ::k | runLaws | first | get [/ok ~(get /error | type)]
[false ::call/ValueWithheldError]
```

Alternatives. One road for every code: a value of the reader withheld
and refused under its name, `ValueWithheldError`, in held code and in a
body, where no word of the name answers the subject, so `count` stays the
word and `k` is withheld alike, at the cost of held code reading a word
a value of its name shadows in the reader's own steps. A value withheld
wherever its name is read, the body of a word among it, as held code
withholds it, at the cost of a word of the root failing where a reader
named a value as a word it calls, unless the root's words read the root
alone. A label of the reader reached in a word of the root by its tag
alone, its bare name the root's, at the cost of a word of the root that
names a reader's kind bare. A node of data under an address withheld as

a rule that follows a value through a group. A law reading the name it
stands under, the one value of the reader its claim is about, at the
cost of held code that reads a value by where it is declared. A quote
declared under a name written into by `fill` at its declaration, each
value of the reader it names put in its text, a closure that prints and
reads back, at the cost of the quote under the name no longer being the
text written and of a value declared after it never reaching it. Or the
