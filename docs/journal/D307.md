# D307 · Open: a function with no code of its own

Domain. Language.
Question. What is a function whose recipe is no code: a host's function
read back from its print, a contract with no recipe under a label, and
the `::builtin{}` a reader writes as the check of a kind? A host's
function prints and reads back equal, and runs only where the host
handed it [QSHST#source]; a contract under a label answers three ways;
and a reader's kind with a host's check lays its tag:

```qlang
> ::number/add | binding | get /value | :f it | print | parse | open | :g it | get [~(f | eq g) ~(5 | apply f [1]) ~(5 | apply g [1] !| type)]
[true 6 ::fn/RecipeMissingError]

> :number/c (::fn | takes :x |~~ x ~~| /0) | 5 | c 1 !| get [/name /nearest]
[:c []]

> :number/c (::fn | takes :x |~~ x ~~| /0) | 5 | number/c 1 !| type
::call/ValueTakesNoModifiersError

> 5 | apply (::fn | takes :x |~~ x ~~| /0) [1] !| type
::fn/RecipeMissingError

> :B |~~ B. ~~| (::kind | impl ::builtin{}) | ::B[1] | type
::B
```

The page of `::fn/RecipeMissingError` calls a function with
`::builtin{}` one with no recipe. The chapters part on it: a function
under a label is a word [QSNAM#address], while a `::builtin{}` a reader
writes as a recipe is the value it is, its address answering the
function and its bare name reaching no word [QSHST#source]:

```qlang
> :number/z (::fn | returns |~~ n ~~| ::number | impl ::builtin{}) | get [~(5 | z !| type) ~(number/z | type)]
[::call/UnknownNameError ::fn]
```

A function of the reader whose recipe is the `::builtin{}` of a verb of the
core runs that verb's primitive under its own chain and not the verb's, so
on a subject the verb would refuse the primitive answers what JavaScript
gives, a missing value that reads as null for `first` over a map, and a
number past the doubles under no kind, which the printer refuses as no
value of the language [D361]:

```qlang
> {:a 1} | apply (::fn | impl (::vec/first | binding | get /value | get /1)) [] | get [~(type) ~(eq null)]
[::null true]

> 1e308 | apply (::fn | takes :x |~~ An x. ~~| /0 | impl (::number/add | binding | get /value | get /1)) [1e308] | type
::number
```

Alternatives. A recipe no host handed refused alike on every road, the

primitive through its print, the literal naming the address it was
handed for, at the cost of a literal that names a host. Or the roads as
they stand.
