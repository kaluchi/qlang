# D309 · Open: paths read where a key, a part or an element is computed

Domain. Language.
Question. A path reads beneath the tags over each value it meets
[QSPTH#get], `query` answers null where null stands on the path
[QSPTH#query], a key alone is a keyword, a number or a string and any
other value given to `get` a template [QSPTH#key], and `toPath` builds a
path from a vector of keys [QSPTH#words]. Where a key, a part or an
element is computed, the roads part: null under a tag stops `query`, a
key computed as null or `true` answers itself under the strict `get`,
`toPath` refuses the number `get` reads as a key and answers no path for
a path, and a part a path reads for an input of numbers is refused under
the word that summed it, not under the input:

```qlang
> {:a ::T#null} | query /a/b !| type
::path/SubjectHasNoPartsError

> {:a null} | query /a/b
null

> {:true 1 :k null :f true} | get [~(get (get /k)) ~(get (get /f))]
[null true]

> [:a 1.5] | toPath !| type
::vec/toPath/ElementNotKeyError

> /a | toPath !| type
::call/KindAnswersNoVerbError

> {:b "x"} | get [~(sumOf 1 (get /b) !| get [~(type) /index]) ~(sumOf 1 /b !| get [~(type) /index])]
[[::any/sumOf/numbers/ElementKindNotTakenError 1] [::vec/sum/ElementNotNumberError 1]]
```

The words that combine the values of one subject part the same way: a
part a path reads is refused by the word its recipe calls, under an
address the reader never wrote; `unionOf` runs a quote `sumOf` refuses,
and refuses a pair of numbers under `union`. And a number names a key by
its text where `get` and `has` take one, while `minus` and `inter` refuse
it:

```qlang
> {:x "1" :y 2} | get [~(subOf /x /y !| type) ~(mulOf /x /y !| type)]
[::number/sub/SubjectNotNumberError ::number/mul/multiplier/KindNotTakenError]

> {:a {:x 1}} | get [~(unionOf ~(get /a)) ~(sumOf ~(get /a/x) !| type) ~(unionOf 3 4 !| type)]
[{:x 1} ::any/sumOf/numbers/ElementKindNotTakenError ::call/KindAnswersNoVerbError]

> {:"1" 5} | get [~(get 1) ~(has 1) ~(minus [1] !| type)]
[5 true ::map/minus/KeyNotKeywordOrStringError]
```
Source. The first and the second checks of the chapters, the reports of
paths, numbers and collections and of functions and errors,
`docs/journal/research/spec-check/2026-10-15-3d6ad533/` and
`docs/journal/research/spec-check/2026-10-15-985a4b82/`.
Alternatives. Null read beneath its tags by `query`, as every part is,
at the cost of a soft read that passes a tag the strict read would stop
at. A key computed at the call that is no keyword, number or string
refused under the input of the strict read, at the cost of the template
`get` reads in that place. `toPath` taking a number as the key of its
text and a path as itself, at the cost of a word that answers its own
kind. A part a path reads for an input held to the input's kinds as a
value given there is, every word of one subject taking a value, a path
and a quote alike, at the cost of a check of each part where the input
runs code. A number naming a key by its text in `minus` and `inter` as
in `get`, at the cost of the refusal that names a key of a keyword or a
string. Or the roads as they stand.
