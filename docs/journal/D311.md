# D311 · Open: the refusal of a pair of kinds an operation has no rule for, a comparison across kinds, `::desc` and the algebra

Domain. Language.
Question. Which refusal does a pair of values meet whose kinds an
operation has no rule for, and what does it name? Two operations meet
such pairs today, and each names them otherwise on its roads.

The comparisons of the core compare within one kind, a value of another
kind refused under the input [QSCND#compare], while `::desc` owns

```qlang

```

