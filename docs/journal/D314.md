# D314 · An empty trail is no path, and a failure prints as the error at rest `!|` opens it to

Domain. Language.
Decided by. The model, on the maintainer's words: that a failure prints
as `!|` would open it, with no `:trail []`, is his; that an empty
`:trail` is no path, its raise starting the path at its own stop, and
that the runner of the cases and the ring of atoms read the failure an
expectation writes as its facts are written, are the model's.
Overrides [QSERR#trail], [QSERR#print], [QSSYN#step], [QSSYN#refusal],
[QSSYN#line], [QSSYN#combinator], [QSLIT#number]
Decision. A raise resumes the path an error or a map writes, a `:trail`
that holds a stop, and adds no stop. An empty `:trail` is no path, as an
error holds none, so its raise starts the path at its own stop as the
raise of a map that writes no `:trail` does, and the steps the failure
skips after it join that stop:

```qlang
> {:a 1 :trail []} | raise | count !| trail | map ~(get [/step /skipped])
[[~(raise) ~(count)]]
```

So every failure a step answers holds its path from its first stop, and
an error a catch opened, raised again, is the error it was:

```qlang
> {:a 1 :trail []} | raise !| keys
#[:a :trail]

> {:a 1 :trail []} | raise !| :e it | raise !| eq e
true
```

A failure prints as the error at rest `!|` opens it to, the path it flew
among its facts. The refusal of a text that does not parse, which flew
no step, prints its facts alone, and its print raised starts its path at
that raise:

```sh
$ qlang '[01' < /dev/null | sed -n '1,7p'
|~| raised, and no !| caught it
::quote/ParseError!{
  :source "[01"
  :marker " ^~"
  :message "a number is written without a leading zero: write `1`"
  :location ::span[1 1 2 3 1 4]
}
```

The expectation of a failure in the conformance suite, its error at rest
under `raise`, names the failure that holds the facts the literal
writes, its path among them, as they are written; the ring of atoms
builds a failure back as the error at rest it is opened to.
