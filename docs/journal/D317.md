# D317 · Open: a doc a quote holds as a step, its role one a label refuses

Domain. Language.
Question. A doc lays each tag of a quote's role through the tag's label,
so a tag that takes no quote refuses the doc [QSSLF#doc], and a quote
holds a literal step as the value it writes [QSQUO#step]. A quote that
holds such a doc as a step holds a segment no constructor builds, a
quote under a tag that refuses a quote, whose print reads back as the
refusal:

```qlang
> ~(|~~ see ::vec~(x) ~~|) | first | segments | get /1 | :v it | get [~(v | payload) ~(v | print)]
[~(x) "::vec~(x)"]

> ~(|~~ see ::vec~(x) ~~|) | apply it !| type
::vec/PayloadKindNotTakenError
```
Source. The second check of the chapters, the report of
self-description, printing and hosts,
`docs/journal/research/spec-check/2026-10-15-985a4b82/`.
Alternatives. The quote literal lays the roles of each doc it holds
through their labels as the doc does when it runs, refusing
`~(|~~ see ::vec~(x) ~~|)` as the doc is refused, at the cost of a quote
literal that reads the labels of the roles it holds. A role a tag over
the quote alone, laid as it is wherever a doc stands and read by the
words that follow it, `open`, `links` and `snippets`, at the cost of a doc
whose role no word takes standing until it is opened. Or the step as it
stands, a value its print does not read back to.
