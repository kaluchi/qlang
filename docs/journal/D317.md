# D317 · Open: a doc or an error literal a quote holds as a step, its tag one a label refuses

Domain. Language.
Question. A doc lays each tag of a quote's role through the tag's label,
so a tag that takes no quote refuses the doc [QSSLF#doc], an error
literal lays the tag written before its bang through its label
[QSERR#rest], and a quote holds a doc and an error literal as the value
each writes [QSQUO#step]. A quote that holds such a step holds a value
no constructor builds, whose print reads back as the refusal:

```qlang
> ~(|~~ see ::vec~(x) ~~|) | first | segments | get /1 | :v it | get [~(v | payload) ~(v | print)]
[~(x) "::vec~(x)"]

> ~(|~~ see ::vec~(x) ~~|) | apply it !| type
::vec/PayloadKindNotTakenError

> ~(::number!{:a 1}) | first | :v it | get [~(type) ~(print) ~(is ::number)]
[::number "::number!{:a 1}" false]

> ::number!{:a 1} !| type
::number/PayloadKindNotTakenError
```

A tagged literal is held as the record of its construction, which reads
back as it prints:

```qlang
> ~(::number"5") | first | type
::construct
```
