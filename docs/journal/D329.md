# D329 · Open: the kinds of values written as literals, one language for the chains, the shape of a value and its check

Domain. Language.
Question. Should the kinds a word declares, the shape `shape` answers
and the kinds a check holds a value to be written in one language of
literals, which names the kind of each element of a container? The
chains write a part of it already: a tag is a kind, `#[…]` one of its
kinds and `[X]` a vector each of whose elements is of `X`, `takes :xs
|~~ … ~~| /0 [::number]`; and `shape` writes a record, `{:k X}` [D324].
Neither says a set of `X`, a map whose keys are data and whose values
are of `X`, a pair read by its places, a key a record may lack or a
value that may be null. So a word that answers a container says its
kind alone, `returns ::vec` for `split`, `lines`, `range`, `zip` and
`trail`, `returns ::set` for `keys`, `kinds`, `manifest` and `paths`,
and a fact of a refusal is declared otherwise than it holds:

```qlang
> get [~(1 | add "x" !| get /expected) ~(::error/expected | binding | get /value)]
[#[::number] #[::tag]]
```

A clean reviewer of `shape` found a key a record lacks and a key that
holds null shown alike, though `get` refuses the one and reads the
other; a part that is a record or null no longer read by the paths of
the data; a set below the top shown as `::set` alone; and a map keyed by
data growing with the data:

```qlang
> [{:a 1} {}] | shape | eq ([{:a 1} {:a null}] | shape)
true

> [{:v {:x 1}} {:v null}] | shape | get /0/v/x !| type
::path/IndexNotIntegerError

> {:tags #[:a]} | shape
{:tags ::set}
```

The model's reading: a kind a word declares is a contract for every
call, which the runtime holds an answer to and `doc` and `manifest` read
before the call, and the shape of a value an observation of one value;
the two are written alike, and the shape of every answer of a word fits
the kind its `returns` declares.

Alternatives. The roads, each with its cost:
- B, the road the maintainer leaned to. A tag is a kind; `#[a b]` one of
  kinds that differ, null not among them; `[a]` a vector each of whose
  elements is of `a`, and `[a b]` a vector of two places, each of its
  own kind; `{:k a}` a map that holds its keys of their kinds, other
  keys free; `[]` and `{}` the empty ones; and an atom a kind holds, a
  string or a keyword, that value itself, `#["open" "closed"]`.
  `::set/of[a]` is a set and `::map/of[a]` a map whose keys are data,
  each element or value of `a`, the payload written as the vector of
  the elements is written; `::nullable a` a value that may be null and
  `::optional a` a key of a record that may be missing, each a tag over
  its kind that the paths of the data read through,
  `{:author ::optional::nullable{:login ::string}} | get /author/login`
  answering `::string`. The chains write their kinds so, in `returns`,
  `takes`, `carries`, `wraps` and `reads`, `shape` answers so, and `is`
  holds a value to such a kind, one matcher of a value to a kind for all
  of them; the grammar stays as it is. At the cost of the matcher; a
  check of every element of an answer on every call, or the agreement
  held by a law alone; the bringing of an answer to its kinds learning a
  kind that is a value; the chains of the catalog rewritten wherever the
  elements of a container are of one kind; four names with their pages,
  `::set/of`, `::map/of`, `::nullable` and `::optional`; and null
  leaving `#[…]`, so a value that may be null keeps one spelling.
- A. `::absent` and `::null` among the kinds of `#[…]`,
  `{:email #[::absent ::null ::string]}`, as TypeScript and JSON Schema
  write a union; at the cost of a part that is a record or null no
  longer read by the paths of the data, the reviewer's case.
- Or the kinds as they stand, a container's kind alone in a chain, and
  `:expected` declared otherwise than it holds.
Under either road the decision settles: whether the payload of `/of` is
written as the vector form, `::set/of[::number]` a set of numbers, or
as the kind of an element itself, `::set/of::number`, under which
`::set/of[::number]` is a set of vectors; what `::optional` is outside
the value of a key; whether an answer is checked at the call or its
agreement held by laws; the label an answer of a kind that is a value
returns under; when `shape` folds a map into `::map/of`; and whether a
record checked as an input is open.
