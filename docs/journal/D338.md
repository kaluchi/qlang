# D338 · Open: the sentences and names that answer a past, repaired where they stand

Domain. Implementation.
Question. Which sentences of the texts that state what holds, and which
names of the code, answer an earlier layer of the language rather than
the tree, and is each repaired as named below? None of these repairs
moves a rule: no case, no chapter and no name of the package's surface
changes, so a branch takes the list whole or in parts, item by item, and
reruns the probe of each item it repaired, whose answer changes with the
repair, writing the item out of this record in the same commit. The items
were found by the audit whose recipe is [D342]; the deeper scars it found
are [D339], [D340] and [D341], where an item that moves a rule stands.

Each anchor names a file and the words it holds, which a grep finds where
the lines moved; the line numbers are those of the tree of this record's
commit, on the branch `the-trail-as-frames`, whose work on the trail
[D337] changed some of the files named here since the baseline e90d39b3.
Where an item says “since” a commit, the commit is where the earlier
layer left the tree, `git show <commit>` telling what it was.

**A. Sentences of the pages of the catalog that the tree contradicts.**

answers.

**B. Comments of the code that answer a past.** A comment states what

language left, a consumer, a version of a tool, or a reason.

25. A value under a tag is named an instance in the code alone, with one
    name for two things: `isTaggedInstance` holds of every value whose tag
    rides its header, a set, a quote, a doc and a binding among them, while
    the value class `'taggedInstance'` brands the wrapper alone
    (`core/src/types.mjs`); `formOf` calls the same value `'underTag'`, and
    `mintUnderTag` (`core/src/runtime/verb.mjs`) is `mintTaggedInstance` with
    its arguments in another order. The language says “a value under a
    tag” and `::tagged`, and [QSWRK#code] asks the code to name a thing as
    the language does. `isQMap` and `isQSet` keep the prefix from when they
    told the language's map and set from the JavaScript `Map` and `Set`
    that held them (`git show bc11e56d:core/src/types.mjs`, where
    `isQSet` reads `v instanceof Set`). And the walk beneath the tags over a
    value is written by hand in several modules,
    `while (isValueClass(beneath, 'taggedInstance'))`. Repair: names of one
    meaning each, `isTagged` for a value with a tag, a name of its own for
    the wrapper, `isMap` and `isSet`, and one helper for the payload beneath
    the tags.

    ```sh
    $ git grep -l -F "while (isValueClass(beneath, 'taggedInstance'))" -- core/src | wc -l | tr -d ' '
    5
    ```
