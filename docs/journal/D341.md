# D341 · Open: one thing under many words, and one word over many things

Domain. Language.
Question. Which things of the language go by several words across the
texts that state what holds, the code, the tools and the cases, and which
word names several things, so that a reader takes one thing for two or two
for one; and which word is kept for each? Each part below gives the words,
where each stands, the earlier layer where the history keeps it, and a
probe or a command that shows it; the roads stand under `Alternatives.`.
[QSWRK#code] asks the code to name each thing as the language names it,
and the principle of [the aim](AIM.md#principles) that words carry
paradigms weighs which word a reader trained on other languages reads
right. A word the maintainer chose stays the maintainer's to change. The
pentimento audit [D342] found them; its other records are [D338], [D339]
and [D340].

Each anchor names a file and the words it holds; the tree is that of this
record's commit, on the branch `the-trail-as-frames` over the baseline
e90d39b3. A count is answered by the command written beside it, which the
gate does not run.

**8. Shape, and outline.** Shape names the form an answer takes, which a
template builds (the first page, “An answer of a new shape is built by
`get`”, its laws `:buildsAShapeByATemplate` and
`:buildsTheShapeOfEachElement`, and “the shape of an answer is written as
the literal it takes”), the value beneath the tags (“its tags from the
outside in, then the shape beneath them”), the keys of a map (“its keys
are the shape that travels with them”, `core/lib/qlang/map.qlang`), the
quote of [QSLIT#atoms], the values the runtime reads (“the shapes it reads,
`::fn`, `::kind` and `::builtin{}`”, [QSHST#source]), the refusal of a
literal that computes (“a shape computed is built by `get`”,
`core/src/grammar.peggy`) and `shapeKindOf` of `core/src/ordering.mjs`;
and the word `shape` answers the schema of a value under `::shape`, the
latest of them, while the tasks of the benchmark ask each answer in the
habitual sense, “Expected shape: a JSON array of strings.”
(`scripts/benchmark/tasks.mjs`). Two laws of the first page stand side by side in the two
senses, `:looksAtTheInput`, “The keys of the first element show the shape
of the input.”, and `:looksAtTheShapeOfTheInput`. The maintainer asked
of it, «просто тут вопрос .. шейп это ответ глагола и шейп конкретного
литерала .. может оно разное ... понимаешь?..» (maintainer, 2026-10-15
16:32, session 70702c43). Outline is `paths` in the catalog and
[QSPTH#verbs], and `shape` in the aim and [D327].

```qlang
> get [~("[(1 | add 2)]" | parse !| get /message) ~([1] | shape)]
["a literal computes nothing: a shape computed is built by `get`, its parts paths and quotes, write `get [~(1 | add 2)]`" ::shape[::number]]
```

**13. The refusal of what a holder takes is named two ways.** An input,
an answer, a payload and an element are refused as `…/KindNotTakenError`
and its kin, the subject of a word as `…/SubjectNot<Label>Error`, and the
subject of a function `apply` runs as `…/SubjectKindNotTakenError`
(`subjectRefusalAddress` and its kin in `core/src/runtime/nouns.mjs`):
two refusals with facts of their own, the refusal by the kinds of a holder
carrying `:expected` and the refusal by residence none, as [QSERR#site]
tells them apart, so one name would write that rule anew. A third stands
beside them: a payload of the wrong kind for the record of a step,
`::call`, `::bind` or `::construct`, is refused as
`…/PayloadNotSchemaError` with `:field` null and no `:expected`, “the
field the refusal names is null when the payload itself is no Map”
(`recordConstructor` in `core/src/runtime/quote-steps.mjs`), where
`::fail` and `::group` refuse it as `…/PayloadKindNotTakenError` with
`:expected` (`wrapperConstructor` there), the schema of each record a
table of predicates of the JavaScript [QSQUO#step] since the steps took
their constructors (2a4bae35).

```qlang
> get [~("x" | add 1 !| type) ~(1 | add "x" !| type) ~("x" | apply (::fn | on |~~ A number. ~~| ::number | impl ~(add 1)) !| type)]
[::number/add/SubjectNotNumberError ::number/add/addend/KindNotTakenError ::fn/call/SubjectKindNotTakenError]

> get [~(::call[1] !| get [~(type) /field]) ~(::fail[1] !| get [~(type) /expected])]
[[::call/PayloadNotSchemaError null] [::fail/PayloadKindNotTakenError #[::quote]]]
```

**31. Wrapper.** The code calls two things a wrapper: the holder of a tag
over a payload that is no bare vector or map, “is held by a wrapper,
which `payload` opens” (`makeTagged` in `core/src/types.mjs`), whose class
is `'underTag'`, a third name (`isValueClass`), and the steps `::fail` and
`::group`, “the wrappers a step takes on the fail track or in
parentheses” (`core/src/types.mjs`), “A wrapper's payload is the quote of
the step it wraps” (`wrapperConstructor` in
`core/src/runtime/quote-steps.mjs`); the language says a value under a tag
([QSLIT#tag]) and names the steps by their tags ([QSQUO#step]).
