# D341 · Open: one thing under many words, and one word over many things

Domain. Language.
Question. Which things of the language go by several words across the
texts that state what holds, the code, the tools and the cases, and which
word names several things, so that a reader takes one thing for two or two
for one; and which word is kept for each? Each part below gives the words,
where each stands, the earlier layer where the history keeps it, and a
probe or a command that shows it; the roads stand under `Alternatives.`.
[QSWRK#code] asks the code to name each thing as the language names it,
and the principle of [the aim](AIM.md#principles) that words carry
paradigms weighs which word a reader trained on other languages reads
right. A word the maintainer chose stays the maintainer's to change. The
audit that found them is [D342]; its other records are [D338], [D339]
and [D340].

Each anchor names a file and the words it holds; the tree is that of this
record's commit, on the branch `the-trail-as-frames` over the baseline
e90d39b3. A count is answered by the command written beside it, which the
gate does not run.
