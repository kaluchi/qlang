# D344 · Open: the trace of frames held against the older layers

Domain. Language.
Question. Which texts and mechanisms of the trace of frames, which [D337]
wrote over the path of stops before it, still stand on an older layer, and
is each repaired where it stands, rebuilt, or written as a rule of its
own? Each part below tells what the tree holds, where, the earlier layer
where the history keeps it, and a probe; the roads stand under
`Alternatives.`. Each anchor names a file and the words it holds; the
tree is that of this record's commit, on the branch

the fields of a kind, the frame's among them.

**2. Where a step failed is spelled three ways.** A refusal at an
element names its index or its key by a fact, `:index` or `:key`, a
number or a keyword, and its frame names no place; a word whose code
failed on a part names the place in its frame, a path, `/1` (`atPlace` in
`core/src/eval-trace.mjs`); and `update` names a path both ways, the path
its read missed by the fact `:path` and the path its code failed on in its
frame. The index or the key of one element is spelled both ways by one
word: `verdictOf` in `core/src/runtime/vec.mjs` spreads it among the facts
of `ConditionNotBooleanError` where the condition answers no boolean and
hands `segmentOf(at)`, a segment of a path, to the frame where it fails,
from the facts `{ index }` and `{ key }` that `indexed` and `keyed` build.
[D360] holds index, key, segment and place as words.

```qlang
> get [~([1 2] | filter ~(add 1) !| get [/index ~(trace | last | place)]) ~([1 "x"] | filter ~(add 1 | gt 1) !| trace | last | place) ~({:a 1} | update /b/c ~(add 1) !| get [/path ~(trace | last | place)]) ~({:a {:b "x"}} | update /a/b ~(add 1) !| trace | last | place)]
[[0 null] /1 [/b/c null] /a/b]
```

**4. Three facts of a call are kept by the identity of the error it
received.** The place a word's code failed on, the node whose own fault
raised a failure, and whether a raise resumes the trace a map wrote, are
kept on the error value itself, `PLACES` and `RAISED_BY`, maps weak by the
error, and `RESUMING_THEIR_TRACE`, a set weak by it (`atPlace`, `raisedBy`
and `resumingItsTrace` in `core/src/eval-trace.mjs`), each read by the
step that receives that very value, where [QSWRK#code] has “a fact of a
call is kept by the call and never by a value it received”; an equal value
carries none, “a fresh value that carries no mark” (`withTrace` there).
`RAISED_BY` and `RESUMING_THEIR_TRACE` came with the path of stops
(a8cb6c67), `PLACES` with the frames (6728d783).

**5. The value refused is read in one of two places, chosen by an
equality.** A refusal a primitive throws leaves `:actualValue` out where
it equals the subject the first frame holds,
`name === 'actualValue' && deepEqual(value, subject)` in `errorFromQlang`
of `core/src/error-convert.mjs`, and writes its `:actualType` in any case,
as [QSERR#site] has it; so the value refused is read by `/actualValue` or
by `/trace/0/0` as an equality decides, and where an input is refused the
first frame holds the subject while `:actualType` names the value of the
input. The leaving out came with the repairs of the first check of the
chapters (1bef7db7).

```qlang
> get [~("x" | add 1 !| get [~(keys) /actualType ~(trace | first | subject)]) ~(1 | add "x" !| get [~(keys) /actualType /actualValue ~(trace | first | subject)]) ~(2.5 | range !| keys)]
[[#[:actualType :trace] ::string "x"] [#[:actualType :actualValue :expected :trace] ::string "x" 1] #[:actualType :trace]]
```

**6. The frame is built by hand.** `::frame` is a vector whose indices a
reader reads by five words written by hand, `subject` `~(get /0)`,
`unfinished` `~(get /1)`, `failed` `~(unfinished | take 1)` and `skipped`
`~(unfinished | drop 1)` over it, and `place` `~(query /2)`
(`core/lib/qlang/frame.qlang`), its layout held by one invariant over its
indices, `holds :PayloadNotSubjectAndStepsError`, where a field `reads`
declares lays a node of kinds no word reads ([D326]); and the code spells
the layout by position, `makeFrame` in `core/src/types.mjs`, `skipping` in
`core/src/eval-trace.mjs`, and `framesOf` and `partsOf` in
`core/src/elide.mjs`, `[subject, steps, place = null]` and `value[0]`.

```qlang
> [::frame/subject ::frame/unfinished ::frame/failed ::frame/skipped ::frame/place] | map ~(binding | get /value | get /1)
[~(get /0) ~(get /1) ~(unfinished | take 1) ~(unfinished | drop 1) ~(query /2)]

> :P |~~ P ~~| (::kind | wraps |~~ v ~~| ::vec | reads :a |~~ A ~~| /0 ::number) | get [~(::P[1] | a !| type) ~(::P/a | binding | get /value)]
[::call/UnknownNameError ::number]
```
