Decision.
- The name of a case says the rule it shows in the words of its chapter,
  as [QSWRK#cases] asks, `and-answers-true-where-both-hold` in the place
  of `and-both-true`: each case of the sections above whose name says no
  rule, a name of three words or fewer and a name that names a verb, a
  form or a refusal alone, is written anew as its rule, its query and its
  answer unchanged, and a name of the suite holds four words at least.
- Each case renamed opens with this record until the move, and its old
  name stands below among the cases named anew.

```sh
$ git grep -h -o -E '"name":"[^"]*"' -- core/test/conformance | grep -c -E '^"name":"[^-"]+(-[^-"]+){0,2}"$' || true
0
```
