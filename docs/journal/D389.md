# D389 · A refusal names a kind only where its address names it: every other refusal of a kind is named by the role of its holder, the kinds the fact `:expected`

Domain. Language.
Decided by. The maintainer, who chose for the holders of a function and a
kind the name by the role with the kinds as `:expected` [D287], asked the
same of the names the primitives give, held by a lint, and put the check
with the lints and the suites, with no list beside it; the names, the
facts, the reach of the rule and the check are the model's.
Overrides [QSERR#site], [QSBLD#fn], [QSBLD#kind], [QSBLD#label], [QSCND#boolean], [QSCND#branch], [QSCND#quantify], [QSCOL#algebra], [QSCOL#filter], [QSCOL#reduce], [QSCOL#sequence], [QSDSP#residence], [QSHST#source], [QSLIT#tag], [QSNAM#root], [QSORD#set], [QSPRN#span], [QSPTH#verbs], [QSPTH#write], [QSSLF#axis], [QSSLF#doc], [QSSLF#page], [QSTXT#match], [QSTXT#split], [QSWRK#tooling]
Decision.
- A refusal is public: a catch, a law and a page compare its address. The
  words of its last name after `Not` name a kind only as the label its
  subject resides on, `number/add/SubjectNotNumberError`, which the runtime
  writes from that one label, or as the kind a conversion of its address
  reads, `string/toNumber/TextNotNumberError`; a place after `NotIn`,
  `path/KeyNotInMapError`, names none the value is not. So the name moves
  only with the word.
- Any other refusal of a value of none of the kinds its holder takes is
  named by the role of the holder, the kinds the fact `:expected`, a set of
  tags: an element of the subject a verb reads, `…/ElementKindNotTakenError`
  of `sum` and `avg` over a vector and a map, of `join`, of `union`, `minus`
  and `inter` over a vector, of `zip` over a vector and a set and of
  `toPath`; the answer of a condition a verb runs,
  `…/ConditionKindNotTakenError` of `filter`, `every` and `any` over a
  vector and a map and of `allOf`, `anyOf` and `cond`, beside the input of
  `if`, `::any/if/condition/KindNotTakenError`; the answer of the code of
  `replace`, `string/replace/with/AnswerKindNotTakenError`; the tag of the
  pair `tag` takes apart, `any/tag/PairTagKindNotTakenError`; an element of
  a doc, `doc/ElementKindNotTakenError`; a name `doc` reads in turn,
  `any/doc/anchor/NameKindNotTakenError`, apart from an element of a set of
  anchors, `any/doc/anchor/ElementKindNotTakenError`; a row of `table`,
  `vec/table/RowKindNotTakenError`; the subject of `out` and `err`, verbs
  of `::any`, `…/SubjectKindNotTakenError`; the constructor of a kind,
  `kind/ConstructorKindNotTakenError`; the recipe of a function,
  `fn/RecipeKindNotTakenError`, and the recipe `fill` writes into,
  `fn/fill/RecipeKindNotTakenError`, refused as the part of its subject it
  is; and the address a module of the runtime registers a primitive under,
  a defect, `builtin/AddressKindNotTakenError`. The first law of each shows
  its `:expected`.
- An invariant names the roles of what it holds, a point
  `point/PayloadNotOffsetLineAndColumnError` and a span
  `span/PayloadNotStartAndEndError`, and a refusal that names a condition
  and no kind names the condition: a tag that addresses a name holding a
  value of its own is `construct/TagNamesAValueError`.
- `check:conventions` refuses, of every address the code declares, a
  refusal, a defect and a failure of the embedding alike, read as it reads
  the factories of an address, and of every one a page of the catalog
  throws or holds, read by the parser, a last name that names after `Not`
  a kind the catalog declares in neither place its address names it; it
  runs with the lints of the gate, `npm run ci`.

Set aside.
- The names as their writers gave them: a contract a new kind breaks.
- The label refusals and the conversions named by the role as well: their
  kind is the word's own, which moves only with the word, and a check that
  reads the address holds them.
- The kinds of the elements of a subject declared in the chain, which the
  call would hold as it holds an input of each element's kinds: a command
  more, or a second reading of `on`, and the order a fold refuses in, the
  kind, the pair and the tags at each element [QSCOL#sequence], given up;
  the kinds a word's code tests and writes again as `:expected` stay with
  that question in [D329].
- A check by a list of the names it refuses: a list kept beside the names.
- A hook of the session that ran the conventions before each commit of its
  shell: no one asked for it, it started a process at every call of a
  shell, and it read the checkout its script stood in, not the one a
  commit was made in.
- A list of the factories of what no catch meets, which the check left
  out: the classes of the core spelled again by the names of their
  factories beside them; the rule holds for every address.
Requirements. The cases named for this record,
`fill-refuses-a-function-whose-recipe-is-no-code` written again as
`fill-refuses-a-recipe-that-is-no-quote-at-its-place`; the laws of the
pages of the refusals it names anew; the check of the conventions and its
tests, `a refusal names a kind only where its address names it`.
