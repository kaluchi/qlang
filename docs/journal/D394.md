# D394 · A clean reader runs at the effort `max` unless its run names another, a child and an author of the benchmark at `high`, each set by the environment of its start

Domain. Process.
Decided by. The maintainer, whose words it quotes, for a reader at the
maximum unless its run names another and for the benchmark kept to the
conditions it measured. The model's are the level `high` the benchmark
keeps, the effort set by the environment of the start, and the line of the
head and of the run that name it.
Overrides [QSWRK#review], [QSWRK#measure]
Decision.
- A clean reader of the research runs at the effort `max`, or at the one its
  run names by `--effort`, one of `low`, `medium`, `high`, `xhigh` and
  `max`; any other level stops the run before a reader starts. The head of
  its report names the effort in a line of its own.
- A child and an author of the benchmark run at the effort `high`, which no
  run changes, and a run fixes it among the environment its child was
  started with.
- `CLAUDE_CODE_EFFORT_LEVEL` in the environment of the start sets each,
  over every flag of the command line and every settings file, so the
  effort of the session that starts them reaches none of them.

какой-то конфиг запускающий их .. и можно было его оверрайдить парамтером
запуска...» and «там были запуски соннетов - те пусть запускаются с теми же
дефолтами, это для чистоты экспериментов, здесь условия менять нельзя... а
вот прочие аудиты запускаемые чере claude -p должны запускаться на максимуме
по умолчанию .. иначе мало в этом смысла, когда нас ревьювит более слабый
агент...» (maintainer, 2026-10-20 23:31 UTC, session 64e8ee3a). Before them
the session read in the transcripts of the machine the effort each request
sent. Every reader the scripts started from 2026-10-12 to 2026-10-20 ran at
`medium`, the default of `claude-opus-5-5`, since `--restricted` reads no
settings file, while the agents of a workflow and the subagents of a session

default, `high`; the command line 2.1.302, which the machine took on
2026-10-17, sends `medium` for it under the same flags. A child the session
started on 2026-10-20 with `--effort high` and `CLAUDE_CODE_EFFORT_LEVEL=low`
in its environment ran at `low`, and `claude-haiku-4-5`, which takes no
effort, was sent none under `--effort high`.
Set aside.
- The default of the command line for a reader, `medium`, under which a
  reader weaker than the session reviews its work.
- `--effort` alone, which a `CLAUDE_CODE_EFFORT_LEVEL` of the session
  overrides, so the head would name an effort its reader did not run at.
- A file of configuration beside the scripts, a second place for the effort
  the module that starts the readers names.
- The benchmark left to the defaults of the command line, which moved under
  the condition the sets V and W measured.
