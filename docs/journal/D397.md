# D397 · Every host prints every answer within one budget, an answer past it refused as `::qlang/AnswerBeyondBudgetError`, and a host's word reads the state of its call by the mark the core hands it

Domain. Host.
Decided by. The maintainer decided the bound, in the words [D327]
quotes: it belongs to the print of the host, one budget holds every
answer and is never smaller than the first screen, an answer past it is
an ordinary failure and no elision, no flag of the command line cuts an
answer, and `out` is the door a query opens itself; and he asked the
batches pushed through, «остальное по консилиуму дожимай» (maintainer,
2026-10-21 01:19, session 4fde8c60). The model's, on the roads the
consilium chose for D327 parts 3 to 7 and for D340 part 7,
`docs/journal/research/design-check/D327~2.md` and
`docs/journal/research/design-check/D340~2.md`, each with its checker's
repair: the size of the budget, the address and the facts of the
refusal, the road by which a word of a host reads the state of its call,
which decides [D293], and the print of each host.
Overrides [QSHST#answer], [QSHST#effect], [QSHST#repl], [QSHST#tools], [QSHST#source], [QSPRN#print], [QSERR#site], [QSSLF#manifest], [QSNAM#root]
Decision.
- Every host prints every answer through one print of the core within
  one budget, sixteen thousand characters of the print counted before a
  host paints it, a constant of the core beside the excerpt of an alert
  and the head of an elision, never smaller than the first screen,
  `[::qlang ::cli] | map ~(get [~(it) ~(doc)])`, which the command line
  prints whole.
  - An answer whose print fits prints whole, a string as its text where a
    host writes one so.
  - An answer past the budget is not cut: the host prints
    `::qlang/AnswerBeyondBudgetError` in its place, an ordinary failure
    under the line `|~| raised, and no !| caught it` and above the prose
    of its page, which exits as every failure does, 0, and 1 under
    `--fail`.
  - A failure prints as its alert within the budget [QSHST#answer].
- The refusal stands under `::qlang`, the topic of the language, whose
  chapter of hosts tells the budget, and `::qlang | manifest` lists it
  beside the chapters. No step raises it and no `!|` reaches it: the host
  raises it after the last step of the query. Its facts are
  `:characters`, the characters of the print, and `:budget`, then
  `:actualType`, the kind of the answer, and `:actualValue`, the answer
  cut to the excerpt of an alert, the `:read` of each elision there
  continuing the query from the answer, `~(drop 12)`. Its page is the
  repair: the answer narrowed by `get`, `take`, `keys`, `count` or
  `shape`, or written whole through the door a query opens itself,
  `print | out` or `json | out`.
- No flag of the command line sets or cuts the budget: `--budget` leaves
  the command line and its REPL, and an argument before the query that
  opens with two dashes and names no flag is refused with a usage line
  and the code 2, since no query opens so. `elide` stays the word a query
  cuts a value with on purpose, and `print` answers the whole text.
- A query that wrote by `out` holds the channel: the host makes no print
  of its answer and raises no refusal of one, and its code is the one its
  answer exits with, a failure the query answered exiting with 1 under
  `--fail`.
- `tap` writes `[tap <label>]` and the print of its subject on standard
  error as a host prints an answer, the print a kind declares among it,
  within the budget, and past the budget the refusal in their place, its
  reads continuing the query from the subject at the `tap`; the query goes
  on with the subject as it came, and `err print` writes a look whole.
- A word a host hands reads the state of its call as a word of the core
  does: the core hands the mark `readingState`, and a primitive so marked
  takes the state after the values of its inputs. The marks of the inputs
  a primitive runs as code stay the core's, a word of a host taking a
  quote as the data it is.
- The command line prints an answer through the one print in a script and
  in its REPL, whose alert stands without the prose of its page, and so do
  the playground and the REPL of the site, a failure as its alert under
  the line that says it was raised. The language server prints no answer.
- A cell of `table` writes its value on one line by the printer's own
  form: a quote its steps on one line, which read back as the same steps,
  and a doc its prose with each line break written as a space, a view at
  the boundary its page names. No host lays a print on one line by a
  pattern over its text.

$ qlang '3000 | range | map ~(get {:id ~(it) :name "user"})' < /dev/null | grep -o -E ':(characters|budget) [0-9]+|::elision\{:size [0-9]+ :read ~\(drop [0-9]+\)\}'
:characters 70891
:budget 16000
::elision{:size 2988 :read ~(drop 12)}
$ qlang '3000 | range | map ~(get {:id ~(it) :name "user"}) | json | out' < /dev/null | wc -c
76892
$ qlang --fail '5000 | range' < /dev/null > /dev/null; echo "exit $?"
exit 1
$ qlang --budget=100 '1' < /dev/null 2>&1; echo "exit $?"

exit 2

Set aside.
- A view of an answer past the budget printed in its place, which makes
  the limit of the print an elision, against the maintainer's word; a
  wrapper a query lays over its answer, `elide :off` or a budget asked
  larger, where `out` is the door already; a budget of the words, `shape`
  and `paths` answering by the host they run under; a budget only where
  it is asked, which floods a reader who forgets it; and a budget read
  from the first screen at each start, which moves with every sentence of
  the first page.
- The refusal under `::elision` or under `::builtin`, the first making the
  limit an elision and the second a defect no reader repairs, and the
  fact `:size`, which an elision counts parts by.
- `tap` written in the language over `err` and `print`, whose print
  passes the budget whole; `tap` printing by the scope of its session,
  which misses a `print` the query declares; and `printValue` taken out of
  the package, the literal that reads back, which the codec of JSON, the
  fuzz of the gate and a host that writes a literal read.
- The marks of the inputs a primitive runs as code handed to a host, a
  second spelling of the names its function takes outside the catalog,
  which no host asks for.
Requirements. The tests of the command line, of the site and of the
