# D402 · The command line lifts its input by the word `parseJson`, a query headed by `in` lifts nothing, and `--json` leaves

Domain. Host.
Decided by. The model, by the consilium on [D340] parts 10 and 11,
`docs/journal/research/design-check/D340~2.md`, which the maintainer
handed the open records to, and on his word to take the questions of the
consilium in hand alone, which the source quotes; `--raw` and the help of
the command line printed as the page of `::cli`, which the same road took
out, wait for his word in [D340].
Overrides [QSHST#stdin], [QSHST#answer]
Decision.
- JSON text has one reader, the word `parseJson`, whose primitive tells a
  text that is no JSON and reads the rest in the order it writes its keys;
  the package exports no second road to it.
- The command line lifts the text standard input holds by that word:
  before the query it runs `parseJson` on the text in the session of the
  query, as a cell the session numbers not, so the query stays `:cell-1`.
  A text that is no JSON stays the string it is, and any other refusal, a
  number past the doubles among them, is the answer, as `parseJson`
  answers it.
- A query whose first step that declares nothing is `in`, the word of the
  command line that reads standard input as it came, called by its name
  or its address, `any/in`, reads no subject and lifts nothing, so
  `in | count` counts the characters of any text and `in | parseJson`
  reads it as JSON alone; `readsItsSubject` takes the names of the words
  of a host that read no subject.
- `--json` leaves the command line, refused as every argument that opens
  with two dashes and names no flag; `in | parseJson` is its read.

```sh
$ printf '[1e400]' | qlang 'in | count'
7
$ printf '[1e400]' | qlang 'any/in | count'
7
$ printf '{"a":7}' | qlang 'in | parseJson | get /a'
7
$ printf '[1e400]' | qlang 'count' | grep -o '::string/parseJson/NumberNotFiniteError'
::string/parseJson/NumberNotFiniteError
$ printf '{"a":7}' | qlang --json 'get /a' 2>&1; echo "exit $?"
qlang: --json is no flag of the command line, which `qlang --help` lists
exit 2
```

Set aside.
- `--raw` leaving with `--json`, the consilium's road, for which the
  eleventh outside audit voted to keep it, the measure reading a text of
  its tasks by it: the maintainer's word on the flag.
- `qlang -h` printing the page of `::cli`, the consilium's road, which
  leaves the budget of every answer, which the usage writes from the
  constant of the core, no text to name it: the maintainer's word on the

- The lift calling the reader of the core from the command line, the
  second spelling the consilium took out.
