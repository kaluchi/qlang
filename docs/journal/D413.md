# D413 · A test file stands in the section of the rule its tests hold, as a file of the conformance suite does, and the title of a test cites no rule

Domain. Process.
Decided by. The maintainer, whose words it quotes, for a test file that
stands in its section as a file of the cases does and a title that is no
second description of it. The model's are the layout of the folders, the
parts of a section and the check.
Overrides [QSWRK#marks], [QSWRK#cases], [QSWRK#baseline], [QSWRK#tooling]
Decision.
- A test file stands in the section whose rule its tests hold, as a file
  of the conformance suite does, `<chapter>/<section>.test.mjs` under the
  tests of its workspace: `core/test/unit/`, beside
  `core/test/conformance/`, `cli/test/`, `cli/test/integration/` for the
  tests that run the command line in a process of its own, `lsp/test/`,
  `site/test/` and `vscode/test/`; a test of a record in force of a domain
  its tests hold, whose rule no chapter states, stands at the record,
  `core/test/unit/D404.test.mjs`. The runner of the cases stands at its
  section, `core/test/unit/QSWRK/cases.test.mjs`, and the runner of the
  laws at its own, `core/test/unit/QSSLF/laws.test.mjs`.
- A section holds one test file in each folder of tests, and a part runs
  apart in a file of its own, `<section>.<part>.test.mjs`, where it cannot
  run beside the rest: a module of Node it mocks,
  `QSHST/source.loaders.test.mjs`, the table of the primitives it meets
  before the bootstrap seals it, `QSHST/source.primitives.test.mjs`, and a
  share of a walk one worker runs too long, `QSLIT/atoms.catalog-1.test.mjs`.
- The title of a test says its rule in words and cites none: its path
  names the section, as the path of a case does, and no line of the file
  cites that section again. A helper the tests of several files share
  stands under `test/helpers/` of its workspace, a module that marks its
  rule.
- `check:conventions` refuses a test file whose path names no section of a
  chapter and no record in force its tests hold, a part among them, a line
  of it that cites the rule its path names, and the title of a test that
  cites a rule; a test file at its section is no orphan, and
  `node scripts/dissolve-records.mjs` takes a record off no title.
Source. The maintainer asked for the tests under their right marks and for
no file of tests holding a heap of them, «меня волнует что б тесты были
посажены подправильне метки и что б одном mjs-тесте не было свалки из
разных меток.. (тогда тест лучше разделить или перетасовать как-то по
другим)» (maintainer, 2026-10-21 22:55 UTC, session fb2bbca3), and
answered the path that names the section with «второго описания не надо -
метки сейчас это попытка выяснить/понять к какому разделу вообще тест
относится  .. а так да, лучше разнести конечно, как уже в конформансе
сделано..  в общем порядок на твое усмотрение» (22:59). The marks the
titles carried were the reading the session moved them by, each read
against the text of its section, a test a section states no rule of going
to the section that states it.
Set aside.
- A title that names its section in brackets, as [D409] wrote it: a second
  description of the file it stands in, which drifts from it.
- A test file per module of the code, its tests under the sections their
  titles name: a file of sixteen sections, the parser's, and a section
  spread over a dozen files, which no reader of a section can be handed.
Requirements. `check:conventions`, which refuses a test file at a path of
no section and of no record its tests hold, a line that cites the rule its
path names and the title of a test that cites a rule; every test of the
tree standing in the section of its rule.
