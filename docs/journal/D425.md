# D425 · Open: a value whose print does not read back as it, a function a host gives, a value nested past the stack and a lone surrogate

Domain. Language.
Question. What does the language answer for a value whose print does not
read back as it? The text of a value of the language reads back as it by
`parse | open` [QSPRN#print], and a cell that keeps an answer past the
budget keeps it as that text [D407], so a value that misses it is a hole
of the language, which the store of a cell meets first. A doc whose prose
the block form cannot hold is one, which [D369] holds; three more stand
beside it.

A function a host gives prints its recipe as `::builtin{}`, which names no
primitive, so the function read back from its print is equal to it by
`eq` and runs nothing:

```qlang
> ::vec/count | binding | get /value | :f it | print | parse | open | :g it | get [~(eq f) ~([1 2] | apply f) ~([1 2] | apply g !| type)]
[true 2 ::fn/RecipeMissingError]
```

A value nested past the stack of the host has no print: the printer walks
a value by that stack, `collectPrintsOfKinds` in
`core/src/runtime/print.mjs` among its walks, so `print` fails as a
failure of the host where a JSON text a host reads gives the value whole,
and the command line, whose alert prints the subject of that failure,
ends with the message of the host and no answer:

```qlang
> get [~(100 | range | reduce [] ~(get [/0]) | :v it | print | parse | open | eq v) ~(20000 | range | reduce [] ~(get [/0]) | print !| type)]
[true ::call/HostFailureError]

> :l (5000 | range | map ~("[") | join "") | :r (5000 | range | map ~("]") | join "") | l | append r | parseJson | get [~(type) ~(print !| type)]
[::vec ::call/HostFailureError]
```

```sh
$ (qlang '20000 | range | reduce [] ~(get [/0]) | print | count' < /dev/null 2>&1; echo "exit $?") | grep -e '^qlang:' -e '^exit'
qlang: Maximum call stack size exceeded
exit 1
```

The reader reads deeper than the printer prints, which on the command
line fails between nine hundred and a thousand levels: a literal nested
two thousand deep reads, and one four thousand deep is refused as a parse
failure whose message is the host's, a text of the language refused as
no text of it:

```qlang
> :l (2000 | range | map ~("[") | join "") | :r (2000 | range | map ~("]") | join "") | l | append r | parse | open | count
1

> :l (4000 | range | map ~("[") | join "") | :r (4000 | range | map ~("]") | join "") | l | append r | parse !| get [~(type) /message]
[::quote/ParseError "Maximum call stack size exceeded"]
```

A string that holds a lone surrogate, which the escape `\uD800`, a JSON
text and a host give, prints it as it is, and a text written as UTF-8
holds no lone surrogate, so its print read back within the process is the
string and its print written to a file or a stream reads back as another
string, the replacement character in its place:

```qlang
> "\uD800" | print | parse | open | eq "\uD800"
true
```

```sh
$ qlang '"\uD800" | print' < /dev/null | od -An -tx1
22 ef bf bd 22 0a
```

Alternatives. The roads, each with its cost.
- The function of a host, the road the maintainer's word of 08:19
  sketched and the model's leading reading: the root writes the address
  of the primitive into the recipe it binds,
  `::builtin{:of ::vec/count}`, the catalog
  writing `impl ::builtin{}` as it does, so a function read back finds its
  primitive by that address over the root it is read in, and one whose
  address the root binds to no primitive is refused as
  `::fn/RecipeMissingError` naming the address; at the cost of the print
  of every function of a host growing by its address, a `::builtin` that
  holds a key, and a function read back over another root running the
  primitive that root binds at the address.
- A value nested past the stack, the model's leading reading: a depth of
  nesting the language holds, a constant of its own as the depth of the
  evaluation is, `::call/EvaluationDepthExceededError`, within the stack
  of every host, five hundred and twelve levels on the reading of the
  depths above; the reader, the codec of JSON and the door of a host
  refuse a value nested past it, each by a refusal that names the depth
  and the limit, `print` refuses so a value a query built past it, and the
  layers of an excerpt end at it, a part below them showing as its least
  excerpt, so no alert meets the stack of the host. At the cost of a count
  of the depth in the reader, the printer and the walk of the doors, of a
  text of JSON nested past the limit refused, and of a value built past
  it in a query that keeps no print and no cell.
  Or the printer, its walks and the reader of literals walking by a stack
  of their own, so a value prints and reads back at any depth the
  evaluator builds; at the cost of the printer written as a loop and of a
  reader the grammar generates, which recurses by the nesting of the
  literal, where a reader of the literals of data of its own beside the
  grammar, which reads code, would read data at any depth and at the speed
  of JSON, the print of two million characters taking two and a half
  seconds through the grammar and fifteen milliseconds through
  `JSON.parse` [D407]. Or a depth the language bounds where a value is built, a check
  on every container built.
- A lone surrogate, the model's leading reading: the printer writing it
  as its escape, `\uD800`, which the grammar reads as it, so the print
  holds no code unit a text in UTF-8 cannot carry; at the cost of a look
  at each code unit of a string it prints. Or a string refusing a lone
  surrogate at its doors, the escape, the codec of JSON and the door of a
  host [QSHST#door]; at the cost of a text JSON allows refused.
- The holes as they stand, a store keeping the text the core prints and
  a cell meeting the hole where a path passes its card and reads the
  answer back.
