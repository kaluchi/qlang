# D439 · The comments of a file read by the parser of its language, one reader for the conventions, the marks and the audit

Domain. Process.
Decided by. The maintainer, that the traces of a mess the work let stand
are put in order, and that no reading of the syntax stands over the grammar
and its parser. The model's: the reader and its scope.
Overrides [QSREQ#rigor]
Decision.
- A script reads the comments of a file by the parser of its language, one
  reader, `scripts/comments.mjs`: a module of JavaScript by acorn; a source
  of the catalog by the parser of the core, its docs beside its comments;
  and the grammar by the parser of peggy, the code of its initializers, its
  actions and its predicates by acorn and a comment of the grammar where the
  parser leaves no literal, no class and no code. A file of a language the
  tree holds no parser of, a page of the site and a workflow, is read by the
  form of its comment line.
- The conventions read by it the lines a text holds and names and the
  comment of the code that is a mark, and the marks the blocks of a file;
  the audit of the pentimento reads by acorn the calls that register the
  primitives of the core.

```sh
$ node -e "import('./scripts/comments.mjs').then(m=>console.log(m.linesOfComments('core/lib/qlang/fn.qlang',require('fs').readFileSync('core/lib/qlang/fn.qlang','utf8'),{docs:true})[15].holds.trim()===''))"
true
```
Source. The maintainer, once the lexicon was held to its rule, «и как
завершишь этап этот .. поищи ещё следы легимитизированного бардака,
раздуваюшего сильно пробы и т.п. - это все кандидаты для наведения порядка
и расплетания» (maintainer, 2026-10-24 07:33 UTC, session e5931d71); on a
reading of the syntax over the parser, «мы грамматику писали, парсер .. что
за дрянь поверх него пытается вставиться..  местастаза какого-то адхука»
(maintainer, 2026-10-19 21:43 UTC, session d7f52e95). The model found three
readers of the comments of a file: the lines of the conventions, by a regex
over the lines of a module and by a lexer of the catalog written by hand;
the blocks of the marks, by a regex for each language; and the comment that
is a mark, by acorn; and the audit read the registrations of the core by a
regex. Each reading was run beside the parser's over every file it reads,
and each divergence explained: the lexer closed a doc at a doc literal
between backquotes and read the rest of its page as code, so some two
hundred and forty lines of nine pages escaped the lexicon and the check of
the names taken out, which the parser reads as prose and which hold none of
them; a line comment of the catalog opened a block for the marks, which read
the rest of the showcase of the editor as comment lines; the lines of a
template string of a generator of the benchmark read as comments; and a
block comment after code in a sensor went unread. The groups of the audit,
the blocks the marks cover and the blocks marked astray stand as they were.
Set aside. A parser of YAML and of the pages of Astro, which the tree holds
none of; and the marks read from the comments alone, which would move the
citations the pages of the catalog write in their docs out of the scope of
the marks.
