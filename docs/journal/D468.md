# D468 · Code carries the values it reads: the step that hands it on writes them in, and all code runs in its lane

Domain. Language.
Decided by. The model, on the maintainer's words: a quote is its literal,
a declaration laying it under its name as it is written, and the binder
writing visibly the names the code it binds reads, the road the session was
asked to make sure of before a verdict. The model: which code a step writes
into and what it writes there, the lane every code runs in, the refusal of
held code at the door of a verb written in the language, the head declared
once where the code is handed on, and the cases.
Overrides [QSQUO#held], [QSNAM#reach], [QSNAM#root]
Replaces in part [D257], [D281].
Decision. A quote written in a step, a modifier of its call or a part of a
template the modifier writes, a quote, an error literal or a template under
a tag among them, is code of that step. Where the step hands it to a verb
that runs it, the step writes at its head a declaration of each value of
its scope the quote reads and does not declare itself, read by its bare
name or by its tag, with the page of its record, so the verb takes the
literal of what it runs, the values it reads in it:

```qlang
> :k 10 | :vec/show (::fn | takes :q |~~ The code. ~~| /0 ::quote | impl ~(q)) | [1] | get [~(show ~(add k)) ~(show ~(add 1))]
[~(:k 10 | add k) ~(add 1)]
```

A verb runs code by an input a primitive runs, the code of `map`,
`filter`, `sort` or `if` and the templates of `get` and `query`, by any
input of a verb written in the language, whose recipe may hand it on, by
the args `apply` hands a function, and by the body and the selectors of
`with`, whose names stand over the values of the step; an input that takes
a quote as data takes it as it is written, `~(add k) | eq ~(add k)`
answering `true`. The code holds what it reads, so it runs alike by
whatever road the call hands it on, a verb written in the language among
them, and a quote a call answers carries what its step wrote into it:

```qlang
> :k 10 | :vec/twice (::fn | takes :q |~~ The code. ~~| /0 ::quote | impl ~(map q | map q)) | [1 2] | twice ~(add k)
[21 22]

> :any/keep (::fn | takes :q |~~ Q. ~~| /0 ::quote | impl ~(q)) | :k 1 | :h (keep ~(add k)) | get [~(h) ~(5 | apply h)]
[~(:k 1 | add k) 6]
```

All code runs in a lane: the subject the verb that runs it hands it, the
verbs, the nodes and the labels of the step that runs it, and the names
the code declares itself, those a binder wrote into it among them, a value
of that step withheld and refused under its name as
`::call/ValueWithheldError`. The words of the host read in code what the
code holds, `env` listing its own names and no value of the step it reads
none of, and a verb written in the language called from code reads the
tree of names of that code:

```qlang
> :vec 5 | get [~(env | has :vec) ~(vec)]
[false 5]
```

A quote the step did
not write, read from a name, computed by a group or answered by a call,
is held as it is written: a verb of the root runs it in the lane of its
step, which withholds the value it reads, and a verb written in the
language refuses it at the step that hands it on, under the name it reads
that the step names as a value:

```qlang
> :k 10 | [1 2] | get [~(map (~(add k)) !| tag) ~(:q ~(add k) | map q !| tag)]
[::call/ValueWithheldError ::call/ValueWithheldError]

> :first 2 | :big ~(take first | count | eq 2) | :vec/keep (::fn | takes :p |~~ P. ~~| /0 ::quote | impl ~(:c p | filter c)) | [[3 1 2] [1 9]] | keep big !| get [~(tag) ~(name)]
[::call/ValueWithheldError :first]
```

The trace holds the steps as the text wrote them, the declarations of the
head run before the step that failed: `:k "x" | [1 2] | map ~(add k) !|
trace | map ~failed` answers `[~(add k) ~(map ~(add k))]`. An input that a
chain declares, written into code its recipe writes, is read past a verb
of its name as the recipe reads it [QSBLD#recipe]. The declarations of the
head are declared once, where the step hands the code on, and its steps
after them run at each run of the code, the value of a declaration the
step wrote answered as itself, built once, and printed as its literal.
The evaluator keeps no record of where a quote came from: a quote is its
literal.

Of the three roots of [D257], the first is answered here, code that holds
no closure carrying the values it reads in its own literal where the step
writes them; the third, a modifier computed against the subject alone, is
answered by `with`, which names the parts of one subject for one template,
`{:a 5 :b 3} | with [/a /b] ~(a | gt b)` answering `true` [QSPTH#template];
and the second, one space of names for values and verbs, is the question
[D256] holds.
The two cases of [QSNAM#reach] and [QSNAM#root] that read a value of the
step by `env` inside a quote of a template read it by `env` at the step.

Set aside.
- The value captured where the quote is declared, `:q ~(add k)` holding
  `~(:k 10 | add k)`, the road of the eleventh outside audit: a
  declaration lays the literal under its name as it is written, and a
  capture no word of the text shows is the second literal the maintainer
  named.
- Code read in the scope of the step that runs it: the names of a recipe
  would reach the reader's code, `t ~(add k) 99` reading the input `k` of
  `t` in the place of the reader's.
- The record of origins the tree kept, a call keeping where each of its
  args came from: two quotes that print alike and are equal ran apart by an
  identity no print shows.
- Every quote of every modifier written in, an input of data among them:
  `~(add k) | eq ~(add k)` would answer `false`.
- The value of a declaration the step wrote evaluated as a literal at each
  run: it lays its tags and runs its constructors again, refuses a segment
  of a doc built raw, `::number~(~(x))`, and costs the size of the value at
  each element.
- The answer of a group written into as code of the step, `map (~(add k))`:
  a group computes a value, and a value is held as it is written.
Requirements. Every case that names this record. Of the cases it renames,
`a-quote-a-call-answers-is-held-again` gives way to
`a-quote-a-call-answers-carries-what-its-step-wrote-into-it`.
