# D474 · A `~(` of a doc is code, and one that reads as no code is refused

Domain. Language.
Decided by. The maintainer: a doc reads its `~(` one way, no reading
falling back to another where the first fails, a fallback being a second,
implicit reading of the language. The model: the refusal of a quote that
reads as no code at its place with the rule it breaks, a quote of a line doc
running on across lines as any code, the counters of the parser that leave
with the fallback, the checks of the catalog that read a page for a quote in
its prose leaving with them, and the cases.
Overrides [QSSYN#doc], [QSSLF#doc], [QSLIT#closed]
Replaces in part [D369].
Decision. A `~(` of a doc outside a span between backquotes, under the tags
written before it, is code: its text reads as the quote it writes, and a text
that reads as no code, a quote left open, steps that break a rule of a step,
a literal that computes and a number written with a leading zero among it,
is refused as `::quote/ParseError` where its reading stopped, with the
message of the rule it breaks where the grammar writes one. A prose that
shows code writes it between backquotes, `` `~(add 1)` ``, which a doc reads
as prose whole:

```qlang
> get [~("|~~ a ~(1 | ) b ~~|" | parse !| tag) ~("|~~ a ~(f 01) ~~|" | parse !| message) ~("|~~ a `~(1 | )` b ~~|" | parse | first | segments)]
[::quote/ParseError "a number is written without a leading zero: write `1`" ["a `~(1 | )` b"]]

> "|~~ see ::snippet~([(1 | add 1)]) ~~|" | parse !| message | contains "a literal computes nothing"
true
```

A quote of a line doc runs on across lines as any code does, and the prose of
the doc runs on to the end of the line the quote closes on:

```qlang
> "|~~| see ~(5\n  | add 1) and more" | parse | first | segments
["see " ~(5 | add 1) " and more"]
```

The parser reads a quote of a doc as it reads any quote, so the depth of a
quote of a doc it counted, the look ahead of a declaration read whole inside
one and the span of a line doc read as prose leave the grammar with the
fallback, and a failure a nesting form met at an offset is kept by the
offset alone [D404]. A page of the catalog whose quote reads as no code
fails its source, so the checks that read the prose of every page for a
`~(` left in it leave.

Set aside.
- The prose reading whole, the refusals the grammar passes over inside a
  quote of a doc failing the try as the others do: the reading the
  maintainer names a second, implicit one, and a slip that turns a link or
  a snippet into prose in silence.
- A quote of a line doc closed on its line, one of several lines refused:
  with no prose to fall to, the line served no reading, and the closers that
  complete a source cut short could no longer be found past it.
Requirements. Every case that names this record.
