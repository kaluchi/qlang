# D493 · A page is written into the Markdown of the editor as its prose reads

Domain. Tooling.
Decided by. The maintainer, who met a page struck through in a hover; the
model's: the cause and the escape.
Overrides [QSLSP#reach]
Decision.
- The server writes the prose of a page, and of the docs of a reader's
  declaration, into the Markdown of a hover and of the documentation of a
  completion as it reads: each sign of punctuation of Markdown outside a
  span between backquotes escaped, a span between backquotes kept as
  written, so the editor shows a code span as code and every other sign as
  itself. A pair of tildes struck the prose between them, as GitHub's
  Markdown reads `~…~`, and `::snippet~(…)` and `::link~(…)` write one each,
  so the page of `::tagged` showed the prose between its snippet and its
  first link struck through and the tildes gone.
- The help of a signature, which the editor shows as plain text, keeps the
  page as its content reads.
Source. «ещё в :tagged и не только внутри доков почему-то зачеркивание
какое-то применяется ... откуда оно? markdown правила такие?» (maintainer,
2026-10-29 11:27 UTC, session 74e933c0), beside a picture of the hover of
`::tagged`.
Set aside.
- The signs of Markdown escaped one by one, the tilde, the star and the
  underscore: a sign left out is the next page struck, bolded or listed, and
  every sign of punctuation reads back as itself when escaped.
- The hover sent as plain text: the code spans of a page and the form of a
  call lose their marks.
Requirements. The test of the server that a hover writes the prose of a page
with each sign of Markdown escaped and a span between backquotes as written.
