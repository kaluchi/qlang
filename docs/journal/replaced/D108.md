# D108 · The code of a doc takes its role from the tags over it: a link opens a page, a snippet shows a query to run

Left at 95a0454d, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 95a0454d:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, on the model's proposal of `::link` over a
quote, his questions of a second role and of a stack, and his word for
`::snippet`. The model's: the general stack, the role of each tag, a
link that answers a page, and the check that follows every link.
Decision. A doc holds prose, quotes and quotes under tags, a stack of
any depth, `::link~(…)`, the form a quote under a tag has in code [D20];
the grammar of a doc reads the stack before a quote. A quote with no tag
is code the prose holds; a tag gives the quote a role, each tag of the
stack its own, read from the outside in as the tags of any value
[D34]. `::link` is a query a reader follows, which answers a page, a
doc: `links` answers the segments of a doc whose stack holds `::link`, a
host's tag over it among them, so `links | map ~open` over a page answers
pages alone and `map ~content` reads them, and the suite follows every
link of every page of the catalog, the pages of the concepts among them,
and fails on one that answers no doc. `::snippet` is a query a page
shows its reader to run and see, `::snippet~({:a [5 6]} | get /a/-1)`,
answering whatever it shows, where a law answers true and a link opens a
page [D175]. `::link` and `::snippet` are kinds of the core with a page
and no constructor, and a role that asks for its own check comes as a
kind of its own, with no change to the grammar or to the doc. `open` is
a word of `::quote` and runs a quote beneath whatever tags stand over
it, so a link and a snippet open alike. A query that lists or shows
something, `::vec | manifest`, stands in the prose as a snippet or as
code with a sentence saying what it answers. `content` and the print of
a doc write each stack before its quote, so a doc reads back as itself
[D96]. A mention in backticks stays prose, for a fragment that is no
query; a query a page names to be followed is a link.

Set aside. A link that stores the answer it showed, which a host
computes when it shows the link and which would go stale in the page. A
link to a listing, which `links * open` mixed with the pages it opened.
A filter by `type` after every fan-out, which each reader would write
again.
