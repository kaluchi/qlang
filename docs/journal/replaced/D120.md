# D120 · The command line answers whole, and a budget is asked for

Decided by. The maintainer, that no budget surprises a reader unasked;
the flag, its one number and the refusal of an argument after the query
are the model's.
Decision. The command line prints an answer whole, in script mode and
in the REPL alike, and applies no budget of its own. A budget is asked
for: in the query, `| elide 4000`, which answers the value within four
thousand characters of its print, and on the command line,
`--budget=N`, which a caller that reads answers into a context of its
own, a model's harness among them, passes to print every answer within
N characters, a failure among them. What gives way is an `::elision`
marker, whose `:read` continues the query to the part left out, so an
elision appears in an answer only where a reader asked for it, the
alert of a failure aside [D7], and the first screen says how to ask
before any answer meets one. `-i` takes a query after it, `qlang -i
'::qlang | doc'`, which the REPL runs as its first cell before it
prompts, the session and its bindings staying for the cells after. An
argument after the query is read by nothing and is refused,
`qlang '1 | add 1' --budget=10` answering a usage error that names
where the flags stand, so a flag written there is never left unread.
