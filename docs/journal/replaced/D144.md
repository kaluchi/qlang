Domain. Command line.
Decided by. The model, at the maintainer's word on the repairs it takes
on its own, on its proposal to run the children of the benchmark with
the conversion off, and on what the children stumbled on.
Decision. Under MSYS, the shell beneath Git Bash, whose `MSYSTEM` names
it, a query that begins with a drive and a slash and with the root of
the shell, the nearest directory of its path that holds the runtime
`usr/bin/msys-2.0.dll`, is read from the slash after that root:
`qlang '/data/users | segments'` arrives as `C:/Program
Files/Git/data/users | segments` and runs as `/data/users | segments`,
the initial query of the REPL alike. No source of qlang begins with a
drive and a slash, so a query that does was written by the shell. A
query the command line cannot read back, under another shell or with no
runtime on its way, and that fails, gets a line on standard error that
says so and names the two ways around it: a read begun with its word,
`get /data/users`, which the shell leaves alone, and
`MSYS_NO_PATHCONV=1`; the answer and the exit code stay as they were.
The reading is the command line's, at the boundary where the shell
hands its arguments, and the core reads no path. A child of the
benchmark runs with `MSYS_NO_PATHCONV=1` in its environment, which turns
the conversion off, and its record holds the environment it ran in
[D26]; its prompt keeps its line on the prefix, since a prompt changed
between two measurements makes them two experiments.

Set aside. A refusal of the parser for it, which knows no shell. The
`export` allowed among the tools of a child, which keeps the cost of a
prefix the language does not need. A reading in the language of a path

launcher of Git for Windows and which MSYS2 sets otherwise; and asking
`cygpath`, a process at every such call.
