Decision. What a host loads and what a source declares are two things,
and the language knows only the second: a host hands its sources and the
implementations of their words [D72], and nothing else of it takes part
in a query.

A word takes the address of its first declaration and resides on the
noun of that address when the noun is a label, so a value of the label
finds it by name through the walk of its tags [D72], whoever declared
it, and it takes its subject by the walk of its tags [D34]. The command
line declares `:vec/table` and `:any/out`, and a reader declares
`:Box |~~ A box. ~~|` and then `:Box/area ~(…)` in the cells after it.
A host's word is a function whose recipe is `::builtin{}`,
`impl ::builtin{}`, or the value `::builtin{}` of a name under a label,
which calls the implementation the host handed beside its source under
the name it declared: the root refuses, as it is declared, a
`::builtin{}` the host handed nothing for and an implementation handed
for any other name. A `::builtin{}` written in the recipe of a word a
reader declares is the value it is [D34]. The kernel is the evaluator
with its table of primitives and the shapes it reads, a word's `::fn`,
a kind's `::kind` and the recipe a host implements, `::builtin{}`, which
the catalog documents rather than defines [D251], [D252].

`manifest` answers the nodes declared one name under a noun, and a
helper several words share is a node under their noun. The language
server answers goto-definition by the reach of a bare name
[QSNAM#reach]. The root sits beneath the frame of a reader's names under
a key no name spells, so a declaration copies the frame alone. The
language lists its sources once, `LANGUAGE_SOURCES` in
`git show 95a0454d:core/src/runtime/bootstrap.mjs`, which the bundle of the site and the
language server read, and every source is read whole when the runtime
starts, since the refusals that name where a word lives and the names a
guess is held against read every kind.
