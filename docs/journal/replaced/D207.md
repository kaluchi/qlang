Overrides [QSWRK#code].
Decided by. The maintainer, on the names the model laid out to him.
Decision. The code of the core names the value of a tag, `::Box`, a tag,
as the language names it: `makeTag` makes one and `isTag` tells one,
both of which the core hands its hosts; the node of a tag written alone
is `TagLit`, beside `TaggedLit`, and its evaluator `evalTagLit`; the
brand of the value's class is `tag`; and the kind of tags is
`CORE_KIND.tag`, with no constant of its own. The names of an older
model, which called a tag a type keyword, `makeTagKeyword`,
`isTagKeyword`, `BareTypeKeyword` and `TAG_BINDING_TAG`, leave the core,
the command line, the language server, the editor's grammar and the
sister project.
Source. The outside audit of 2026-10-10 named them among the scars of
older models (`git show 80a499d9:docs/research/outside-audit/2026-10-10.md`, 3.8). Asked
who had asked for the rename, the model answered the audit and laid out
the names: «окей, давай так» (maintainer, 2026-10-11 14:05, session
22b934f8).
Set aside. The names as they stood, which keep the older model before
every reader of the code; and a rename that leaves the sister project
behind, which calls `makeTag` through the core's surface.
Requirements. No name of the older model in the sources, the tests and
the tools of the tree or of the sister project; the tests of the core,
the command line, the language server and the sister project hold the
renamed surface.
