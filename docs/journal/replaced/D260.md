# D260 · Open: the pressure for a second format

Domain. Host.
Question. Clojure answered the slowness of parsing its notation in
browsers with Transit, the same model written over JSON and MessagePack,
and so kept two formats of one data. The site's playground and any host
that speaks HTTP will feel the same pressure; the cost is paid in
parsing speed at the boundary, and it has not been measured.
Source. The audit, which held it in its open chapter from its first
version.
Alternatives. The literal or plain JSON and nothing between, as the
principle of the audit says; or a second format of one model, as Transit
is, at the cost of two spellings of every value.
