# D271 · Open: an expert that answers a set in one call from the whole self-description of the language

Left at ff31d9e4, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show ff31d9e4:<path>`, not in today's.

Domain. Benchmark.
Question. The measure of the mission is a fresh model that writes a
correct query on the first attempt, and a child of the benchmark [D26]
reaches its answer in the loop: it reads the screen, asks the language
for more, runs its queries and repairs them by the refusals it meets, so
a run that solves every task, as each run of [D270] did, does not tell
how many of its first attempts were right. An expert that answers every
task of a set in one call, its context the whole self-description of the
language, the first page, its chapters and the catalog as it is written,
every page, chain and law, with the inputs of the set, and no tool to
run, would tell whether what the language says of itself is enough for
a first attempt, its queries graded as a child's final queries are. It
would not tell what the progressive disclosure the screen opens saves,
which the children in the loop measure. The blind mode [D26] set aside,
a child that answered from the screen alone and ran nothing, read two
pages and guessed the rest, and the maintainer removed it as a measure
of nothing clear; the expert reads all there is.
Source. The maintainer's proposal, «у меня в подписке есть токены для апи запросов ... может сделать какой-то скрипт, который сфомирует one shot эксперта и за один вызов передат ему какой-то исчерпывающий набор файлов из скоторых точно можно вывести как работает язык  ... и задать сразу 14 вопросов тех и попросить написать к ним правильные квери? или модели не видят данных своих? ...»

Alternatives. The expert with the catalog as it is written for its
context, the self-description of the language, a call of a clean model
with no tool from a directory of its own; the expert with the grammar
and the evaluator besides, which measures how readable the
implementation is rather than the language; a pilot of either on a set
no reader has seen, kept as a mode of the benchmark only where its score
and its misses tell what the children's do not; or the children in the
loop alone, as [D26] measures now.
