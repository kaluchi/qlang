# D289 · The axes read every value alike, a value under a tag of identity by the kind beneath it

Left at cd573ebb, the tree this text was last true of: a path, a case or a

Domain. Language.
Decided by. The model, at the maintainer's word that the choice is the

Overrides [QSSLF#axis], [QSSLF#manifest].
Decision. The axes read a name and, over a value, the kind it shows, one
rule for all of them. `manifest` is a word of `::any`, as `doc`,
`binding`, `source`, `laws` and `explain` are: over a value it answers
the names under the kind the value shows, `5 | manifest` the listing of
`::number`, a keyword among values, and a name nothing declares it
refuses as every axis does, `::any/manifest/UnknownNameError`. A value
under a tag nothing declares, a tag of identity that checks nothing, is
read by the axes as a call of a word reads it, down its stack of tags to
the first kind declared, so `::Box{:a 1} | doc` is the page of `::map`
where `::Box` names nothing; `type` still answers `::Box`.

```qlang
> 5 | manifest | eq (::number | manifest)
true

> ::Nothing | manifest !| type
::any/manifest/UnknownNameError

> ::Box{:a 1} | doc | eq (::map | doc)
true
```

Source. The maintainer asked whether the axes answer every literal,
«а скажи .. набор аксис глаголов доступен для всех литералов? там нет
ошибок в ответах..» (maintainer, 2026-10-15 00:19, session d65e4c1d);
the model ran the eight axes over a literal of every kind and laid out
three changes, and the maintainer left the choice to it, «а можешь сам
решить? наиболее академичным образом в духе языка и совпадающий с
твоим ожиданиями-прайорами..» (00:27).
Set aside. `manifest` kept on `::tag`, the one axis a value could not
ask; the empty set for a name nothing declares, a second answer to the
question the other axes refuse; a refusal for a value under a tag of
identity, whose words its payload answers.
