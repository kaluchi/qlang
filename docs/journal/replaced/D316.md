Domain. Language.
Question. On a map `has` asks what `get` reads, a number naming the key
of its text [QSPTH#has], the maintainer having decided that the two
agree [D284]. On a vector and a set `has` asks whether an element equal
to the value stands and reads a path, so a number asks for an element
there while `get` reads the index it names, and the one question, is it
there, is answered two ways by the kind of the subject:

```qlang
> [5 6] | get [~(has 0) ~(has /0) ~(get 0)]
[false true 5]

> {:"0" 5} | get [~(has 0) ~(has /0) ~(get 0)]
[true true 5]

> #[5 6] | get [~(has 5) ~(has /0) ~(get 0)]
[true true 5]
```

`contains` asks a vector and a set for an element [QSTXT#search].
