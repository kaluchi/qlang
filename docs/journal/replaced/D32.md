Domain. Language.
Decision. Every value has a kind: the outermost tag of its stack, and
for a value without a tag of its own, the kind of the core its literal
implies. `[…]` implies the vector, `{…}` the map, `#[…]` the set,
`#"…"` the pattern [D246], `~(…)` the quote, `|~~ … ~~|` the doc,
`!{…}` the error [D13], `/a` the path [D248], and a number, a string,
a keyword, a tag name, a boolean and null each have their own; a host's
value carries its tags above one of them. The printer writes every tag
of a stack except the kind the brackets already imply, so `[1 2]`
prints bare and `::jdt/list[1 2]` prints its tag. `type` answers the
kind of any value, `[1 2] | type` answering `::vec`, and `type | doc`
reads the kind's page for a value of the core as for a host's.
