# D331 · Open: every answer a host prints within one budget, and `out` the door a query opens past it

Left at 4c447319, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 4c447319:<path>`, not in today's.

Domain. Language.
Question. Should qlang promise a model that no answer floods its
context: every answer a host prints, a failure among them, held within
one budget known before the query runs and never smaller than the first
screen of the language, an answer past it a failure that tells its size
and the way on, and the query's own explicit step the one door past the
budget? Today a host prints a value whole unless a budget is asked
[QSHST#answer], and `elide` holds a budget where it can, the answer
standing over it where no part gives way shorter [QSPRN#elide]: a map
and a text at the top of an answer, or of the excerpt of a failure, pass
every budget, and a map beneath the top gives way to a marker that says
nothing of its parts:

```qlang
> 1000 | range | map ~(get [~(it) ~(it)]) | toMap | get [~(print | count) ~(elide 2000 | print | count)]
[12783 12783]

> 300 | range | map ~(get [~(it) ~(it)]) | toMap | get {:users ~(it)} | elide 2000
{:users ::elision{:size 300 :read ~(get /users)}}

> get [~(200 | range | map ~("a") | join "" | elide 50 | count) ~(::vec/sort | doc | elide 50 | type)]
[200 ::doc]
```

The alert of a failure holds its excerpt over a wide map, the subject of
its first stop giving way whole where its cut passes the excerpt, as the
subjects of the later stops do, the road the critique of the first text
found within the text of [QSHST#answer]:

```
$ node cli/src/bin.mjs '1000 | range | map ~(get [~(it) ~(it)]) | toMap | add 1' < /dev/null | wc -m
457
```

A step does not hold a budget for a failure, which passes it by, while
`out` writes what a query hands it whole, on either track:

```qlang
> 1 | add "x" | elide 5 !| type
::number/add/addend/KindNotTakenError
```

```
$ node cli/src/bin.mjs '1 | add "x" !| it | print | out' < /dev/null | wc -m
194
```

The first screen a fresh session reads [QSWRK#measure], the page of the
language and the page of the command line, prints:

```qlang
> [::qlang ::cli] | map ~(get [~(it) ~(doc)]) | print | count
14254
```

The record holds the first principle of [D332] at the print of the host,
where the tree breaks it. The model's reading: the economy of a session
the aim names, a context
that only grows and an answer read again on every later round trip, asks
that what an answer adds be bounded and known before it arrives, and a
source whose size is unpredictable, or whose bounded answer says nothing,
is worth nothing to a model. Only what a host prints reaches the context,
so the bound belongs to the print of the host, past the boundary of the
core; the words of the core answer as they answer, `shape | keys | count`
the same under every host. A critique of the first text of this record by
a clean reader,
`docs/journal/research/design-check/2026-10-15-50d8072e/D331.md`, found
the budget of the words breaking that boundary, a view cut in width
breaking the constructor of a kind under a tag and colliding with a key
JSON may hold, and the scripts that read a whole answer; this text takes
its road of the bound at the print alone.

Alternatives. The roads, each with its cost:
- The bound at the print, the road the maintainer laid out. A host
  prints every answer within one budget, a constant never smaller than
  the first screen above, which a law holds against it; no flag of the
  command line cuts an answer. An answer whose print passes the budget is
  not cut into a view: the host prints a failure in its place, its facts
  the size of the print, the budget and a preview, the head and the tail
  of the print with each long string in it chopped, within the budget,
  and its page the repair, the answer narrowed by `get`, `take`, `keys`
  or `shape`, or written whole through the door the query opens itself,
  `print | out`, on either track `!| it | print | out`. A failure's alert
  holds the budget as well, each fact within its excerpt as it holds now.
  An explicit step that writes, `out` and `err`, writes what the query hands
  it. `elide` stays a word a query cuts a value with on purpose, and learns
  to cut a map and a text at the top. `shape` and `paths` stay words of
  the core that answer as they answer [D324]. The aim writes the promise
  among the requirements of every host. At the cost of the print of the
  command line changing from whole to bounded and the flag `--budget`
  leaving it; the texts that say an answer prints whole, the first page,
  the pages of `::cli` and `::elision` and the usage, and with them the
  first screen and its measure; the scripts and the tools that read a
  whole answer, the grade of the benchmark, the screen it takes and the
  probes, each writing through `out` or answering within the budget; the
  excerpt of the alert in `git show 4c447319:core/src/elide.mjs`; and the sections
  [QSHST#answer] and [QSPRN#elide] and their cases.
- A wrapper a query lays over its answer, `elide :off` or a budget asked
  larger, which the host takes off before it prints: set aside by the
  maintainer, `out` being the door already.
- The print cut into a view with markers, the first text of this record:
  at the cost the critique found, a container under a tag cut in width
  refused by its own constructor and a marker under a key JSON may hold.
- A budget of the words, `shape` and `paths` fitting their answers within
  the budget of the host or refusing: at the cost of a word of the core
  answering by the host it runs under.
- A budget only where it is asked, as today: at the cost of a model that
  forgets the flag reading a whole answer, and a failure printed whole.
Under the leading road the decision settles: the size of the budget; the
address and the facts of the failure an answer past it raises, and the
length of the head and the tail of its preview; whether `tap`, which
shows a value halfway through a query, is a door as well; whether the
REPL, the language server and the playground of the site, which prints
by `printValue` alone, print within the same budget; how `elide` cuts a
map in width, which the third road of [D327] and the elision by the
schema of a kind in [D257] weigh too; and the words of the promise the
aim writes.
