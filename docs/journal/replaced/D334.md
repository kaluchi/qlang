Domain. Language.
Decided by. The model, on the maintainer's words, who left the order of

Overrides [QSORD#order]
Decision. Two texts rank by their code points, the characters a string
counts [QSTXT#string]: a string, the text and the flags of a pattern, the
name of a keyword and of a tag, the tag over a value, a segment of a path
and a key of a map. Their code units rank so too, but where a character
past the basic plane, written by two surrogates, meets one from U+E000 to
U+FFFF, which the code units ranked after it; so `sort`, `min`, `max` and
the comparisons read the characters `count`, `take` and `drop` read:

```qlang
> ["😀" "ﬁ" "a" "👍"] | sort
["a" "ﬁ" "👍" "😀"]

> get [~("😀" | count) ~("😀" | gt "ﬁ")]
[1 true]
```
