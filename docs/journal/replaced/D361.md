Decision.
- A host is a tool that hands the language its sources, each
  `{ uri, source, primitives }`, and receives its answers: the core is the
  host of the language's own sources, and the command line, the language
  server, the site and the sister project are hosts, so a verb of the core
  and a verb of another host answer alike [QSNAM#owner]. `impl` gives a
  function its recipe, code or `::builtin{}`, the descriptor of a recipe a
  host answers by a primitive, the JavaScript function it hands under the
  verb's address beside its source; the runtime, the evaluator with its
  table of primitives and the values it reads, `::fn`, `::kind` and
  `::builtin{}`, runs it, and a failure inside a primitive is
  `::call/HostFailureError`. A primitive that reads the state of its call
  takes it after the values of its inputs, and every other takes the
  values alone. The modules of the runtime register the core's primitives
  in that table, two under one address refused as
  `::builtin/AddressRegisteredTwiceError`; the root refuses a
  `::builtin{}` its host handed no primitive for as
  `::builtin/PrimitiveNotHandedError`, and a primitive handed for a name
  its source declares otherwise as
  `::builtin/PrimitiveNamesNoBuiltinError`. The engine a host runs on
  bounds the length of a vector and runs a regex alike on every platform,
  the terminal hands the REPL a paste in chunks, and the painters read the
  verbs of the root, `verbNames`.
- The sources of the language are read where `git show c5e34146:core/package.json` maps
  them, by the road each platform asks for: the files on Node, read by the
  loader of `git show c5e34146:core/host/`; `fetch` in a browser that maps `#qlang/<name>`
  in its import map; and the locator a bundle hands `langRuntime`, as the
  site's does; the root reads each whole as it boots, and what the boot
  costs stays [D268]'s. No consumer reckons where the core lives from the
  layout of the repository: the language server reads the file of each
  source where the package exports it, `@kaluchi/qlang-core/lib/<uri>.qlang`,
  resolved from its own dependency, and the editor's extension imports the
  core by its name, a dependency of its package. The refusals of the boot
  stay under `::builtin` and name no platform: `::builtin/SourceLoadError`
  holds `:origin`, the source, as `::builtin/BootstrapSourceMissingError`
  names it, `:sourceLocation`, where the platform looked for it, and
  `:cause`, the host's account of the failure; their pages name no
  platform, protocol, import map or `imports` of a package, while the
  message a host's developer reads still says where the platform maps the
  sources.
- A value enters the language from a host only as a value of the
  language, which two doors hold, each by one walk of the value at any
  depth, a container met twice in one value walked once. The answer of a
  primitive a host hands beside its source, and the facts of a refusal it
  throws, are held where the call takes them: an answer that is or holds a
  function, an object of JavaScript, a map whose key is no string, a
  failure whose facts are no map, a value under a tag that is no tag, a
  container that holds itself, a hole of a vector or a number past the
  finite doubles fails the call as `::call/HostFailureError`, its
  `:message` naming the verb and the path where that value stands in its
  answer [QSERR#site]; a value the call handed in passes back as it is,
  the door trusting a host to change none of the values it is handed; and
  the primitives of the core are never walked, whatever function runs
  them, their tests and the fuzz of the gate holding them. A value
  JavaScript leaves undefined is null wherever the language reads it. A
  session has no `bind`: a host puts its names into the scope by its sources alone,
  and a reader by a declaration. The subject a host hands a cell and the
  values of the scope it hands a session or `evalQuery` are held where the
  core takes them, by the same walk: a value of no kind there is a defect
  of the host, raised past the fail track, `::builtin/ForeignValueError`,
  whose `:actualValue` names the value as JavaScript holds it, its type
  and its name or its maker, `"function hello"`, `"number Infinity"`, or
  what makes a container of no kind, `"a map whose key number 1 is no
  string"`, while `:actualType` stays the kind of a value refused, a tag,
  and is no fact of it; and the printer and the codec of
  JSON raise the same defect for a value of no kind no door met, a number
  past the doubles that a function of the reader answered from a
  primitive of the core under no kind among them. The print `<host-fn …>`,
  the kind `::unknown` and its form, the fallbacks of the printer and of
  the codec of JSON, `::builtin/JsonValueNotEncodableError` and
  `::builtin/NumberNotFiniteLeakedToPrintError` leave, and `fromPlain` is
  the road a host builds a lawful answer by from data it holds parsed.
  The doors hold the shape of a value, and not the invariants of a kind of
  the core a host stamps over it by the exports of the package, which
  [D293] weighs with the surface a host builds on. A binding no
  declaration wrote, a node a chain lays among them, holds no source,
  which the axis `source` answers null for.
- A scope is the names a step reads over the root, and the interface of
  the package names it so: a session keeps the scope its cells write,
  `createSession({ scope })`, `session.scope` and the entry's
  `scopeAfterCell`, `evalQuery` runs a query in the scope it is handed,
  and `langRuntime` answers the scope of the root; `env` is the verb alone,
  and `process.env` the environment Node gives the process of the command
  line; a function the package exports names the scope it takes `scope`.
  The names of the scope inside the evaluator wait for the evaluator over
  the steps.
- A source is code as written: the text a host hands, the step that
  declared a binding, its `:source`, every declaration under an address,
  which the axis `source` reads, and the line where a parse stopped, the
  `:source` of `::quote/ParseError`. Where a text came from is its
  `:origin`, a keyword naming the source, the cell or the verb that read
  it, on a binding, a failure to parse and a refusal of the root alike,
  and the root records the `uri` a host hands as that origin.
- qlang is a pipeline query language over values: the first page opens
  so, and the help of the command line, the READMEs, the descriptions of
  the packages, the site and `CLAUDE.md` name it so; the pitch of a
  general language of transformation leaves them.
- A plain value stands under no tag, `{:a 1}` a plain map beside
  `::Box{:a 1}`; an object of JavaScript is named so; and `toPlain` and
  `fromPlain` keep their names while [D340] part 10 and [D293] weigh what
  a host builds on.
- The retired terms join the lexicon of retired terms
  [QSWRK#documents], each a pattern of its one sense: `impls`, a host's
  implementation and its binding, `bindPrim` and its kin, the kernel,
  `ImplementationNotHandedError`, `ImplementationNamesNoBuiltinError`,
  `AddressBoundTwiceError`, `::unknown`, `<host-fn`,
  `JsonValueNotEncodableError`, `NumberNotFiniteLeakedToPrintError`,
  `:logicalName`, written `:origin`, the `:uri` of a refusal, the
  session's `env`, `envAfterCell` and `bind`, a plain function for a
  primitive, and the pitch of an expression language; the generic words,
  host, status and plain, stay out of it.
