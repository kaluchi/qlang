# D408 · A span between backquotes of a block doc holds a doc nested in it, and a closer that closes none of its docs ends the doc

Left at b935e4af, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show b935e4af:<path>`, not in today's.

Domain. Language.
Decided by. The model, on the maintainer's report of a page painted
otherwise than it is written, which the source quotes, taking the road of
the third question of [D369] that reads a doc nested in a span, held
within the span, so an opener alone in a span reads as it did.
Overrides [QSSYN#doc]
Decision.
- In a block doc, a span between backquotes holds a doc nested in it: a
  `|~~` in the span opens a doc of the span and a `~~|` closes the last it
  opened, `|~~|`, the marker of a line doc, opening none; a `~~|` that
  closes none of the docs of the span ends the span and the doc, and the
  run that closes the span closes it whatever docs it left open.
- The pages of the catalog whose spans write a doc literal, the examples
  of a declaration with its page on the pages of `::fn`, `::kind` and
  `::qlang/verbs` among them, read as they are written: each run of
  backquotes pairs with the run its author wrote, a quote between
  backquotes stays prose, and the painter paints the code each span
  spells.

```qlang
> |~~ a `f |~~ b ~~| c` then `~(count)` d ~~| | segments
[" a `f |~~ b ~~| c` then `~(count)` d "]

> |~~ a `|~~` then `~(count)` d ~~| | segments
[" a `|~~` then `~(count)` d "]

> [|~~ a `~~| |~~ b` c ~~|] | count
2

> ::qlang/verbs | doc | segments | filter ~(type | eq ::quote)
[]
```

Set aside.
- A span read to the run that closes it whatever it holds, the closer of
  the doc sought after it; a backquote a writer leaves open reads on into
  what follows the doc.
- A doc nested in a span read by the rule of a doc nested in the prose,
  which reads past the run that closes the span; an opener alone in a
  span, as the page of `::qlang/values` writes `|~~` among the signs a
  print opens with, swallows the closer of the doc around it.
- No page writing a doc literal between backquotes; the examples of a
  declaration with its page leave the pages of `::fn` and `::kind`.
- A comment or a quote nested in a span read whole as well, its `~~|`
  closing nothing; no page holds a `~~|` inside one in a span, and a span
  reads the prose of a comment and of a quote as its own.
