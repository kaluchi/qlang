Decision.
- `node scripts/dossier.mjs <section>` hands the dossier of a section, or
  of a record its tests hold: its text, the records in transit over it, its
  cases, its test files with their groups and their titles, the code its
  tests import, the imports of the helpers of the tests among it, the blocks
  its marks cover, each with the sections whose tests reach it, and the code
  its tests alone reach.
- A test reaches the code its imports read: each declaration a name it
  reads reaches through the imports, the exports and the members of a
  module taken whole, the imports its code runs, `await import(…)` taken
  apart or read by a member and `require(…)`, and the code every module it
  loads runs as it loads; the command line of a script, the code of its
  head that reads `process.argv`, runs where the script is the command. The
  runner of the cases reaches what it reaches for each section that holds
  cases, since a case runs its query through the evaluator, which reaches
  the whole core; so the reach tells apart the code of the tools and of the
  scripts, which their tests import, and none of the core the cases run.
- `node scripts/dossier.mjs --astray` lists the blocks of the code whose
  mark names a section no test of which reaches them while the tests of
  another do, a record in transit standing for the sections it overrides: a
  reading for the review and no check of the gate, since a block of a tool
  that cites the rule of the language it follows is reached by the tests of
  the tool alone.
- A citation written in backquotes is the example of a mark and names
  nothing.
