Decision.
- A comment of the sources and the tests of the core, the command line and
  the language server is a mark alone, one line of the citations of the
  sections and the records its block holds, `// [QSNAM#reach], [QSDSP#walk]`,
  a citation between backquotes the example of a mark and none, or a
  directive of a tool, `/* global fetch */`: what the code does is read from
  the code and its names, the rule from its section and the reason from its
  record, so no comment says again what a section states or the code shows.
- A mark that repeats the mark before it in its file leaves, since the block
  of that mark reaches to the next [QSWRK#marks], so the blocks the marks
  cover stand as they stood; the head of a module marks the rules it holds,
  and its name says what it holds.
- `check:conventions` refuses any other comment of those sources and tests,
  each read by acorn, a comment after code on its line among them; the
  share of comment lines to lines of code is no measure a branch is held to,
  since a mark comes with the block it marks, and `node scripts/measure.mjs`
  prints it beside the sign of the diff.
