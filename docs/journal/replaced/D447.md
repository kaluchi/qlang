not write: `"` and `\` escaped, a line break, a tab, a carriage return, a
backspace and a form feed as `\n`, `\t`, `\r`, `\b` and `\f`, every other

cannot see, holds no code unit a text in UTF-8 cannot carry, and reads back
as the string by `parse | open`.

```qlang
> "\uD800" | print | parse | open | eq "\uD800"
true
```

```sh
$ qlang '"\uD800" | print' < /dev/null
```
