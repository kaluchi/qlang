# D448 · The address of a primitive in its descriptor, and a function and a kind of a host read back from their print running it

Decision. The root writes into the descriptor of each primitive it takes the
address it takes it under, `:of`, the tag of the verb or of the kind: the
recipe of `::number/add` is `::builtin{:of ::number/add}` and the constructor
of `::number` `::builtin{:of ::number}`, while the catalog writes
`impl ::builtin{}` and the axis `source` reads the text as written. A
primitive runs within the function or the kind its host handed it with, and
within one equal to it by the one order, read back from its print among
them, where the root it runs in holds that function or that kind at the
address its descriptor names: a function of a host read back reads as the
function it was, `eq` and its call alike, and a kind of the core read back
builds its one form. A descriptor that runs no primitive so, one a reader
writes, one put into a function of its own and one whose address the root
holds otherwise, runs nothing: the call of its function is refused as
`::fn/RecipeMissingError`, `:of` naming the address where the descriptor
names one by a tag, and a kind lays its tag over the payload as it is.

A root tells a function or a kind read back from the one it holds once, the
first time it runs it, and keeps what it told for that value.

Set aside.
- The primitive held by the identity of its descriptor alone, as it stood:
  a function read back `eq` to the function it was and running nothing, a
  kind of the core read back building no form, and the store of a cell
  meeting the hole first [D407].
- A descriptor that names an address running the primitive the root holds
  there whatever function holds the descriptor: a function of a reader's own
  over `::builtin{:of ::vec/take}` handing the primitive inputs its chain
  never held, the primitives of the core passing the door unscanned
  [QSHST#door].
- The address a field of `::builtin` declares, `reads :of`: the soft read of
  a field runs `query`, which the last source of the root declares, after
  the first descriptor the root builds.
- The read of a function resolving it, the constructor of `::fn` answering
  the function the root holds where the one it builds equals it: a
  constructor reading the scope of its call.
- The refusal with no fact of the address, read from the recipe of its
  `:actualValue`: a fact an alert prints at the end of the print of a
  function.
