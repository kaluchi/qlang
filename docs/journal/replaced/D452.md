# D452 · `explain` leaves with `::explanation`: `doc` reads the page of a value, and of an error at rest the page of the refusal it carries

Left at 297d1956, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show 297d1956:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, who took `explain` out with its kind; the
road of the pages it read is the model's: `doc` reads them as it read
them before.
Overrides [QSSLF#axis], [QSSLF#explain], [QSNUM#combine]
Decision. `explain` and its kind, `::explanation`, leave the language. The
page `explain | page` read is the page `doc` reads, the page of the kind of
a value, a name's own page, and for an error at rest the page of the
refusal it carries, the page that says how the call is repaired,
`"x" | add 1 !| doc`; the value `explain | value` read is the subject
itself.
Source. The maintainer's word on the kinds of the catalog the wiring
names, «::explanation - можешь удалить вместе с explain» (maintainer,
2026-10-25 10:23 UTC, session b7688601); the model's probe in that session
that `doc` answers every page `explain` answered, `"x" | add 1 !| doc | eq
(::number/add/SubjectNotNumberError | doc)` and `5 | eq !| doc | content |
contains "with no value"` answering `true`, `::Nothing | doc !| tag`
answering `::any/doc/UnknownNameError`.
Set aside.

  page `doc` reads of it alone.

error at rest, `an-error-at-rest-reads-the-page-of-the-refusal-it-carries`,

`a-refusal-raised-by-rule-with-no-page-of-its-own-reads-the-page-of-what-refused`,
