# D500 · A program carries the values of its text it reads, written at its head where it is declared; a quote stays as it is written

Left at ffaf3079, the tree this text was last true of: a path, a case or a
probe it names reads there, `git show ffaf3079:<path>`, not in today's.

Domain. Language.
Decided by. The maintainer, who took the road of capture at the
declaration for a program alone: «~(gt limit) - ничего захватывать не
должна ... :big (gt limit) и :big gt limit - пусть захватывают что
недостает». The model's: the values a program reads and does not declare
itself written at its head by the fill code written in a step gets
[QSQUO#held], a program under a label among them, and the source of the
name kept as written.
Overrides [QSNAM#declare], [QSBLD#recipe].
Decision.

A program, a body whose head asks for a subject [QSNAM#declare], is code
written in the step of its declaration, and that step writes at its head
the values of its text the program reads and does not declare itself, as
a step writes them at the head of code written in it [QSQUO#held], and no
value of its own name, by which a word calls itself [QSBLD#recipe]:
`:limit 4; :big (gt limit); [1 5 10] | filter big` answers `[5 10]`, and so
do `:big gt limit` and the program under a label,
`:limit 4; :number/big gt limit; [1 5 10] | filter big`. The value of the
name holds the code with that head,
`:limit 4; :big (gt limit); ::big | binding | value` answering
`~(:limit 4; gt limit)`, while its source stays the declaration as
written. A value declared after the program is no value of its text yet
and stays out of it, `:big (gt limit); :limit 4;` refusing `limit` where
`big` runs, and a value of the code that calls the program stays out of
it as before, so a value a recipe needs from its call is an input.

A quote is a literal, held as it is written: `:big ~(gt limit)` writes
nothing at the head of the quote, and the quote run by a verb refuses the
value of its step it reads as `::call/ValueWithheldError` [QSQUO#held];
`fill` writes a value at its head, `~(gt limit) | fill {:limit 4}`.

The page of `bind` and the page of the recipe tell the head a program
carries, and the chapters write it at the closeout. The recipe of a word
under a label reads the value of its text:

```qlang
> 5 | apply (:factor 3; :number/times mul factor; times !| tag)
15
```
