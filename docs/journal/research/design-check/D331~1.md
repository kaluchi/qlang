### conflict · One budget the environment holds

Сегодня `shape` и `paths` — чистые примитивы субъекта. Дорога делает их ответ функцией бюджета хоста, вплоть до отказа `::any/shape/OutlineOverBudgetError`. Это расходится с принципом «The host boundary» из AIM.md: нужды терминала «shape no semantics of the core». Расходится и с «only what has a literal reaches the pipeline»: бюджет не значение области видимости, и прогон кейсов идёт без хоста. Кроме того, ломается композиция: `shape` над 300 записями печатается в 15793 символа, но внутри конвейера отвечает то, что читатель уже сужает:

```
$ grep -n "bindPrim('any/shape'\|bindPrim('any/paths'" core/src/runtime/path.mjs
148:bindPrim('any/paths', subject => {
174:bindPrim('any/shape', subject => shapeOf(subject, true));
```

```qlang
> 300 | range | map ~(get [~(it) ~(get {:id ~(it) :tags ~(get ["a"])})]) | toMap | shape | get [~(print | count) ~(keys | count) ~(get /"7")]
[
  15793
  300
  {
    :id ::number
    :tags [::string]
  }
]
```

При этой дороге один и тот же запрос `shape | keys | count` ответит 300 или отказом, смотря по флагу хоста. Бюджет печати при этом сработал бы на конечном ответе, а не на промежуточном шаге.

### conflict · One budget the environment holds

Этот закон держат кейс записи D325 в транзите, `a-top-whose-least-prints-no-shorter-stays-as-it-is`, и кейс `a-part-no-longer-than-its-marker-stays-under-a-budget`. ### counterexample · One budget the environment holds

Контейнер под тегом сохраняет форму ([QSPRN#elide]) и стоит над любым бюджетом. Если же резать его в ширину, вид становится значением, которое отвергает конструктор его вида. Тогда ломается правило «prints and reads back», которое та же дорога требует от формы map, срезанной в ширину:

```qlang
> :Big |~~ B ~~| (::kind | holds :SmallError |~~ b ~~| ~(count | gt 20)) | 30 | range | tag ::Big | get [~(elide 30 | print | count) ~(::Big[0 1 ::elision{:size 28 :read ~(drop 2)}] !| type)]
[86 ::Big/SmallError]

> 30 | range | map ~(get [~(toString | toKeyword) ~(it)]) | toMap | tag ::Box | elide 40 | print | count
318
```

Широкая map или вектор под тегом — дыра в обещании. Закрыть её срезом значит нарушить инварианты видов, и дорога ничего из этого не решает.

### hole · One budget the environment holds

Нижней границей бюджета записи служит «the first screen», usage плюс первая страница, 2608 + 11527 = 14135. В дереве у этих слов уже два других значения. Кейс `the-first-screen-holds-its-weight` называет первым экраном одну первую страницу и держит её в пределах 13664. Экран, который получает ребёнок бенчмарка по [QSWRK#measure], печатается в 14254:

```qlang
> ::qlang | doc | print | count | lte 13664
true

> [::qlang ::cli] | map ~(get [~(it) ~(doc)]) | print | count
14254
```

При константе 14135 хост срезал бы тот самый экран, по которому меряется миссия. Если же бюджет — «the print of the first screen read at the start of a run», он меняется с каждой правкой первой страницы, и бюджет перестаёт быть известным заранее. Кроме того, текст `--help` живёт строкой в `cli/src/argv.mjs` и закону ядра недоступен.

### road · One budget the environment holds

Если map режется в ширину внутри `elide`, `shape` и `paths` собственный бюджет не нужен. `paths` отвечает множеством, а множество уже делится пополам. `shape` состоит из map и векторов, и срез печати сохранит его первые ключи с их формами:

```qlang
> 300 | range | map ~(get [~(it) ~(get {:id ~(it) :tags ~(get ["a"])})]) | toMap | paths | elide 2000 | get [~(print | count) ~(last)]
[1597 ::elision{:size 525 :read ~(drop 75)}]
```

Бюджет `paths`, бюджет `shape`, отказ `OutlineOverBudgetError` с его страницей и дыра «what `paths` answers over the budget» становятся лишними. Цена — только форма map, срезанной в ширину, причём при бюджете по запросу, как во второй дороге.

### hole · One budget the environment holds

Обещание «every answer a host prints» запись мерит только печатью ответа. Есть ещё каналы: `out` занимает stdout и пишет целиком, `tap` пишет в stderr, который сессия тоже читает, а проза страницы под алертом стоит вне `elideAnswer`:

```
$ qlang --budget=10 '200 | range | map ~("a") | join "" | out' < /dev/null | wc -m
201

$ qlang --budget=10 '200 | range | tap | count' < /dev/null 2>&1 | wc -m
307
```

Решение должно сказать, входят ли `out`, `err`, `tap` и проза отказа в бюджет. Пока это не сказано, «never floods its context» остаётся обещанием о части вывода.

### hole · One budget the environment holds

Маркер уровня `shape`, который «reads it with the word again», не имеет пути в данных, когда уровень — свёртка элементов вектора. `/users/0` в форме — это свёртка всех пользователей, а `get /users/0 | shape` читает одного:

```qlang
> {:users [{:a 1} {:a "x"}]} | get [~(shape | get /users/0) ~(get /users/0 | shape)]
[
  {
    :a #[::number ::string]
  }
  {:a ::number}
]
```

Кроме того, `:read` по [QSPRN#elide] — это quote, применяемый к значению, которое взял `elide`. У маркера `shape` он применялся бы к субъекту `shape`, и у `:read` появилось бы два значения.

### hole · One budget the environment holds

Вариант «a reserved key» для маркера остатка map сталкивается с [QSLIT#json]: ключом может быть любая строка JSON, так что любое зарезервированное имя может оказаться данными:

```qlang
> {"…": 1, "$rest": 2, "elision": 3} | keys
#[:"$rest" :elision :"…"]
```

Решение должно сказать, как вид отличит маркер от записи с тем же ключом. Иначе `get` на виде прочтёт маркер вместо данных или наоборот.

### hole · One budget the environment holds

Третья проба самой записи не совпадает с деревом. Map из одной записи, держащая маркер, печатается в три строки, а не в одну, как записано. Значит, раскладка map с маркером, которую задаёт D325 («keeps the layout its other parts give it»), для map не устоялась:

```qlang
> 300 | range | map ~(get [~(it) ~(it)]) | toMap | get {:users ~(it)} | elide 2000
{
  :users ::elision{:size 300 :read ~(get /users)}
}
```

`check:probes` на этой записи упадёт. К тому же map, срезанная в ширину, по [QSPRN#print] кладёт каждую запись на свою строку. D325 показала эту потерю на векторах: бюджет уходит на раскладку. Форма среза map должна решить и раскладку.
