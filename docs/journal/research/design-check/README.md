# Critiques of the open records

Each run a folder named by its date and the tree it read,
`<date>-<tree>/`: a report for each open record as its clean reader wrote
it, `<Dnn>.md`, and the model's reading, `reading.md`, every finding with
its probe and its fate [QSWRK#review]. `node scripts/spec-check.mjs --records Dnn …` runs a
critique, and a run stays in its branch until the move of the baseline
cleans the research.

[QSWRK#review]: ../../../spec/QSWRK-the-work.md#review
