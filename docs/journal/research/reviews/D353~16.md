## Что проверено и в порядке

- **Подъём отвечает как `parseJson`:**
  - пустой ввод и `< /dev/null` → `::qlang`;
  - текст не JSON и BOM → строка;
  - порядок ключей сохраняется;
  - ключ дважды → `{"a":3,"b":2}` обоими путями;
  - глубокий `1e400` → `:path /a/b/1`;
  - `""` → 0;
  - одни пробелы → 3;
  - вложенность 20000 → HostFailureError обоими путями;
  - `--fail` → exit 1.
- **Ячейки:** запрос остаётся `:cell-1`; ячейка подъёма не оставляет в сессии ни привязок, ни истории.
- **`in`:**
  - по имени, по адресу, в группе, после объявления с литералом → 7;
  - объявление, тело которого читает субъект, перед `in` и `count | in` → подъём есть;
  - stdin читается один раз: `[2 "[1,2]" "[1,2]"]`.
  - `out`, `err`, `tap` и `table` читают субъект, так что набор слов полон.
- **argv:** `--json`, `-i --json`, `--json -i` → exit 2 со строкой использования; справка, README и `::cli` говорят одно и не называют `--json`.
- **Ядро:** после группы и литерала остаётся только вызов (`steps.mjs:75-76`, 157-158), так что `get('name')` безопасен. `fromJsonText` из пакета не читает никто: ни сестринский проект, ни lsp, ни site, ни scripts.
