Судьбы, каждая с пробой на дереве после починки:

1. **jdt ломается при посадке.** Принято. Сестринский проект правится в момент
   посадки, коммитом в своём репозитории без пуша, как велит его запись: проба
   его `coverage` получает тег `::CoverageProbe` через `returns` в
   `coverage.qlang`, тесты читают тег через `typeOf`, а факты через `.facts`;
   его страницы и комментарии, где descriptor значит факты, говорят facts.
   D378 говорит о пробе покрытия сестринского проекта в решении о слоте
   заголовков. Правка проверяется его набором после влития.
2. **Страница `::construct` описывала отвергнутую дорогу.** Починено:
   `construct.qlang` называет шагом-конструкцией литерал ошибки под тегом и
   только его. `~(|~~ see ::link~(a) ~~|) | first | segments | get /1 | type`
   → `::link`; страница: «a tag written before an error literal among them».
3. **Проверка экспортов держала не то, что утверждала D378.** Починено:
   чтение вынесено в `scripts/root-exports.mjs` на разборщик JavaScript, который
   гонит линтер (espree). Он читает:
   - импорт по имени экспорта, псевдоним в стороне;
   - реэкспорт `export {…} from` пакета;
   - пространство имён, импортное и динамическое, по членам, которые оно читает;
   - динамический импорт с разбором объекта, в `then` и через `await`;
   - `export *` пакета как чтение всех имён;
   - фронтматтер Astro.

   Корень отказывает любому экспорту не по имени из модуля (`export const`,
   `export *`) и имени из модуля, который открывает другая дверь. Хосты —
   воркспейсы из `readWorkspaces`, имя пакета, его корень и двери — из
   манифеста ядра, страница — его README.

   Страница пакета теперь называет то, на чём строит хост вне дерева:
   `declareRefusal`, `makeErrorValue`, `keyword`, `makeTag`, `typeOf`.
   Каждую клаузу держит `core/test/unit/root-exports.test.mjs`: резка каждой
   на копии роняет тест. Две клаузы не держались ничем — запасной разбор как
   скрипт и пропуск `loc` — и ушли.

   Дверь `./errors` отдаёт свой модуль целиком: решено в D378 («a door opens
   its module whole»), её сужение отставлено. Шапка проверок называет (19),
   а текст вердикта говорит о воркспейсах рядом с ядром.
   Проба: `node scripts/check-conventions.mjs` → `check:conventions — OK`; на
   копии корня с `export * from './runtime/json.mjs'`, `export const probeConst = 1` и
   `export { tokenize } from './highlight.mjs'` проверка отказывает всем трём,
   двум по строке и `tokenize` как имени чужой двери.
4. **Вид ошибок клал себя второй раз над ошибкой в покое.** Починено:
   у вида `::error` конструктор ядра `error/construct`, который отдаёт
   нагрузку, так что ошибка в покое под `::error` остаётся собой, а любая
   другая карта получает тег. Закон `readsAnErrorAtRestAsItself`, кейс
   `the-kind-of-errors-over-an-error-at-rest-is-that-error` (QSERR#rest).
   `get [~(!{:by 3} | tag ::error | eq !{:by 3}) ~(!{:by 3} | tag ::error | :v it | print | parse | open | eq v)]`
   → `[true true]`. `fill` с таким значением отдаёт
   `~(:x |~~ X. ~~| [!{:by 3}] | x)`. Fuzz с сидом рецензента
   `node scripts/fuzz-laws.mjs 25 20261020` → `0 broke`, с сидом 777 → `0 broke`.
5. **Квоты литерала ошибки бежали в двух областях по тегу.** Починено по
   правилу [QSQUO#held]: «a part of a template it writes… is code of that step».
   Литерал ошибки, с тегом или без, теперь шаблон, написанный в шаге
   (`isTemplate`), и его квоты — код шага. Кейсы
   `a-quote-an-error-literal-of-a-step-holds-is-code-of-that-step` и
   `…-reads-the-verbs-of-the-reader` (QSQUO#held), который D378 теперь
   переопределяет.
   `:k 10 | 5 | get [~(get ::E!{:q ~(add k)}) ~(get !{:q ~(add k)}) ~(get ::error!{:q ~(add k)})]`
   → `[::E!{:q 15} !{:q 15} !{:q 15}]`. Затенение глаголом читателя показывает
   второй кейс; дорогу шаблона уже держат его прежние кейсы.
6. **Трасса провалившегося факта в литерале ошибки под тегом.** Без правки:
   тегированный литерал ошибки теперь тегированный литерал, а правило
   [QSERR#trace] «a step the failure skips joins the steps of the last frame»
   держит шаг тега так же, как у любого тегированного литерала.
   `::Box{:t ::number#"x"} !| trace | map ~(get [~(failed) ~(skipped)])` →
   `[[~(::number#"x") ~(tag ::Box)] [~(::Box{:t ::number#"x"}) ~()]]`, той же
   формы, что у `::E!{…}`.
7. **Отказ по нагрузке при улове без кейса.** Починено: кейс
   `a-catch-whose-label-takes-no-facts-refuses-the-error-at-rest`
   (QSERR#catch) → `[::P/PayloadKindNotTakenError ::error]`.
8. **Сервер языка не находил ссылок с головы `::E!{…}`, рядом стояли ложные
   комментарии.** Починено: `referencedAt` читает голову тегированного
   литерала, а вхождение тега в тегированном литерале отдаётся спаном его
   головы. Ссылки с головы `::Box[…]`, которых не было и на master, теперь
   тоже находятся. Тест сервера
   `finds the references of a tag from the head of a tagged literal…`:
   `[':E |~~ An E. ~~|', '::E', '::E']`. Комментарии `walk.mjs`,
   `features.mjs` и теста сервера переписаны.
9. **Доля комментариев выросла.** Починено: комментарии, которые написала
   ветка, ужаты. Счёт строк `core/src`, `cli/src`, `lsp/src`: базис
   2443/7372 = 0.33139, дерево 2436/7355 = 0.33120.
10. **Единый страж видел меньше двух прежних.** Починено: страж грузит каждый
    модуль `cli/src`, кроме `bin.mjs`, который трогает процесс. Отказ,
    объявленный командной строкой, он требует страничкой в её источнике
    (`origin cli`), а отказы ядра отделяет снимком реестра до загрузки модулей
    командной строки. Резка: отказ, объявленный в `repl.mjs`, роняет тест
    `any/repl/UnpagedError is paged under the noun it guards`. Страницы ядра
    по-прежнему держит набор cli: так решила D296, «a test that boots each
    host's sources».
11. **Лексикон без тестов, регекс descriptor узок.** Починено: регексы D378
    ловят каждую формулировку, которую ветка вычистила, и путь
    `scripts/benchmark/inputs/…`. `retired-words.test.mjs` держит четыре
    записи двумя тестами, отказа и пропуска (drift вида находки, input функции,
    descriptor примитива).
12. **Проверка (2) потеряла наследника дефекта.** Починено: класс над
    `QlangError` или `QlangDefect` без суффикса Error ловится. Резка на копии:
    `class Broken extends QlangDefect {}` в `errors.mjs` →
    `class Broken names a refusal without the suffix Error`.
13. **Увиденные наборы бенчмарка переписаны.** Взвешено в D378. Набор V и W
    читается в форме контракта, а запись каждого автора в `author/` остаётся
    как он её написал. Генератор автора бенчмарк не запускает (в
    `scripts/benchmark` нет чтения `gen.js`), набор меряет один раз, а прогон
    фиксирует дерево своего коммита. Отставлено с причиной: «the code of the
    benchmark reading two forms of one set».
14. **Тест таблицы зависел от порядка.** Починено: каждый тест после загрузки
    сам грузит рантайм. Каждый из шести тестов проходит отдельно через `-t`.
15. **Запись и сиды.**
    - D378 переопределяет [QSHST#source] (правило хоста ляжет туда, а не в
      QSWRK#tooling) и [QSQUO#held].
    - README называет то, на чём строит хост.
    - CLAUDE.md называет новую проверку в «What the tooling enforces».
    - `Domain. Language.` оставлен по образцу D361 и D365, которые вели
      поверхность хоста в той же записи.
    - Цитаты строк кода на запись в транзите без правки: перенос базиса —
      следующие коммиты ветки, и его скрипт пишет в каждую такую строку
      раздел, так что состояние после переноса то же.
16. **Кейсы.** Починено:
    - шаг литерала ошибки показывает только QSQUO#step (дубль в QSERR#rest
      ушёл);
    - кейс конструкции разделён на два правила, построение и отказ
      `a-construct-of-the-kind-of-errors-over-an-error-literal-is-refused-naming-its-tag`.
17. **Слова.** Починено: `defect` в `errors.test.mjs`, заголовок
