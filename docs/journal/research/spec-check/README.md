# Checks of the chapters

Each run a folder named by its date and the tree it read,
`<date>-<tree>/`: a report for each group of chapters as its clean
reader wrote it, `<codes>.md`, and beside them the model's reading,
`reading.md`, every finding with its probe and its fate [QSWRK#review].
`node scripts/spec-check.mjs` runs a check, and the series keeps its two
latest runs.
